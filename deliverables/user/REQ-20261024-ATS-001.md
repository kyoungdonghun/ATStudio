기존 6개 상품 가격·기간·한도·정기결제 정책 유지. 운영 환경·배포/되돌리기·자동 작업 담당 확정, 불필요한 시험 자동생성 비활성화 준비. 메일은 기존 정보 우선으로 NCP SENS MAIL 전환 준비(현재 Gmail 보존), PG는 기존 Toss 구현/TEST 근거와 자동결제 계약/MID/키/콜백/웹훅/운영 설정 준비. 클라이언트 시험 종료 전 실결제 검증 계획을 남긴다.
## 제한
새 비용·실결제/환불/청구·공개 접근·새 계정·데이터 삭제·스키마 변경·무관한 변경·commit/push 금지. 가격 확인 전 과금 가능한 호출 금지. 비밀값은 출력하지 않고 기존 참조/전용 입력 사용. 최신 원격 사실과 과거 근거 구분. 기술상 실패의 범위 내 복구·수정·검토·안전한 재시도는 재승인 없이 진행. 도구 강제 확인 준수.
여기서 새 계정 금지는 불필요한 ATStudio 신규 계정 생성을 포함한다. 후속 승인된 공급자 가입 준비는 클라이언트 본인이 NCP/Toss 신원·약관을 직접 처리하는 인계안이며 MA의 임의 가입·계약 수락·결제수단 추가·유료 활성화를 허용하지 않는다. 사용자는 두 공급자 가입을 클라이언트에게 한 번에 요청하기로 했으므로 이 세션의 즉시 NCP 가입 요청은 철회되었다.
