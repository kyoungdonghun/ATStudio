# WI-20260713-ATS-002 설계 확정 요약

## 판정

- 확정된 P0 세 건은 DB 스키마를 바꾸지 않고 수정할 수 있다.
- 공개 음원은 원본 경로를 숨기는 것만으로 끝내지 않고, 전용 미리듣기 파일이 없을 때도 원본 전체가 스트리밍되지 않도록 제한 구간만 제공한다.
- SMTP 실패 로그는 수신자·제목·본문·토큰·예외 메시지를 제거하고 난수 `deliveryId`만 추적값으로 남긴다.
- 회원 탈퇴는 로컬 자동결제 차단을 먼저 커밋하고, Toss 빌링키 삭제는 커밋 후 처리한다. Toss 실패가 탈퇴나 로컬 차단을 되돌리지 않는다.

## 주요 호환성 결정

- 공개 Track 응답의 `audioFile` 필드는 삭제하지 않고 `null`로 유지해 API 형태 변화는 최소화한다.
- 관리자 Track 응답에는 편집 화면에 필요한 원본 저장 키를 유지한다.
- 기존 파일의 실제 이동은 하지 않는다. `/uploads/tracks/audio/**`를 모든 역할에 차단하고, 구독 다운로드는 기존 보호 API를 계속 사용한다.
- 빌링키 삭제 실패는 기존 결제 대사 Incident의 `LOCAL_DONE_PROVIDER_NOT_DONE`으로 기록해 새 DB enum과 마이그레이션을 만들지 않는다.

## 다음 단계

1. 원본 음원 노출 차단과 제한 미리듣기 구현
2. SMTP 로그 최소화 구현
3. 탈퇴 시 로컬 갱신 차단, 사후 빌링키 정리, 실패 Incident 및 재시도 구현
4. 각 결함의 집중 테스트 후 보안·통합 교차 검토
5. API·운영·설계 문서 현행화와 전체 품질 검증
