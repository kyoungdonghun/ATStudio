- 포함: 현재 코드/기존 감사 근거를 이용한 JVM·MySQL·Hikari·요청/전송 동시성·다운로드 속도·SMTP timeout 초기 설정표와 검증 기준.

- 제외: 실행 템플릿/제품 코드 변경, 도구 설치, restic 실행, 서버·스토리지 생성/구매, 원격 접속/설정, DB 접근/덤프/DDL, 시크릿 생성·열람, 실제 업로드·삭제·메일·결제, 커밋/푸시.
