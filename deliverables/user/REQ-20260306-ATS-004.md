[GOAL / WHY]

- Playlist 도메인의 한국어 UI 레이블이 과거에 "앨범"으로 **오기입**되어 문서 전반에 잔존하고 있음
- 이후 신규 Album 도메인(어드민 큐레이팅 앨범, Section 15)이 추가됨으로써 "앨범"이 두 개의 서로 다른 개념을 지칭하는 명칭 충돌 상태가 됨
- Playlist(구독자 개인 재생목록)의 한국어 레이블을 **"재생목록"**으로 정정하여 두 도메인 개념을 명확히 구분함

---

[SCOPE]

- **In:**
  - 문서 내 Playlist 기능을 "앨범"으로 오기입한 모든 한국어 레이블 → "재생목록"으로 정정
    - `docs/check/atstudio-front-list.md` — 섹션 헤더 및 화면명 (Playlist 섹션 한정)
    - `docs/design/api-spec.md` — Section 3 (Playlist) 내 "앨범" 표기
    - `docs/design/usecase/sound-playlist.md` — "앨범" 표기
    - `docs/design/usecase/index.md` — Playlist 행 설명
    - `docs/design/db-schema.md` — playlists 테이블 설명 내 "앨범" 표기
    - `docs/standards/glossary.md` — Playlist 용어 설명 내 "앨범" 표기
  - 백엔드 Java 소스코드 내 한국어 주석에서 Playlist를 "앨범"으로 표기한 부분 정정

- **Out:**
  - API URL 변경 (`/api/playlists` 유지)
  - DB 테이블명 변경 (`playlists` 유지)
  - Java 클래스명 / 메서드명 / 변수명 변경 (`Playlist`, `PlaylistService` 등 유지)
  - 영문 기술 식별자 전체 (변경 대상 아님)
  - Album 도메인 관련 문서 (별도 REQ로 처리)
  - 화면 목록 v2 업데이트 (Album 화면 추가 등 — 별도 REQ로 처리)

---

[SUCCESS CRITERIA (DoD)]

1. 모든 대상 문서에서 Playlist를 지칭하는 "앨범" 표기가 "재생목록"으로 정정됨
2. Album 도메인(Section 15, 어드민 큐레이팅)을 지칭하는 "앨범" 표기는 **변경되지 않음** (정확한 의미 구별 검증)
3. API URL, DB 테이블명, Java 식별자는 변경되지 않음
4. 백엔드 빌드 성공 (`gradlew.bat build -x test`)
5. cr 리뷰 통과 (CRITICAL 0, MAJOR 0)

---

[CONSTRAINTS / POLICIES]

- 작업 추적 단위: WI
- REQ 승인 전 파일 수정 금지
- **핵심 제약**: "앨범"이 Playlist를 의미하는 오기입인지, Album 도메인을 의미하는 올바른 표기인지 **반드시 문맥으로 판별** 후 변경
  - Playlist 맥락 (구독자, `/api/playlists`, 개인 재생목록) → "재생목록"으로 변경
  - Album 맥락 (어드민, `/api/albums`, 큐레이팅) → "앨범" 유지
- 변경 범위: 한국어 레이블/주석만. 영문 코드 식별자 변경 금지
