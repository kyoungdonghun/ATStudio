[GOAL / WHY]
- ATStudio의 첫 번째 기능 구현: 사용자 인증/인가 및 회원 정보 관리
- 모든 후속 기능(음악 업로드, 구독, 결제 등)이 인증 시스템 위에서 동작하므로 최우선 구현 대상
- JWT Bearer Token 기반 인증 + Spring Security 6 필터 체인 구축
- 일반 로그인(이메일/비밀번호) + 소셜 로그인(Google/Kakao/Naver) 통합 지원

[SCOPE]
- In:
  - **회원가입** `POST /api/users` — 이메일, 비밀번호, 닉네임, 전화번호, 직업, 회원 유형
  - **일반 로그인** `POST /api/auth/login` — accessToken + refreshToken 발급
  - **소셜 로그인** `POST /api/auth/social/{provider}` — GOOGLE/KAKAO/NAVER OAuth2 Authorization Code Flow, isProfileComplete 플래그 반환
  - **소셜 프로필 완성** `PUT /api/users/me/complete-profile` — 첫 소셜 가입 시 추가 정보 입력 (닉네임, 전화번호, 직업, 회원 유형)
  - **토큰 재발급** `POST /api/auth/refresh` — Refresh Token으로 Access/Refresh Token 재발급
  - **내 프로필 조회** `GET /api/users/me`
  - **내 프로필 수정** `PUT /api/users/me` — 닉네임, 전화번호, 직업 (userType 변경 불가)
  - **회원탈퇴** `DELETE /api/users/me` — 비밀번호 확인 후 소프트 딜리트 (is_deleted=1)
  - **이메일 중복 확인** `GET /api/utils/check-email`
  - **전화번호 중복 확인** `GET /api/utils/check-phone`
  - **인프라**: Spring Security 6 설정, JWT 유틸리티 (JJWT 0.12.5), JwtFilter, CustomUserDetailsService, GlobalExceptionHandler Auth 에러 처리
- Out:
  - 이메일 인증 (별도 REQ)
  - 비밀번호 재설정 (별도 REQ)
  - 관리자 회원 관리 API (`GET /api/users`, `GET /api/users/{id}`, `PUT /api/users/{id}`)
  - 구독/결제 관련 기능 (별도 REQ)
  - React 프론트엔드 화면 구현

[SUCCESS CRITERIA (DoD)]
- 모든 10개 엔드포인트가 api-spec.md 명세대로 동작
- 인증 없이 `[PUBLIC]` 외 엔드포인트 접근 시 401 Unauthorized 반환
- 비밀번호는 BCrypt 해시로 저장 (평문 절대 금지)
- JWT Secret Key가 application.yml에 하드코딩되지 않고 환경변수로 처리
- `gradlew.bat build` 성공 (컴파일 오류 없음)
- 핵심 Service 레이어 단위 테스트 통과 (JUnit5 + Mockito)
- 소셜 로그인 3개 provider (GOOGLE/KAKAO/NAVER) 플로우 구현 완료
- GlobalExceptionHandler에 Auth 에러 코드 처리 추가
