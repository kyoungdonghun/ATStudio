# WI013 역할과 결정 결과 설명 PDF

[클라이언트 전달용 PDF](client/ATStudio_policy_roles_and_changes.pdf)를 8쪽으로 작성했습니다. 각 주제에 클라이언트가 할 일과 결정에 따른 개발자 작업을 분리하고, 유지·변경·수동·자동 처리 등의 선택이 어떤 추가 작업으로 이어지는지 설명했습니다.

상품·PG·해지·환불·기존 콘텐츠·증명서·CID·개인정보를 포함합니다. 클라이언트가 기술적 해결 방법을 직접 결정할 필요가 없으며 개인정보의 실제 처리 불일치는 선택적으로 생략할 항목이 아님을 명시했습니다. 답변만으로 추가 개발·비용이 승인되는 것으로 보지 않습니다.

내용 검사와 작성자·MA 독립 전페이지 시각 검토 PASS입니다. 검토 중 보완한 6쪽 역할 표시는 재생성 후 다시 확인했습니다. 이전 7쪽 PDF를 보존했으며 코드·HWP·실제 정책·서버·공급자 변경이나 발송은 없었습니다. 기존 검토 근거를 재사용했으며 새 운영 사실이나 법적 적합성을 확인한 문서는 아닙니다. [증거 기록](../agent/WI-20261025-ATS-013-evidence-pack.md).
