# REQ-20261121-ATS-001 · 지인 선공개와 판매 가오픈

[REQ] Project ATS / Owner MA / Status completed-planning-only (2026-11-21 승인·검토)

[GOAL / WHY] 기존 2차를 지인용 선공개와 판매 가오픈으로 나눈다. 지인별 시험 계정과 비결제 이용권으로 다운로드를 체험하고, 운영 메일과 PG 실결제는 후반에 연결한다.

[SCOPE] 기존 한국어 로드맵·문서 진입점 갱신, 로컬 소스·시험·운영 완료 기록 대조, 선공개 전 준비와 단계별 담당·수락 기준 정리.

[SUCCESS CRITERIA] 재사용 가능한 기능과 실제 검증 환경·한계, 현재 청취 전용 제한에서 필요한 변경, 익명/관리자/일반 시험 사용자와 최초/재다운로드·기간/회수 경계를 명시한다. 클라이언트의 확인 사항과 개발·운영 준비 순서를 기록한다.

[EXECUTION STRATEGY] WI-20261121-ATS-001 문서 담당이 기존 로드맵에 반영하고 링크를 검사한다. MA는 근거와 최종 내용을 검토한다. 이번 요청의 실행 대상은 로드맵이다.

[OUTCOME] [차수별 로드맵과 초대 전 시험표](REQ-20261104-ATS-002.md#stage-b-rollout-2026-11-21)에 B1·B2 결정과 준비 순서를 반영했다. [WI 근거](../agent/WI-20261121-ATS-001-evidence-pack.md)에서 날짜별 시험과 현재 제한을 추적한다. 다음 실행 작업은 B1 초대 범위와 일반 USER의 접근 변경안을 구체화하는 것이다.

## 11월 21일 후속 결정

[REQ] Status completed-planning-only · WI-20261121-ATS-002 · 문서와 실행 순서 확정

사용자가 확정한 2차 전반 범위는 지인별 일반 시험 계정과 비결제 이용권, 현재 공개곡의 최초·재다운로드, 로그인한 본인의 이력과 라이선스 확인이다. 곡 자격은 기존 공개 카탈로그 판정을 재사용한다. 회원가입·가입 화면의 정책 동의·운영 메일·PG는 2차 후반에 둔다. 로컬 소스와 기존 증거를 토대로 기존 로드맵과 문서 진입점을 맞추고, 구현·시험 순서와 추론 등급 전환 시점을 기록한다.

[OUTCOME] [현행 B1 실행안](REQ-20261104-ATS-002.md#stage-b-rollout-2026-11-21)과 [소스 근거](../agent/WI-20261121-ATS-002-evidence-pack.md)를 정리했다. 다음은 Medium에서 합성 사용자 두 명으로 진행하는 로컬 구현·집중 시험이고, Extra High 독립 검토와 실제 시험 환경 확인이 뒤따른다. 이번 완료 대상은 계획이다.
