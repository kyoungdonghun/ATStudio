# 지인 선공개 보관함 운영 검증

11월 23일 운영 사이트에서 전용 시험 계정 5·6으로 좋아요와 재생목록을 확인했습니다. 두 계정이 서로 다른 공개곡을 좋아요에 추가했고 각 계정에는 본인 변경만 보였습니다. ID 5는 새 재생목록에 공개곡 두 곡을 추가하고 순서를 바꿨습니다. 로그아웃 후 다시 로그인해도 바꾼 순서가 유지됐습니다. 비로그인 공개 음원도 구간 요청에 응답했습니다.

검증 후 시험용 좋아요와 재생목록을 정리했습니다. 양쪽 계정의 기존 좋아요·활성 재생목록·다운로드 잔여 횟수를 다시 확인했고 두 계정 모두 로그아웃했습니다. ID 6의 임시 이용권 연장은 11월 21일 만료 상태로 복구했습니다. ID 5는 승인받은 대로 기존 세션을 교체했습니다. 지인에게 배정한 30개 계정은 이 시험에 사용하지 않았습니다.

운영 검증은 HTTPS API로 진행했습니다. 재생목록 삭제 후에는 서비스 설계에 따라 비활성 행이 남습니다. 전용 계정 참조·시험 데이터 복구 등을 검사하는 로컬 시험은 다섯 건 통과했습니다. [검증 방법과 근거](../agent/WI-20261123-ATS-018-evidence-pack.md)

11월 23일 23시 50분(KST) 최종 조회에서 ID 5의 만료일은 11월 30일, ID 6은 11월 21일이었고 두 계정 모두 갱신 토큰이 비어 있었습니다. 배포용 키를 제거하고 Windows SSH agent의 중지·비활성화를 확인했습니다. iwinv 인바운드 규칙은 웹용 80·443만 남았고 기존 작업 PC에서도 서버의 22번 포트에 연결되지 않았습니다. 이 상태에서 외부 공개 목록 조회와 음원 구간 요청이 다시 통과했습니다. [완료된 요구사항](REQ-20261123-ATS-003.md)
