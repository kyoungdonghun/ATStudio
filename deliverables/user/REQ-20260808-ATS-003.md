[GOAL / WHY]
- 공개 메인 화면의 저장 음원 길이와 실제 재생 길이 불일치를 원인·영향 화면·기존 데이터 범위까지 조사하여 SR로 기록한다.
- 메인 화면 태그 탐색이 `GENRE`와 `MOOD`에만 한정된 상태를 `INSTRUMENT`와 `USAGE` 정책까지 포함해 개선할 요구를 정리한다.
- 재생 지연 안내가 표시되는 정확한 조건과 앨범 전체 재생 시 waveform이 사라지는 데이터 계약 결함을 하나의 재생 신뢰성 SR로 기록한다.

[SCOPE]
- In:
  - `SR-99`: MP3 길이의 128kbps 고정 추정으로 인한 저장 길이 오차, 영향 화면, 생성·수정·기존 데이터 보정 요구
  - `SR-100`: 메인 화면의 장르·분위기 탐색에 용도·악기 탐색을 보강하는 정보 구조와 우선순위 제안
  - `SR-101`: `waiting`/`stalled` 즉시 안내의 조건·UX와 앨범/플레이리스트 등 축약 Track 데이터의 waveform 누락 개선 요구
  - 공개 Cloudflare 화면, 공개 API, 스트림 메타데이터, 현재 프론트·백엔드·테스트·기존 SR 교차검증
  - `docs/SR/index.md`, `docs/index.md` 번호·상태·문서 개수 동기화
- Out:
  - React/Spring Boot 코드 수정
  - DB 음원 길이 또는 waveform 데이터 변경·백필
  - 공개 사이트 배포나 터널 변경
  - 실제 운영 계정·재생목록·앨범·음원 데이터 수정

[SUCCESS CRITERIA (DoD)]
- `docs/SR/SR-99.md`, `SR-100.md`, `SR-101.md`가 서로 독립적인 목적을 가진다.
- SR-99는 세 트랙의 API 길이와 실제 미디어 길이를 표로 기록하고 128kbps 고정 추정 원인, 약 320kbps 파일 증거, 수정 경로의 duration 미갱신, 기존 데이터 검증 요구를 포함한다.
- SR-100은 공개 API에 실제 존재하는 `INSTRUMENT`·`USAGE` 태그와 메인 미노출 사실을 구분하고, `USAGE` 우선 탐색 및 홈 화면 과밀화 대안을 제시한다.
- SR-101은 재생 지연 문구의 이벤트 조건과 해제 조건, 정상 시작 시 순간 노출 재현, 앨범 API의 축약 Track 계약과 `waveformData: null` 매핑, 다른 영향 화면과 개선안을 포함한다.
- 세 SR은 `OPEN`으로 인덱싱되고 SR 파일/인덱스가 100개, 상태가 `OPEN` 15건, 전체 관리 문서가 202개로 실제 파일과 일치한다.
- validate-docs, 내부 링크, Markdown 구조, `git diff --check`가 통과한다.

[CONSTRAINTS / POLICIES]
- Work tracking unit: WI
- 공개 UI, API 응답, 실제 미디어 메타데이터와 저장 데이터를 분리해 기록한다.
- 실제 재생 시간이 authoritative한 사용 경험이지만, 장기 계약은 서버가 파일 메타데이터에서 정확히 추출한 duration으로 통일한다.
- `USAGE`는 라이선스가 아니라 콘텐츠 활용 장면을 설명하는 visible guide/search tag라는 기존 용어 계약을 유지한다.
- 순간적인 버퍼링과 재생 실패를 같은 오류로 표현하지 않는다.
- waveform 장식용 생성으로 문제를 숨기지 않고 실제 저장 peak 데이터를 전달한다.
- 기존 사용자 파일과 이전 SR 본문은 수정하지 않는다.

[RISKS / OPEN QUESTIONS]
- Risks:
  - MP3 파일 크기 기반 duration 보정은 CBR/VBR 모두에서 오차가 발생할 수 있으므로 다른 고정 bitrate로 바꾸는 방식은 해결책이 아니다.
  - 기존 데이터 백필은 파일 읽기와 DB 변경을 수반하므로 이 문서 WI에서는 실행하지 않는다.
  - 홈에 네 개의 세로 섹션을 그대로 추가하면 과밀해질 수 있으므로 탭/그룹/우선순위 설계가 필요하다.
  - native `waiting`은 정상 재생 시작에도 발생할 수 있어 즉시 장애 문구를 띄우면 거짓 경고가 된다.
  - waveform 누락은 앨범뿐 아니라 플레이리스트·좋아요·다운로드 내역·재생 기록 등 축약 Track 생성 경로에도 존재한다.
- Questions:
