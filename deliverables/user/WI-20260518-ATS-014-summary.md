# WI-20260518-ATS-014 Summary

- Defined the minimum operator-facing payment support view requirements.
- Operators should be able to inspect payment orders, finalized subscription payments, billing agreement status, masked method, next billing date, failure count, and sanitized failure information.
- Refund, receipt, settlement, webhook reconciliation, and multi-PG operations remain follow-up scopes.
- API candidates are documented as not implemented in `docs/design/api-spec.md`.
