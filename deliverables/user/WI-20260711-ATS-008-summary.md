# WI-20260711-ATS-008 교차 도메인 감사 결과

## 결론

**릴리스 차단(BLOCK)** 입니다. 결제, 화이트리스트, 기업 인증 영역은 WI-006/007의 소유 범위로 남기고 중복 판정하지 않았습니다. 현재 비결제 영역에서 **P0 2건, P1 5건**을 확정했습니다.

## 확정 P0

1. **원본 음원 직접 접근 우회**
   - 공개 트랙 상세가 원본 저장 경로를 반환하고, `/uploads/**`가 같은 저장소 전체를 정적으로 공개합니다.
   - 익명 사용자가 구독, 일일 한도, 다운로드 기록, 라이선스 발급을 거치지 않고 원본 파일에 접근할 수 있는 경로가 정적으로 성립합니다.
   - 근거: `SecurityConfig.java:66-69,129-132`, `WebConfig.java:20-25`, `TrackResponse.java:10-39`, `DownloadService.java:39-86`.

2. **SMTP 실패 시 인증/재설정 토큰과 개인정보 로그 노출**
   - 이메일 본문에 실사용 토큰 URL이 포함되며, 발송 예외 시 수신자와 전체 HTML 본문을 로그에 기록한 뒤 성공 흐름을 유지합니다.
   - 전제는 비밀번호 로그인이 활성화되고 SMTP가 실패하며 공격자가 애플리케이션 로그를 읽을 수 있는 경우입니다. 이때 이메일 인증 또는 비밀번호 재설정 권한을 탈취할 수 있습니다.
   - 근거: `EmailService.java:46-65,88-108,141-180`, `security-policy.md:26-45`.

## 과장 또는 오탐 조정

- **업로드 즉시 P0 관리자 토큰 탈취:** 확정 P0로 단정하지 않습니다. 저장/정적 공개 경로는 확정됐지만 운영 동일 오리진과 실제 응답 헤더는 저장소에서 확인되지 않았습니다. 현재 판정은 P1이며, 동일 오리진 배포가 확인되면 P0입니다.
- **Cloudflare/프록시 뒤 전 사용자 인증 장애:** `remoteAddr` 단일 키 사용은 확인했지만 실제 프록시 주소 수렴은 배포 조건입니다. 현재는 외부 검증 필요이며 확정 P1이 아닙니다.
- **QA 관리자 공용 비밀번호가 현재 노출됨:** 기본값과 프로필 강제 부재는 위험하지만 bootstrap은 기본 비활성입니다. 운영 활성 여부를 확인하기 전에는 확정 침해로 보지 않습니다.
- **ADMIN이 USER 경로에 들어갈 수 있으므로 일반 권한 우회:** 비결제 도메인 전반의 우회로는 확인되지 않았습니다. 프론트 역할 계층은 ADMIN을 USER 이상으로 보지만, 관리자 전용 API와 소유권/구독 검사는 별도로 존재합니다. 결제 역할 결함은 WI-006 소유입니다.
- **공개 스트리밍의 원본 fallback 자체가 다운로드 우회:** 문서와 코드가 의도적으로 허용한 정책입니다. P0의 원인은 스트림이 아니라 원본 저장 경로 공개와 정적 파일 직접 접근 조합입니다.
- **과거 JWT fallback이 현재 런타임 취약점:** 현재 설정은 `${JWT_SECRET}` 없이는 시작할 수 있습니다. 과거 값이나 저장소 이력은 이번 WI에서 읽거나 재현하지 않았으므로 현재 우회로로 판정하지 않았습니다.

## 우선 조치

1. 원본 음원을 정적 루트 밖으로 이동하고 공개 DTO에서 저장 경로를 제거합니다.
2. 이메일 실패 로그에서 수신자/본문/토큰을 제거하고 발송 실패를 명시적 결과로 처리합니다.
3. 업로드를 사설 또는 별도 무쿠키 오리진으로 분리하고 이미지 decode/re-encode 및 고정 응답 타입을 적용합니다.
4. 로그아웃/비밀번호 변경/재설정 시 서버 refresh token을 폐기하고 회귀 테스트를 추가합니다.
5. 소셜 콜백에서 `fetchMe(res.accessToken)` 순서를 보장합니다.
6. 파일 작업을 트랜잭션 인지형 보상 모듈로 통합합니다.

## 검증 경계

- 정적 소스/문서/테스트 코드만 확인했습니다.
- exploit, 업로드, 미디어/첨부 다운로드, 이메일 발송, DB/외부 제공자 호출, 비밀값 조회는 수행하지 않았습니다.
- 기존 변경 파일과 `cloudflared`/Vite 로그는 읽거나 수정하지 않았습니다.
