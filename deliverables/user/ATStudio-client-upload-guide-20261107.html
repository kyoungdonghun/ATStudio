처음 한 곡을 공개하는 순서

  1. 기존 관리자 계정으로 로그인합니다. 로그인 정보는 별도로 전달받은 정보를 사용하세요. 이 안내에는 계정이나 비밀번호가 들어 있지 않습니다.
  2. 태그 관리에서 사용할 태그를 확인합니다. 없는 태그는 + New Tag를 눌러 Name(이름)과 Type(종류: GENRE 장르·MOOD 분위기·INSTRUMENT 악기·USAGE 용도)을 입력하고 Create로 만드세요. 이미 있는 태그는 그대로 재사용합니다.
  3. 음원 업로드에서 먼저 파일을 선택하면 곡 정보와 태그 입력란이 표시됩니다. 곡명·BPM·조성, 설명·이미지를 확인하고 이 곡에 맞는 태그를 선택한 뒤 업로드합니다. 태그를 목록에 만드는 것만으로 곡에 자동 연결되지는 않습니다.
  4. 변환 완료(READY)를 확인합니다. ‘업로드 접수 완료’만으로 재생 준비가 끝난 것은 아닙니다.
  5. 음원 관리 → 수정에서 정보와 선택된 태그를 확인하고 저장합니다. 다시 수정 화면을 열어 태그 선택이 유지되는지 확인하세요. 공개하기 위해 활성화 상태를 따로 바꿀 필요는 없습니다.
  6. 음원 관리 목록의 해당 곡 작업 → 공개 버튼을 한 번 누릅니다. 별도 사유 입력·확인창·권리 확인란은 없습니다. 공개 버튼을 누르면 누구나 로그인 없이 들을 수 있으므로, 공개할 권리가 있는 음원만 선택하세요. 준비된 비활성 곡은 공개와 함께 활성화됩니다. ‘공개했습니다’ 안내와 해당 곡의 공개 중 표시를 확인하세요. 업로드만으로 자동 공개되지는 않습니다.
  7. 로그아웃하거나 별도 비공개 브라우저 창에서 공개 청취 목록과 곡 상세 페이지를 열어 소리와 중간 이동을 확인합니다. 제출할 링크는 공개된 실제 곡의 상세 페이지 주소를 복사하세요.

공개한 곡을 수정하려면

목록의 공개해제 버튼을 한 번 누르고, ‘공개를 해제했습니다’ 안내와 해당 곡의 비공개 표시를 확인한 뒤 수정하세요. 파일을 바꾸었다면 변환 완료도 다시 확인합니다. 수정과 표기 확인을 마친 뒤 해당 곡의 공개 버튼을 다시 누릅니다. 태그 자체의 이름·종류를 바꿀 때에도 그 태그가 연결된 공개 음원을 먼저 공개해제해야 합니다.

공개 버튼을 누를 수 없거나 오류가 날 때

변환 중·변환 실패·파일 변경 처리 중에는 공개할 수 없습니다. 화면에 표시된 이유를 확인하고, 처리가 끝난 뒤 목록 새로고침으로 상태를 확인하세요. 로그인 만료나 관리자 권한 안내가 나오면 로그인 상태부터 확인합니다.

결과가 불분명할 때

이전 변경 결과를 확인해야 합니다 또는 HOLD가 표시되면 같은 공개 요청을 반복하지 마세요. 이전 변경 결과 확인으로 처리 기록을 확인하고, 해결되지 않으면 운영 진단 정보 → 시도 기록 저장으로 기록을 남겨 담당자에게 전달하세요. 현재 목록에 곡이 보이는 것만으로 직전 요청이 완료됐다고 판단하거나 브라우저 저장 기록을 지우지 마세요.

실제 음원은 운영자가 직접 등록합니다. 검증용 음원은 실제 제출용 콘텐츠가 아니며 공개 목록에서 제외합니다. 공개해제 전에 시작된 재생이나 이미 받은 파일은 회수되지 않습니다.

현재 범위는 음원 등록·공개 청취입니다. 결제 서비스 개방이나 지원사업 담당 기관의 증빙 인정까지 완료했다는 뜻은 아닙니다.
