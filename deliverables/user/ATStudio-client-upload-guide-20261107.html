음원 업로드·공개 안내

음원 등록과 공개 청취를 시작할 수 있습니다.
외부 HTTPS 접속과 관리자 로그인·관리 화면을 확인했습니다. 공개 목록은 비워 두었습니다. 아래 순서로 실제 곡을 직접 등록하고 공개해 주세요.

관리자 로그인 · atmusic.co.kr/login

음원 관리 · atmusic.co.kr/admin/track-manage

음원 업로드 · atmusic.co.kr/admin/tracks/upload

공개 청취 목록 · atmusic.co.kr/tracks

처음 한 곡을 공개하는 순서

  1. 기존 관리자 계정으로 로그인합니다. 로그인 정보는 별도로 전달받은 정보를 사용하세요. 이 안내에는 계정이나 비밀번호가 들어 있지 않습니다.
  2. 음원 업로드에서 파일과 곡명·BPM·조성을 입력합니다. 필요한 설명·태그·이미지도 확인하고 업로드합니다.
  3. 변환 완료(READY)를 확인합니다. ‘업로드 접수 완료’만으로 재생 준비가 끝난 것은 아닙니다.
  4. 음원 관리 → 수정에서 정보와 ‘활성화 상태’를 확인하고 저장합니다. 변환이 끝나지 않은 곡은 활성화할 수 없습니다.
  5. 음원 관리에서 해당 곡의 공개를 선택합니다. 변경 사유를 적고 권리·크레딧 확인란을 체크한 뒤 공개 확정을 누릅니다. 업로드나 활성화만으로 자동 공개되지는 않습니다.
  6. 로그아웃하거나 별도 비공개 브라우저 창에서 공개 청취 목록과 곡 상세 페이지를 열어 소리와 중간 이동을 확인합니다. 제출할 링크는 공개된 실제 곡의 상세 페이지 주소를 복사하세요.

공개한 곡을 수정하려면

공개해제 → 공개해제 확정의 완료 응답을 확인한 뒤 수정하세요. 파일을 바꾸었다면 변환 완료도 다시 확인합니다. 수정과 표기 확인을 마친 뒤 별도로 다시 공개해야 합니다.

결과가 불분명할 때

오류가 나거나 HOLD가 표시되면 같은 공개 요청을 반복하지 마세요. ‘시도 기록 저장’으로 기록을 남기고 담당자에게 전달하세요. 현재 화면에 곡이 보인다는 이유만으로 직전 요청이 완료되었다고 판단하지 않습니다.

실제 음원은 운영자가 직접 등록합니다. 검증용 음원은 실제 제출용 콘텐츠가 아니며 공개 목록에서 제외합니다. 공개해제 전에 시작된 재생이나 이미 받은 파일은 회수되지 않습니다.

현재 범위는 음원 등록·공개 청취입니다. 결제 서비스 개방이나 지원사업 담당 기관의 증빙 인정까지 완료했다는 뜻은 아닙니다.
