[CONSTRAINTS / POLICIES]
- Work tracking unit: WI
- SR은 인수 테스트 시점의 발견 사항과 요청을 보존하는 Historical Record로 작성한다.
- 현재 UI 동작, API 계약, 저장 동작, 제안, 미확정 정책을 분리한다.

[RISKS / OPEN QUESTIONS]
- Risks:
  - 단순 관리자 수 조회 후 강등은 동시 요청 경쟁에서 마지막 관리자 불변조건을 깨뜨릴 수 있다.
  - 역할 변경 뒤 기존 JWT가 즉시 무효화되지 않으면 UI와 실제 권한 반영 시점이 달라질 수 있다.
  - 관리자 플랜 변경은 내부 표시만 바꾸고 외부 정기결제·결제수단·예약 변경을 남길 위험이 있다.
  - `CANCELLED`와 미래 만료일은 유예 기간으로 타당할 수 있으나 `EXPIRED`와 미래 만료일은 의미가 충돌한다.
  - 화면의 `cover`는 비율을 보존하지만 일부를 자르며, `contain`은 전체를 보이지만 여백과 카드 정렬 불일치를 만든다.
- Alternative Suggestion:
  - 단일 운영자 환경에서는 1차로 1:1 권장 규격과 실제 카드와 동일한 미리보기, 비율 경고를 제공하고 복잡한 대화형 크롭 도구는 실제 필요가 확인될 때 후속으로 검토한다.
- Questions:
  - 없음. 정책 선택이 필요한 부분은 각 SR의 후속 결정 항목으로 남긴다.
