[GOAL / WHY]
- ATStudio의 기존 상품 정책인 공개 전체 음원 감상을 복구한다.
- 보안 보강은 원본 저장 경로와 권한 없는 다운로드를 차단하되, 승인 없이 감상 길이 또는 상품 기능을 축소하지 않는다.
- 검증된 결과를 클라이언트 시연용 브랜치와 독립 실행 환경으로 동결하고 외부 접속을 재개한다.

[SCOPE]
- In:
  - 비회원과 회원 모두가 공개 음원의 전체 길이를 스트리밍으로 감상
  - 바이트 비율 기반 제한 미리듣기와 30초/50% 경계 제거
  - 원본 저장 경로와 정적 원본 URL 비노출 유지
  - 다운로드는 활성 구독 회원, 플랜별 일일 다운로드 한도, 다운로드 이력 및 라이선스 정책 유지
  - Range 요청, 전체 재생시간, 탐색, 재생 진행 상태의 백엔드·프론트엔드 회귀 검증
  - 재생 실패를 성공 상태로 표시하지 않는 플레이어 오류 처리
  - 설계, API, 유스케이스, 감사 종결 문서의 정책 현행화
  - 검증 커밋을 `codex/client-demo-stable` 브랜치와 별도 worktree로 동결
  - 로컬 백엔드·프론트엔드와 Cloudflare Quick Tunnel 재시작 및 공개 smoke 검증
  - 전체 시스템 감사 잔여 항목을 최신 코드 기준으로 재판정하여 사용자에게 보고
- Out:
  - 전용 미리듣기 파일 생성기, FFmpeg, 음원 트랜스코딩
  - 원본 음원 물리 이동 또는 DB 스키마·데이터 삭제
  - 다운로드 권한·횟수·라이선스 정책 변경
  - 이번 잔여 감사 보고에서 발견되는 추가 기능 또는 취약점 수정
  - 멀티서버, 멀티 PG, 운영 Toss live 검증

[SUCCESS CRITERIA (DoD)]
- 공개 스트림은 유효한 전체 음원 리소스를 정상적인 Range 응답으로 제공한다.
- 원본 저장 키와 정적 원본 URL은 공개 DTO와 공개 정적 라우팅에서 노출되지 않는다.
- 비구독자 다운로드는 거부되고 활성 구독자의 다운로드 한도·이력·라이선스 흐름은 회귀하지 않는다.
- 실제 브라우저에서 전체 duration이 표시되고 재생 후 currentTime과 진행 바가 증가하며 탐색이 동작한다.
- 재생 요청 실패 시 `isPlaying=true`가 남지 않고 사용자에게 실패 상태가 전달된다.
- 관련 현재형 문서에서 bounded preview, 30초, 50%, 전용 preview 후속 개발을 현행 정책으로 주장하지 않는다.
- 백엔드 집중 테스트, 프론트 typecheck/lint/test/build, 문서 검증, 실제 브라우저 검증이 통과한다.
- 검증 커밋이 데모 브랜치/worktree에 고정되고 로컬·공개 URL의 기본 화면과 `/api/tracks`가 응답한다.
- 잔여 감사 보고가 확정 미해결, 최신 코드 재판정 필요, 배포 환경 조건부, 문서·증거 종결 항목을 구분한다.

[CONSTRAINTS / POLICIES]
- Work tracking unit: WI
- 사용자 승인 없이 제품 기능, 상품 정책, 접근 대상 또는 감상 길이를 변경하지 않는다.
- 보안 통제는 전체 감상과 파일 다운로드를 구분한다. 스트리밍 허용을 원본 저장 경로 공개 또는 다운로드 권한 우회로 구현하지 않는다.
- 기존 사용자 변경과 미추적 런타임 로그를 되돌리거나 커밋하지 않는다.
- DB 스키마 변경, 데이터 삭제, 신규 라이브러리 도입은 이번 범위에 포함하지 않는다.
- 데모 브랜치는 검증 후 동결하고 전체 수정 작업은 개발 브랜치에서 별도 승인 후 진행한다.

[RISKS / OPEN QUESTIONS]
- Risks:
  - 공개 전체 스트리밍은 사용자가 네트워크 응답을 별도로 보존하는 것을 기술적으로 완전히 차단하지 못한다. 이는 승인된 전체 감상 정책의 경계이며 공식 다운로드·라이선스 권한과 구분한다.
  - 기존 P0 문서와 테스트가 제한 미리듣기를 보안 기준으로 고정하고 있어 코드만 바꾸면 문서·검증이 충돌한다.
  - Quick Tunnel URL은 재시작할 때 변경될 수 있다.
- Questions:
  - 없음. 사용자가 전체 감상 복구와 데모 서버 재개 범위를 승인했다.
