[GOAL / WHY]
- 현재 개발 결과를 ATStudio V1의 단일 공식 기준선으로 확정한다.
- 개발 과정에서 누적된 이전 버전 호환 코드, 임시 fallback, demo/acceptance 우회, 백업 파일, 중복 DB 초기화·보정 경로, 오래된 현재 상태 설명 및 끊어진 작업 자산을 제거한다.
- Git 이력과 REQ/WI 기록은 보존하되, 현재 실행 코드와 운영 문서는 과거 버전에 의존하지 않는 하나의 버전만 표현하도록 정리한다.
- 보존할 실제 DB 데이터는 없으므로 최신 `schema.sql`을 V1의 유일한 DB 기준선으로 삼고 빈 MySQL DB에서 재현성을 증명한다.

[SCOPE]
- In:
  - `codex/p1-acceptance-hardening`을 V1 공식 브랜치 후보로 유지한다.
  - 백엔드, 프론트엔드, DB/설정, 문서, 스크립트, Git worktree의 잔여 자산을 전수조사한다.
  - 모든 후보를 `KEEP`, `REMOVE`, `REPLACE`, `ARCHIVE`, `REVIEW`로 분류하고 호출처·런타임 역할·삭제 영향·검증 방법을 기록한다.
  - 사용되지 않는 레거시 API/호환 분기, 임시 demo/acceptance 우회, 중복 초기화·보정 SQL, 백업 파일, 죽은 fallback, 오래된 현재 상태 설명 및 끊어진 worktree를 정리한다.
  - 결제 멱등성, 감사로그, reconciliation, 처리 잠금/lease, 상태 전이, 낙관적 잠금처럼 현재 운영 안전성을 구성하는 코드는 보존한다.
  - 최신 `schema.sql`로 빈 DB를 만들고 `ddl-auto=validate` 기동 및 전체 기능 회귀를 검증한다.
  - 검증 완료 후 클라이언트 브랜치와 worktree를 퇴역시키고 공식 브랜치를 하나로 통합한다.
- Out:
  - 신규 사용자 기능 추가 또는 기존 제품 정책 변경
  - 결제사, 구독 정책, 화이트리스트 정책, 기업인증 정책 변경
  - 운영 데이터 마이그레이션 또는 운영 DB 보존
  - 실제 운영 배포 및 원격 push
  - 근거 없이 안전성 상태·원장·감사 필드를 단순화하는 작업

[SUCCESS CRITERIA (DoD)]
- 잔여 후보가 파일/심볼 단위 판정표로 작성되고 모든 제거 항목에 호출 근거와 검증 방법이 있다.
- 파괴적 작업 전에 정확한 삭제 목록을 사용자에게 보고하고 별도 승인을 받는다.
- 활성 공식 브랜치와 일반 작업 worktree가 각각 하나로 정리된다.
- 현재 실행 경로에 소스 백업 파일, 죽은 fallback, 과거 버전 전용 호환 분기 및 임시 우회가 남지 않는다.
- 최신 `schema.sql`이 V1 DB 구조의 유일한 현재 기준선이며, 빈 MySQL DB에서 적용된다.
- 빈 DB를 대상으로 Hibernate `ddl-auto=validate` 서버 기동이 통과한다.
- 백엔드 전체 테스트/빌드, 프론트 typecheck/ESLint/Prettier/test/build, 문서 검증이 통과한다.
- 역할별 주요 화면과 API 스모크 테스트가 통과하고 제거된 심볼·설정·라우트의 잔여 참조가 0건이다.
- 독립 최종 리뷰에서 잘못 삭제된 필수 기능이나 현재 문서와 코드의 불일치가 발견되지 않는다.

[CONSTRAINTS / POLICIES]
- Work tracking unit: WI
- 모든 Subagent는 Tier 0 문서와 역할별 필수 문서를 주입받는다.
- 조사 WI는 읽기 전용이다. 코드, 문서, DB, 브랜치, worktree를 수정하거나 삭제하지 않는다.
- 파일/브랜치/worktree 삭제와 DB 초기화는 조사 판정표 완료 후 사용자 재승인을 받는다.
- 현재 공개 데모는 구현 검증 완료 전까지 `codex/client-demo-stable`에서 계속 실행한다.
- `frontend/tsconfig.tsbuildinfo`, 로그, 캡처, 생성된 demo seed 등 기존 생성물은 명시적 판정 전 임의 복구·삭제·커밋하지 않는다.
- 커밋은 기능 영역별로 분리하며 `git add .`를 사용하지 않는다.
- 원격 push는 별도 요청 전 수행하지 않는다.
