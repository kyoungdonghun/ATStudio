# WI-20260713-ATS-012 문서 현행화 결과

## 완료 내용

- 공개 음원 응답에서 원본 저장 경로를 노출하지 않고, 전용 프리뷰가 없으면 원본 전체가 아닌 제한된 앞부분만 재생한다는 현행 동작을 API, DB, 유스케이스, 보안 문서에 반영했습니다.
- 이메일 발송 실패 시 수신자, 제목, 본문, 인증·재설정 URL/토큰을 로그에 남기지 않는 정책을 반영했습니다.
- 회원 탈퇴 시 로컬 자동결제를 먼저 중단하고, 탈퇴 커밋 후 토스 빌링키를 정리하며, 실패 시 Incident와 매일 01:15 재시도로 복구하는 흐름을 결제 문서와 SR-93에 반영했습니다.
- 회원 탈퇴는 자동 환불을 만들지 않으며 환불은 기존 관리자 승인 절차로 분리된다는 경계를 명시했습니다.
- 과거 감사 결과는 삭제하거나 완화하지 않고, 구현 커밋 `d11c62d`로 P0 세 건이 종료됐다는 별도 종료 보고서를 연결했습니다.
- 클라이언트 체크리스트에는 구독 중 탈퇴 후 다음 자동결제가 중단되고 자동 환불은 발생하지 않는지 확인하는 항목을 쉬운 표현으로 추가했습니다.

## 추가 교정

- 문서 작업 중 잘못 기록된 미래 날짜 `2026-07-14`를 실제 작업일 `2026-07-13`으로 전부 바로잡았습니다.
- 용어 사전의 업로드 정의에 남아 있던 “비동기 프리뷰 생성” 주장을 원본 저장, 길이 추출, 파형 추출이라는 실제 동작으로 교정했습니다.
- `schema.sql`은 테이블·컬럼·데이터를 변경하지 않고 `audio_file`, `preview_file` COMMENT만 현행 보안 경계에 맞게 수정했습니다.
