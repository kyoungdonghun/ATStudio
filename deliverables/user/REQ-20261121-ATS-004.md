# B1 운영 서버 적용 및 두 계정 검증
승인 범위는 검토된 pilot 배포, 공개 청취 보존, 비결제 시험 계정 두 개의 원본·이력·라이선스 분리 확인과 접근 정리다. 새 비용이나 판매 개방은 별도다.

## 2026-11-21 KST 적용 결과

운영 서버에 지인 선공개 버전을 적용했다. 공개곡 96개의 ID 목록이 배포 전후 일치했고 비로그인 음원 구간 재생은 HTTP 206을 반환했다. 시험 계정 5·6은 서로 다른 공개곡을 받았고 원본 SHA-256이 일치했다. 재다운로드 후 각 계정은 남은 일일 한도 4회, 이력 한 건, 기존 라이선스 UUID를 유지했다. 서로의 라이선스 상세는 양방향 모두 404였다. [배포 근거](../agent/WI-20261121-ATS-009-evidence-pack.md) · [실제 다운로드 근거](../agent/WI-20261121-ATS-010-evidence-pack.md)

두 시험 이용권은 11월 21일 KST 당일만 유효하다. 지인 참여 기간의 이용권 준비와 휴대폰에서 파일이 실제 저장되는지 확인하는 절차는 남았다. 사용자 요청에 따라 TCP22는 현재 작업 PC 한 곳의 /32 제한을 유지하며 원복은 보류한다.
