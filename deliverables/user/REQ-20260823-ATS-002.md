  - 실제 브라우저에서 재생, 일시정지, 새로고침, 곡·seek 위치 복원 확인
- Out:

- 인증 세션이 없는 401 처리와 명시적 로그아웃에서 사용자 데이터는 기존대로 정리되며, 공개 재생 상태만 불필요하게 초기화되지 않는다.
