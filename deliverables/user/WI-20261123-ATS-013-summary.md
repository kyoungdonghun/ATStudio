# 지인용 좋아요·재생목록 서버 기능 검증

유효한 시험 이용권이 있는 회원은 공개곡에 좋아요를 표시하고, 본인 이용권의 한도 안에서 재생목록을 생성·편집할 수 있습니다. 곡을 비공개로 전환한 뒤 다시 조회하면 좋아요, 재생목록 상세, 표시 순번, 곡 수에서 해당 곡이 빠집니다. 다른 계정은 내 재생목록을 열거나 변경할 수 없습니다.

로컬 Spring 시험 140건이 통과했고 실행 JAR를 만들었습니다. 별도의 로컬 MySQL 8.0.45에서도 두 계정의 개인 목록 관리와 기존 다운로드·라이선스 시나리오 2건이 통과했습니다. 이 결과는 로컬 후보에 대한 검증입니다. 운영 사이트 반영 여부는 릴리스 기록에서 확인할 수 있습니다.

테스트용 MySQL 프로세스와 접속 포트가 종료됐고 임시 인증 파일도 제거됐습니다. 도구가 재귀 삭제를 차단해 종료된 합성 데이터 폴더가 로컬 빌드 디렉터리에 남았습니다. [시험 근거](../agent/WI-20261123-ATS-013-evidence-pack.md)
