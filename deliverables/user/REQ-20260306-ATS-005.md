[GOAL / WHY]

- `docs/ui/atstudio-front-list.md`는 API Spec v5 기준 2026-02-20에 작성된 초본으로, 이후 추가된 Album 도메인이 누락되어 있고 여러 컨펌 포인트가 미반영 상태
- 사용자 확정 컨펌 포인트 전체를 반영하여 화면 목록을 **v2**로 갱신

[SCOPE]

- **In: `docs/ui/atstudio-front-list.md` 단일 파일 업데이트**

  | 변경 항목 | 내용 |
  |----------|------|
  | **① Album 섹션 신규 추가** | Track 페이지 구조와 대칭. 공개 화면 3개 + 어드민 화면 2개 |
  | **② 재생목록 상세 화면 추가** | `3.3 GET /api/playlists/{id}` 대응 화면 신규 기입 |
  | **③ 재생목록 수정 화면 API 참조 보완** | Screen 9에 `3.4 POST tracks`, `3.8 DELETE playlist` 추가 |
  | **④ 비밀번호 변경 모달 반영** | Screen 10(개인정보 페이지)에 `5.11 PUT /api/users/me/password` 추가, 모달 처리 명시 |
  | **⑤ 삭제 정책 명시** | 각 섹션 비고: 일반 삭제 = 상세/목록 페이지 confirm(), 회원탈퇴 = 비밀번호 모달 |
  | **⑥ 어드민 트랙 관리 화면 추가** | K-7 신규: 전체 트랙 목록(비활성 포함) + isActive 토글 + 삭제. `1.2 GET`, `1.6 PUT`, `1.7 DELETE` |
  | **⑦ 총 화면 수 업데이트** | 기존 40개 → v2 기준 총 수량으로 갱신 |

- **In: Album 섹션 화면 구성 (Track 대칭)**

  | 화면 | API | 인증 |
  |------|-----|------|
  | 앨범 목록 (이미지 타입) | `15.2 GET /api/albums` | [PUBLIC] |
  | 앨범 목록 (리스트 타입) | `15.2 GET /api/albums` | [PUBLIC] |
  | 앨범 상세 | `15.3 GET /api/albums/{id}` | [PUBLIC] |
  | 앨범 생성 | `15.1 POST /api/albums` | [ADMIN] |
  | 앨범 수정 + 트랙 관리 | `15.4 PUT`, `15.6 POST tracks`, `15.7 DELETE tracks`, `15.8 PUT tracks` | [ADMIN] |

- **Out:**
  - 백엔드 코드 변경 없음
  - API Spec, Usecase 문서 변경 없음
  - 인라인 모달 UX 패턴 정의 (태그 검색 등) — 별도 향후 과업
  - 통계 대시보드 (Screen 18) API 설계 — 별도 향후 과업
