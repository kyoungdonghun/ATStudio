# 커밋 후보와 비공개 보관 분류

고정한 가시 후보 696개를 검사해 **633개는 커밋 후보, 63개는 그대로 보류**로 분류했습니다. 새 보존 도구나 후속 보고서는 별도 추가 검사 목록으로 연결합니다.

- Java/NCP 소스의 기본 발신 주소·합성 시험값·라이브러리 버전 오탐을 실제 개인정보와 구분했습니다.
- 클라이언트 PDF 4개와 입력 전 Word 1개는 현재 본문·메타데이터 검사와 이전 검토 파일의 해시가 일치했습니다. Word의 실제 렌더링 미검증 상태는 유지합니다.
- 개인 홈 경로나 서버 관련 역사 문서는 원문을 대량 수정하지 않고 보류했습니다. 미검토 스크린샷·옛 안내 PDF·생성 JAR도 제외했습니다.
- 활성 문서 두 곳의 개인 절대경로만 일반화했습니다. 원본은 Git 제외 위치에 바이트 그대로 보존했습니다.

[정확한 파일별 분류](../agent/WI-20261026-ATS-004-classification.json), [검사 범위와 한계](../agent/WI-20261026-ATS-004-evidence-pack.md)를 남겼습니다. 검사는 비밀값을 출력하지 않았으며 실제 커밋·푸시·서버 접속은 이 작업에서 하지 않았습니다. 최종 커밋 직전 파일 해시와 Git에 올라갈 바이트를 다시 확인해야 합니다.
