# 지인 선공개 기능 제원과 운영자 시나리오

2026-11-23 검토. 기준은 Git `199f86d`의 판매·선공개 라우터, Spring 메서드·보안 조건, 11월 21일 배포본의 프록시 설정이다. 아래 수량은 소스 재집계 값이다. 서버에서 각 기능을 다시 실행했다는 의미로 쓰지 않는다.

## 전체 화면과 선공개 범위

| 공개 탐색. 홈, 곡 목록·상세, 앨범 이미지형 목록·표형 목록·상세, 요금제, 공지 목록·상세 | 9 | 곡 목록·상세. 홈 주소는 곡 목록으로 이동. 검색 결과는 목록에서 처리하지만 선공개 헤더에 검색 입력이 빠졌다. |

| 제작·관리. 곡 업로드·편집, 앨범 관리·생성·편집 | 5 | 관리자 곡 업로드·편집. |

판매 라우터에는 경로 선언 56개와 인덱스 리다이렉트 1개가 있다. 선공개의 업무 화면 10개는 곡 목록·상세·로그인 3개, 참가자용 3개, 관리자용 4개다. 한 화면 안의 검색창·다운로드 버튼·모바일 메뉴는 이 집계에 하나의 별도 화면으로 잡히지 않는다.

## 운영자가 실제로 하게 되는 일

| 시나리오 | 필요한 화면·동작 | 현재 상태와 경계 |
|---|---|---|
| 여러 곡을 받아 등록하고 곡별로 태그를 붙인다 | 관리자 단일·다중 업로드, 파일별 제목·BPM·조성·선택 썸네일·설명·태그, 접수 상태, 처리 상태·허용된 재시도 | B1 관리자 경로. 등록 직후에는 비공개다. 방문자는 공개 카탈로그를 본다. |
| 기존 곡을 찾아 정보·태그를 수정하고 공개한다 | 관리자 목록의 제목 검색·필터, 편집, 저장 후 재조회, 준비 상태, 공개·해제 | B1 범위. 공개 중인 곡은 먼저 해제하며, 대기·불명 상태에서 편집을 막는다. 권리·버전·변환 검사를 유지한다. 관리자의 곡 제목 검색과 방문자의 검색창은 서로 다른 구현이다. |
| 태그 이름이나 종류를 바꾸거나 시험 데이터를 청소한다 | 태그 생성·편집, 태그·곡 삭제 영향 조회·삭제 | 생성·편집은 열림. 공개곡에 연결된 태그의 편집에는 추가 제약이 있다. 태그·곡 삭제 버튼은 숨겼고 DELETE도 선공개 필터에 없다. 계정·곡·태그 정리를 참가자나 일반 관리자 메뉴에서 할 수 있다고 안내하지 않는다. |
| 지인 30명에게 권한을 주거나 잃어버린 로그인 정보를 안내한다 | 개별 USER 발급·허용 명단·기간 있는 비결제 이용권, 개별 전달·회수 | 운영자가 발급 도구와 허용 명단으로 처리. B1에는 관리자 회원/이용권 관리 화면과 셀프 재설정·메일 흐름이 없다. 분실·오배정은 별도 운영 연락으로 접수한다. 개인별 코드만 전달한다. |
| 참가자가 받은 곡과 발급 여부를 확인한다 | 내 이력, 내 라이선스 목록·상세, 발급 UUID, 재다운로드 | 참가자 자신의 조회가 열렸다. 관리자 메뉴에서 회원을 검색해 UUID를 조회하는 기존 판매 기능은 B1 경로 및 서버 허용 범위 밖이다. 참가자 확인은 본인 화면으로 안내한다. 관리자 CS 조회를 원하면 새 범위로 결정한다. |
| 지인이 다른 계정의 파일·이력을 열거나 기간이 지나 다시 받는다 | 인증·허용 명단, 비결제 유효 기간, 소유자 검사, 공개 상태, 일일 한도 | 최초·재다운로드 모두 현재 공개 상태와 유효 권한 필요. 비공개 전환·회수 후 접근을 제한한다. 기간 만료가 이력·UUID 삭제를 뜻하지 않는다. |
| 지인 피드백·유료 판매·부가 운영을 처리한다 | 문의/공지, 회원·플랜·구독, 정산·환불, 운영 메일, 가입 동의, 화이트리스트·기업 인증 | 기존 코드가 있으나 B1에서 닫혔다. 메일·가입·PG는 B2에 명시됐다. 나머지 운영 도구 전체의 B2 개방은 별도 결정이다. 채널 화이트리스트 CSV 내보내기와 결제 정산 CSV 가져오기는 서로 다른 기능이며 회원 명단 CSV 내보내기 구현 증거는 확인되지 않았다. |

## 서버 기능

컨트롤러 폴더의 GET·POST·PUT·PATCH·DELETE 메서드 선언을 다시 세면 **28개 컨트롤러, 161개 선언**이다. SPA 전달 및 청취 전용 메서드를 포함한다. 기존 API 명세 머리말의 26개·155개는 다른 시점의 집계다. 현재 외부에 161개가 열렸다는 뜻으로 사용하면 안 된다. 기능군별 전체 수량과 B1 허용 동작은 [기술 근거](../agent/WI-20261123-ATS-004-evidence-pack.md)에 정리했다.
