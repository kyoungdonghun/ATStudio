# 지인 선공개에서 공개곡을 저장하고 다시 듣기

상태 · 2026년 11월 23일 23시 50분(KST) 완료. 지인 선공개용 좋아요·재생목록의 운영 배포, 전용 계정 검증, 시험 데이터 정리와 SSH 접근 종료를 확인했다.

## 목표와 완료 기준

초대된 두 사용자로 곡 좋아요·해제, 내 좋아요, 첫 재생목록 생성, 공개곡 담기·순서 변경·제거, 다시 로그인해 목록 재생을 확인한다. 공개곡이 비공개가 되면 이후 조회와 새 재생에서 제외한다. 계정이 바뀌면 이전 회원의 목록·좋아요를 표시하지 않는다. 기존 공개 청취와 다운로드·라이선스는 회귀 확인한다.

## 실행 순서

| WI | 담당 | 작업과 기준 |
|---|---|---|
| 013 | se | 기존 Spring 서비스 재사용, 참가 자격·본인·공개 범위 적용 및 서비스 시험 |
| 014 | se | 카탈로그·플레이어·개인 화면·라우팅에 기존 동선 연결 및 프론트 시험 |
| 015 | qa-integ | 프록시·배포 경로 연결, 두 이용자의 통합 시나리오 및 독립 검토 |
| 016 | qa-fe | 하단 플레이어의 회원 동작 복원, 모바일·PC와 계정 전환 회귀 시험 |

013·014·015의 구현은 병렬로 진행하고 최종 통합 시험은 모두 연결된 후보에서 진행한다. 각 WI는 저장소 표준과 기존 판매판 사용자 흐름을 따른다. 가입·메일·결제·앨범 회원 기능의 공개 및 운영 SSH 개방은 이 로컬 작업에 포함하지 않는다.

## 운영 반영 승인

사용자가 “운영 배포·검증 후 SSH 다시 닫기”를 선택했다. WI017은 기존 초대 계정·곡·공개 목록을 보존하면서 JAR·정적 파일·프록시를 배포한다. 검증이 끝나면 작업 PC에 임시로 허용한 TCP22를 닫는다. WI018은 운영용 확인과 시험 상태 정리를 담당한다.

11월 23일 23시 43분 KST에 WI017 운영 배포를 완료했다. 설치 파일 전체·공개곡 210곡·초대 명단 32명·동일 DB 프로세스를 재확인했고 외부 음원 구간 요청 15건이 통과했다. [배포 근거](../agent/WI-20261123-ATS-017-evidence-pack.md)

## 운영 검증과 종료

WI018에서 전용 계정 5·6의 좋아요 분리와 ID 5의 첫 재생목록 생성·곡 추가·순서 변경·재로그인 후 보존을 운영 HTTPS로 검증했다. 두 보관함의 시험 데이터를 정리하고 기존 상태와 다운로드 잔여 횟수를 확인했다. ID 6의 이용권 만료일을 복구하고 두 시험 계정 모두 로그아웃했다. 최종 조회에서 5·6의 만료일은 각각 11월 30일·11월 21일이었고 두 갱신 토큰은 비어 있었다. [보관함 검증 결과](WI-20261123-ATS-018-summary.md)

작업 PC의 배포 키 제거와 SSH agent 중지·비활성화를 확인했다. 방화벽에는 공개 웹용 TCP 80·443만 남았고 기존 작업 PC의 직접 TCP 22 접속은 차단됐다. 이후 외부 공개 목록과 음원 구간 요청이 통과했다. [운영 인수·종료 근거](../agent/WI-20261123-ATS-018-evidence-pack.md) · [로컬 통합 시험 근거](../agent/WI-20261123-ATS-015-evidence-pack.md)
