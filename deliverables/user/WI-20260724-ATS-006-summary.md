이식성 계약을 검증했습니다. 제품 코드와 과거 감사 기록은 수정하지

- `docs/client/index.md`

    호출해야 한다는 점을 명시했습니다.
  - `--render-tool`은 PATH 명령 이름과 명시적인 Poppler 실행 파일
    경로를 모두 허용한다는 계약을 명시했습니다.
- `docs/payment/acceptance-test-checklist.md`
  - 폐기된 결제 환경변수가 acceptance 번들에서 거부되는지 확인하는
    항목을 유지하고 구현과 대조했습니다.
- `docs/SR/SR-93.md`
  - 폐기된 결제 provider 별칭과 acceptance launcher의 거부 정책이
    현재 구현과 일치함을 확인했습니다.
- 클라이언트 테스트 PDF와 매니페스트를 지정된 bundled Python 및
  Poppler로 다시 생성했습니다.

현재 클라이언트 PDF 생성기는 `docs/client` 아래의 고정된 7개 문서를
원문으로 사용합니다. `docs/payment/acceptance-test-checklist.md`는 현재
생성기의 PDF 원문 목록에는 포함되지 않습니다. 이번 WI에서는 승인된
문서 정합성 범위를 지키기 위해 PDF 원문 구성을 변경하지 않고, 최종
문서 편집 후 PDF와 매니페스트를 재생성하고 검증했습니다.
