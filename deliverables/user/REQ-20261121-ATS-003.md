# B1 로컬 독립 검토와 보완

**상태는 2차 전반 로컬 독립 검토 완료, 서버 반영 승인 대기다.** 승인된 범위는 WI003–005 로컬 구현의 권한·개인 기록 분리 검토와 발견 사항 수정 및 재시험이다.

## 2026-11-21 검토 근거

- [백엔드 독립 검토](../agent/WI-20261121-ATS-006-evidence-pack.md)에서 동시 공개·수정 시 비공개 제목이 개인 기록에 섞일 수 있는 조회 순서와 탈퇴·삭제 후 기존 토큰의 인증 처리를 수정했다. 집중 시험 100건이 통과했다.
- [프론트엔드 독립 검토](../agent/WI-20261121-ATS-007-evidence-pack.md)에서 여러 탭의 로그인 교체, 늦게 도착한 응답과 파일 저장, 개인 이력의 공용 플레이어 전달, 로그인 저장 실패 시 오류 처리를 수정했다. 13개 파일의 집중 시험 181건과 타입·린트·변경 파일 서식·pilot 빌드가 통과했다.
- 일반 모드 전체 프론트엔드 시험의 첫 실행에서 5건이 실패했다. 시험 코드 4개 파일의 계약 기대값·모의 데이터·기존 업로드 오류 문구 기대값을 바로잡고 해당 98건을 다시 통과했다. 최종 전체 실행은 **127개 파일 1,712건 통과, 실패·생략 0건**이다. 이 보정으로 제품 번들은 바뀌지 않았다.
- [두 계정 통합 검토](../agent/WI-20261121-ATS-008-evidence-pack.md)에서 공개 전 차단, 최초·동시·재다운로드, 한도, 상호 이력·라이선스 분리, 공개해제·재공개, 이용권 만료와 회원 탈퇴를 확인했다. Spring 요청 흐름 전체를 H2와 로컬 MySQL 8.0.45에서 각각 1회 통과했다. 별도의 실제 Chrome 두 탭에서는 합성 API를 사용해 계정 교체 후 이력이 함께 전환되는 것을 확인했다.
- 서버 반영과 실기기 파일 수신은 별도 승인 단계다. 배포 시 pilot 프론트·백엔드 설정과 nginx 경로를 함께 검증하고, 개인별 시험 계정과 유효한 비결제 이용권으로 최초 다운로드·재다운로드를 확인한다. [현재 단계](../../docs/index.md#current-decision-entry) · [B1 범위](REQ-20261104-ATS-002.md#stage-b-rollout-2026-11-21)
