# Git에서 빠져 있던 재사용 소스 보존

`build/`의 필요한 운영 도구·준비 자료를 골라 **원본 그대로 73개, 대상 식별값을 제거한 검토용 참고본 13개**를 Git 관리 후보 경로에 보존했습니다. 원본은 기존 경로와 해시를 유지합니다. 전체 `build/`나 JAR·DB·비밀번호·실제 입력·원격 실행 증거를 복사하지 않았습니다.

백업·사전 조회·계정 준비의 핵심 소스와 일부 오디오 처리 보완, 운영 모드·개인정보 흐름·사용자 시험 자료를 포함합니다. 실제 서버·저장소·스냅샷 등에 결합된 값은 참고본에서 제거했습니다. 참고본은 실행 파일로 복원되지 않습니다. 사용자 PC 경로가 들어간 문서 2개는 원본만 로컬에 유지합니다.

**검증:** 86개 원본 해시 불변, 새 빈 폴더로 73개 정확한 파일과 13개 분리 참고본 복원·해시 확인 PASS. 기존 경로 덮어쓰기·경로 이탈·변조·불필요 파일 혼입을 막는 새 보존 도구 검사 4개 PASS. Git 개행 처리 전후 86개 파일의 객체 해시도 일치했습니다.

이 보존본은 새 PC에서 모든 서버 시험을 그대로 실행하는 완전 복구 패키지는 아닙니다. 원격에 고정된 런타임·JAR·crypto 의존성, 비공개 승인·입력·증거는 별도로 필요합니다. 백업 도구의 예전 ID1 역할 조건도 이번에 수정하지 않았습니다.
