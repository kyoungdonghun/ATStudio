[GOAL / WHY]
- 어드민이 트랙을 테마별로 묶어 큐레이팅한 "앨범" 기능이 현재 미구현 상태
- 구독자(PUBLIC)가 앨범 목록/상세를 조회하고, 어드민이 앨범을 생성·관리할 수 있어야 함
- Playlist(구독자 재생목록)와 명확히 분리된 별도 도메인으로 신규 구현

[SCOPE]
- In:
  - DB 테이블 2개 신규
    - `albums`: id, title(VARCHAR 100), description, thumbnail, created_by(FK→users.id), is_active, created_at, updated_at
    - `album_tracks`: album_id + track_id 복합PK, track_order
  - Entity: Album.java, AlbumTrack.java, AlbumTrackId.java (복합PK 키클래스)
  - Repository: AlbumRepository.java, AlbumTrackRepository.java
  - DTO: AlbumCreateRequest, AlbumUpdateRequest, AlbumTrackAddRequest, AlbumTrackOrderRequest, AlbumResponse, AlbumDetailResponse, AlbumListItemResponse
  - Service: AlbumService.java (CRUD + 트랙 추가/제거/순서 변경)
  - Controller: AlbumController.java (8개 API)
  - SecurityConfig.java 업데이트 (앨범 권한 규칙 추가)
  - api-spec.md Section 15 신규 추가 (8개 API 명세)
  - db-schema.md 업데이트 (albums + album_tracks 테이블)
  - AlbumServiceTest.java (단위 테스트)
  - API 8개:
    - POST   /api/albums                       [ADMIN] 앨범 생성
    - GET    /api/albums                       [PUBLIC] 앨범 목록 (is_active=true)
    - GET    /api/albums/{id}                  [PUBLIC] 앨범 상세 + 트랙 목록
    - PUT    /api/albums/{id}                  [ADMIN] 앨범 수정
    - DELETE /api/albums/{id}                  [ADMIN] 앨범 삭제 (소프트 삭제, is_active=false)
    - POST   /api/albums/{id}/tracks           [ADMIN] 트랙 추가
    - DELETE /api/albums/{id}/tracks/{trackId} [ADMIN] 트랙 제거
    - PUT    /api/albums/{id}/tracks           [ADMIN] 트랙 순서 변경
- Out:
  - Playlist 도메인 변경 없음
  - 앨범 공개/비공개 토글 API (is_active 직접 제어 — DELETE로 비활성화)
  - 앨범 좋아요/댓글 기능
  - 앨범 검색 기능 (향후 확장)
