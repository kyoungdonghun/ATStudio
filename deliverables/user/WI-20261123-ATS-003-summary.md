# 지인 선공개에서 실제로 할 수 있는 일

2026-11-23 KST · 승인 로컬 화면, 1차 청취 화면, 2차 전반 화면의 방문자·참여자 동선 대조. [조사 근거](../agent/WI-20261123-ATS-003-evidence-pack.md)

|누가 무엇을 하려는가|현재 동선과 필요한 기능|판정|
|---|---|---|
|처음 들어와 공개곡 둘러보기|홈에서 음원 목록으로 이동한다. 공개 범위 안의 곡 수, 정렬, 페이지 이동, 목록의 곡명 링크가 있다.|지원. 기존 판매 홈의 추천·앨범 등은 별도 진입점이다.|
|곡명이나 용도를 알고 검색하기|기존 헤더의 PC·모바일 입력창이 검색어를 목록에 전달했다. 선공개 헤더에는 입력창이 없다. 검색 URL, 결과, 검색 해제는 작동한다.|**확인된 누락.** 게스트와 참여자 모두에게 기존 검색 입력을 연결하는 것이 우선이다.|
|무엇을 들을지 모르니 조건으로 찾기|장르·악기·분위기·용도·BPM, 전체 필터와 조건 초기화, 정렬, 페이지 이동. 전체 필터 안에서는 태그명·BPM 후보를 찾아 선택한다.|지원. 카탈로그 검색과 필터 내부 검색은 사용 목적이 다르다.|
|원하는 곡인지 확인하고 증빙 링크 전달|곡명 → 공개 상세에 설명·업로더·사이트 업로드일·BPM·조성·재생수·분류 표시. 직접 주소를 열고 재생할 수 있다. 모바일 목록의 분류는 곡명 아래로 이동한다.|지원. 발매일을 사이트 업로드일과 혼동하지 않아야 한다.|
|청취하면서 곡을 비교하기|재생/일시정지, 탐색, 이전/다음, 셔플·반복, 재생 큐와 플레이어의 ‘재생기록’ 창이 있다. 재생기록은 브라우저에 저장한다. 별도 회원 메뉴의 재생 이력 페이지, 좋아요·저장형 플레이리스트는 선공개에서 닫혀 있다.|청취 지원. 기기를 바꿔 확인하는 본인 다운로드·라이선스와 로컬 재생기록은 보관 장소가 다르다.|
|초대 계정 로그인 후 원본 받기|선공개 헤더의 로그인, 기존 비밀번호, 유효한 시험 자격, 공개곡 목록 행 또는 상세의 다운로드, 일반 사용자의 파일 저장이 필요하다. 한도/성공 피드백이 있다.|지원. 비로그인·관리자 화면만 보고 초대 사용자용 버튼 가시성을 판정하면 안 된다.|
|하단 플레이어에서 현재 곡 받기|기존 플레이어에는 다운로드가 있다. 선공개 플레이어는 로그인한 시험 사용자에게도 하단/확장 플레이어 다운로드를 제공하지 않는다.|**부분 차이.** 곡 목록·상세에서 받을 수 있다. 플레이어 안에서도 받을 필요가 있다면 사용자 전환 보호와 동일한 다운로드 검사를 연결한다.|
|나중에 원본 다시 받기|내 다운로드에서 검색·정렬·한도·한 곡씩 재다운로드, 라이선스 목록에서도 곡별 재다운로드가 가능하다.|지원. 한도 0에서도 기존 곡 재다운로드가 가능했던 통합 시험 근거가 있다.|
|받아 둔 곡의 라이선스 증빙|내 라이선스 → 상세에 전체 코드·회원·곡·발급일 표시. 판매 모드 모달의 전체 UUID 복사 버튼은 선공개 전용 상세 화면에서 사라진다.|**편의 차이.** 화면에서 전체 코드를 선택해 복사할 수 있다. 한 번 눌러 복사하려는 경우 별도 보완 대상이다.|
|이력에서 여러 곡 선택·재생하기|선택·전체 재다운로드와 썸네일에서 곧바로 재생하는 동선을 선공개에서 제한한다. 공개곡 제목을 열어 상세에서 들을 수 있다.|개인 이력의 공개 플레이어 전달 방지와 개별 받기 범위로 설명되는 차이다.|
|받았던 곡이 비공개가 됨|본인 이력·라이선스는 보존하고 곡의 정보를 ‘비공개 음원’으로 축소한다. 이력 제목 링크와 재다운로드 버튼은 계속 렌더되지만 서버가 새 상세 조회·파일 수령을 막는다.|**오해하기 쉬운 상태.** 사용 불가 안내와 버튼 표시를 맞추려면 서버가 현재 다운로드 가능 여부를 명시적으로 전달하는 방안을 검토한다.|
|한도 초과·만료·권한 회수·로그아웃|한도 초과는 전용 문구가 있다. 목록/곡 상세의 그 밖의 다운로드 오류는 일반 실패 문구로 모인다. 라이선스 목록에는 공개 상태·기간 확인 문구가 있다. 개인 이력·UUID 접근과 계정 교체는 별도 보호한다.|서버 차단·개인정보 분리와 화면의 이유 설명을 따로 판정한다.|
|가입·메일·결제·다른 회원의 문서 접근|직접 가입·복구 메일·결제·구독 구매는 후반 범위다. 본인의 파일 수령과 라이선스 확인에는 PG 결제·판매 메뉴를 열 필요가 없다.|보류 유지. 다른 회원의 라이선스는 조회 불가다.|

**복원 검증 순서.** 게스트·초대 로그인 각각 PC와 모바일에서 제목·용도 검색, 공백·무결과·검색 해제, 검색 결과와 태그·정렬·페이지 조합, 곡 상세를 거쳐 돌아오기 및 공유 URL 직접 열기를 확인한다. 검색 결과에서 공개곡만 보이고 게스트는 청취만, 유효한 시험 사용자만 원본을 받을 수 있어야 한다. UUID 복사와 플레이어 받기는 각각 별도 판단 항목이다.

운영 공개 페이지는 이번 조사에서 신규 Chrome 세션 1366px/390px로 확인했다. 106번 곡 검색 URL에서 결과와 모바일 너비의 검색 해제 동작, 임의의 무결과 검색, 로그인 양식 및 곡 상세 열기를 확인했다. 로컬 집중 시험은 9개 파일 91건 통과했다. 이 모바일 너비 관찰은 실제 휴대폰 OS의 다운로드·클립보드 시험을 대신하지 않는다. 개인 화면은 현재 소스와 기존 통합·운영 검증을 함께 참고했다.
