### 지인 시험에서 우선할 차이

1. **검색 입력 복원 권장.** 원래 곡명·용도 검색 제출 동작을 선공개 헤더에 연결한다. PC·모바일에서 각각 입력부터 106번 곡 상세 진입, 태그 조합·무결과·해제·뒤로 가기까지 확인한다. 공개곡 목록과 기존 다운로드 권한을 그대로 사용한다. 검색 제출 시 기존 필터 유지 여부는 원본 동작과 대조한다.
2. **라이선스 코드 복사 복원 권장.** 전용 상세에는 전체 UUID가 보이나 기존 판매 상세 모달에 있던 복사 버튼이 없다. 복사 편의만 복원하고 상세의 본인 확인을 유지한다.
3. **플레이어 다운로드는 별도 동선 선택.** 목록·곡 상세·개인 이력과 라이선스 목록에서는 받을 수 있다. 재생 중인 플레이어에서 바로 받아야 한다면 기존 버튼에 현재 시험 계정의 다운로드 권한·사용자 전환 처리를 연결해야 한다.
4. **공개해제와 만료를 설명하는 안내.** 비공개 음원 이력과 발급 사실은 보존된다. 제목 링크·재다운로드 버튼이 남아 실패할 때에는 이용자가 공개해제·만료·한도 원인을 구별할 수 있는지 확인한다. 이전 버전의 문구를 그대로 복원하는 것과 구분되는 UX 개선이다.
5. **운영자 문의 대응.** 관리자가 회원별 라이선스를 찾는 기능은 판매판에 있고 B1에서 닫혀 있다. 본인용 조회와 별도로 관리자 지원 범위를 결정할 수 있다. 지인 선공개의 기존 목적에는 가입·메일·PG, 회원 대량 조회, 채널 관리, CSV 또는 결제 운영 권한이 필요하지 않다.

### 검증 기록

운영 공개 화면을 비로그인 Chrome 1366px·390px에서 읽기 전용으로 확인했다. /tracks의 검색 입력은 양쪽 모두 0개였다. Forsaken 검색 URL에는 106번 결과가 나왔고, 일치하지 않는 문자열에는 빈 결과 안내와 해제 버튼이 나왔다. 390px에서 해제를 누르면 일반 목록으로 돌아왔다. 전체 필터 모달의 입력 안내는 ‘태그 이름으로 검색...’이었다. 이 관찰은 실제 휴대폰 키보드·파일 저장·클립보드 동작 검증과 구분한다.

현행 로컬 프론트엔드의 헤더·목록·상세·플레이어·관리자·개인 경로 관련 Vitest 9개 파일, 91개 시험 통과. 관리자·개인 권한과 실제 다운로드 근거는 이전 검증을 재사용했다. 운영 계정·권한·제품 코드·서버 설정을 변경하지 않았다.
