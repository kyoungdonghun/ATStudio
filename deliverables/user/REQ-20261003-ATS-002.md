# REQ-20261003-ATS-002: 클라이언트용 서버 결제 안내 PDF

[REQ]
REQ ID: REQ-20261003-ATS-002
Project: ATS
Owner: MA
Status: complete
Approval: 사용자가 앞서 제시한 결제 안내문에 대해 "pdf 로 하고, 클라이언트용이니까, 쉽게 표현해서 ㄱㄱ"로 제작을 승인함.

[GOAL / WHY]
- 비개발자가 목적, 결제 항목, 예상 월 비용, 선택 이유, 가입 후 할 일을 이해할 수 있는 한국어 A4 한 페이지 PDF.

[SCOPE]
- In: 직전 안내문을 쉬운 한국어로 정리, PDF 생성, 한글 폰트 포함, 렌더링/텍스트/비용 검증.
- Out: 제품/배포 문서 변경, 실제 구매/가입/외부 발송, 서버/DB/시크릿 작업.
- 한국어 PDF는 사용자가 명시한 클라이언트 전달용 문서이며 이번 요청에 한해 한국어로 작성한다.

[SUCCESS CRITERIA (DoD)]
- A4 정확히 1페이지, 한글 깨짐/겹침 없음, 링크 정상 포함.
- 월 53,020원 서버 및 평균 백업 50~100GB에 1,100~2,200원, 합계 54,120~55,220원(부가세 포함).
- 예상 비용 상한 아님, 별도 비용 및 사용량 가정/성능 미검증 구분.
- 가입만 요청하고 상품 생성/결제는 담당자 확인 후, 비밀번호 공유 금지.
