# REQ-20261011-ATS-005: 비공개 기동과 단계별 정리 진단

[REQ]
Project: ATS
Owner: MA
Status: completed / approved bounded scope
Approval: 사용자 “보완한 진단 코드로 실서버에서 비공개 기동·정리 검사를 한 번 다시 진행” 및 기존 비밀값·임시 에이전트 “이번 시험에 한해 승인”.

[GOAL / WHY]
- 새 1회 비공개 시험에서 실패 항목을 식별하고, 기동 결과와 정리 결과를 분리해 확인한다.

[SCOPE]
- In: WI029 진단 로직과 기존 WI026 실행 구성으로 새 식별자의 별도 실행본 준비, 로컬 시험, 독립 검토, 현재 서버 사전 검사, 공개 파일만 전달, 1회 기동·정리, 결과 기록.
- 기존 서버 atstudio-prod-01 / atadmin, 내부 DB atstudio_prod만 사용한다.
- 기존 서버 내부 DB 암호·JWT 키·결제정보 암호화 키는 출력·변경 없이 앱 내부에서만 사용한다.
- Windows SSH 에이전트는 이번 작업 동안만 활성화하고 사용자가 별도 창에서 기존 키 암호를 입력한다. 끝나면 이번 키만 제거하고 Stopped/Disabled 복귀한다.
- 앱은 기존 차단 검증 성공 후 최대180초, 조회만 수행한다. DB는 내부 접속용으로 일시 가동 후 중지·차단한다. 정상 기동의 로그·디렉터리·DB 엔진 기록은 포함한다.
- Out: 외부 공개, 방화벽/DNS 변경, 새 패키지·유료 상품, DB 구조·업무 데이터 변경, 비밀값 신규 생성·교체, 기록/파일 삭제, 재부팅, 자동 재시도, 커밋·푸시.
- 복구 경로를 확보하고, 검사 실패 시 앱 실행을 중지한다. 실행 중 정리 실패 시 우선 읽기 전용 상태 확인; 승인 밖 복구·수정은 별도 확인한다.
