# 지인 선공개 서버의 좋아요·재생목록 배포 준비

운영 중인 초대 명단 32명과 기존 화면 파일을 보존하는 배포본을 준비했습니다. 교체 중에는 기존 앱이 공개 음원 조회와 재생을 맡고, 데이터 변경과 다운로드는 잠시 대기합니다. 새 앱이 전체 공개곡 목록과 음원 구간 재생을 확인하면 새 화면으로 전환합니다.

로컬 배포 시험 7건과 프록시 경로 시험 2건이 통과했습니다. 11월 23일 23시 43분 운영 배포를 완료했습니다. 새 앱에서 공개곡 210곡과 기존 참가자 32명을 확인했고 DB는 같은 프로세스로 계속 작동했습니다. 외부 음원 구간 요청 15건이 모두 성공했습니다. 배포 후 설치 파일 전체를 다시 대조하고, 임시 공개 재생 경로가 종료된 것과 외부에서 새 화면이 열리는 것까지 확인했습니다. [검증 근거](../agent/WI-20261123-ATS-017-evidence-pack.md)
