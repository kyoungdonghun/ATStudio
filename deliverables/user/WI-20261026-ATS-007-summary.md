# 로컬 변경 보존 및 커밋 결과

검토한 소스·운영 도구·문서를 세 개의 로컬 커밋으로 보존했습니다. 이 문서는 마지막 마감 기록 커밋에 포함됩니다. 서버 작업이나 push는 하지 않았습니다.

| 묶음 | 실제 커밋 | 파일 수 |
|---|---|---:|
| 선택형 NCP 메일 소스·설정·테스트 | `f6742ff` | 7 |
| 운영 도구·설정·재사용 원본 | `254e2fe` | 168 |
| 검토된 문서·증거·클라이언트 자료 | `5134558` | 558 |

ignored build의 재사용 자료 73개는 원본 그대로, 13개는 대상 식별정보를 제거한 참고용으로 보존했습니다. 참고용 파일은 실행 도구를 대체하지 않습니다. 원본은 삭제하거나 덮어쓰지 않았고, 86개 보존 자료의 해시와 복원 경로를 확인했습니다.

개인정보·특정 환경 정보 등이 포함된 과거 텍스트 48개와 미검토 생성물 15개, 총 63개는 커밋에서 제외하고 로컬에 유지했습니다. 별도로 ignored 상태인 비밀값·JAR·실행 증거까지 Git에 들어갔다는 뜻은 아닙니다. 외부 백업이나 완전한 실행환경 복원을 완료한 것도 아닙니다.

현재 Java 관련 7개 파일은 기존 검토·검사 근거와 일치했습니다. 수정된 NCP 16개 검사와 앞선 변경 없는 26개 검사 결과를 재사용했으며, 전체 검사를 새로 실행했다고 보고하지 않습니다. Python 65개·JSON 36개·PowerShell 3개는 선택한 파일만 구문 검사했습니다. 매 커밋의 경로와 Git 저장 내용을 정확한 목록·해시로 대조했습니다.

보존 자료가 Git ignore에 걸린 문제는 해당 보존 폴더 안에서만 수정했습니다. 과거 원문의 CRLF·끝 빈 줄을 바꾸지 않도록 정확한 경로와 해시로 예외를 고정했고, 새 검사기·새 보고서의 불필요한 끝 빈 줄만 정리했습니다. 실패한 시도도 별도로 남겼습니다.

**현재 운영 2단계는 계속 진행 중입니다.** ID 1·2 관리자, ID 3 구매자 및 기존 적용 이용권 결과는 변경하지 않았습니다. 클라이언트 약관 결정과 NCP·Toss 가입/계약을 기다리고 있습니다. 메일 실제 전환, PG LIVE 검증, 3단계 운영 안전장치의 구현·실서버 검증은 남아 있습니다. 이번 작업에서는 새 기능이나 백업 도구 역할 가드도 수정하지 않았습니다.
