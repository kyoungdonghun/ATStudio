# WI-20260711-ATS-007 결과 요약

## TL;DR

화이트리스트 채널과 기업 인증 모두 핵심 순차 흐름은 설계, 구현, 클라이언트 문구가 대체로 맞습니다. 그러나 보안 및 상태 완결성 결함이 남아 있어 두 영역 모두 최종 판정은 **FAIL**입니다.

| 3-way 대상 | 최종 판정 | 핵심 사유 |
|---|---|---|
| 화이트리스트 채널 | **FAIL** | CSV 수식 주입 위험(P1), 해제 완료 상태 부재(P1), 한도/대표채널/내보내기 경쟁 조건(P2), 내보내기 범위 오인 및 복구 부재(P2) |
| 기업 인증 | **FAIL** | 확장자 중심 서류 검증으로 인한 악성 문서 위험(P1), 기존 DB 이관 불완전 가능성(P1 조건부), 개인 회원 화면 차단 누락 및 문서 접근 경계 공백(P2), 심사/재제출 경쟁 조건(P2) |

## 확인된 정합성

- 화이트리스트 상태 8개, 플랜 한도 산정 상태 5개, 초안 저장, 등록 요청, 처리 중 채널 재요청, 소유권 검사는 설계와 구현이 일치합니다.
- 등록 요청 한도에서 `REVISION_REQUESTED` 채널의 기존 슬롯을 제외하는 로직은 백엔드와 화면 계산에 모두 반영되어 있습니다.
- 기업 인증의 `PENDING -> APPROVED/REVISION_REQUESTED/REJECTED`, 사용자 재제출의 `REVISION_REQUESTED -> PENDING`, 반려 후 신규 신청, 승인 후 기업 구독 결제 게이트는 일치합니다.
- 기업 인증 관리자 API는 역할 제한이 있고, 문서 다운로드 시 인증 건과 문서 ID를 함께 검증합니다.
- JPA 엔티티 39개와 `schema.sql` 테이블 39개가 대응하며, 이번 WI 대상 5개 테이블은 모두 존재합니다.
- phase-1에서 고정한 클라이언트 문서와 PDF 해시는 변경되지 않았습니다.

## 즉시 조치가 필요한 항목

1. **P1 보안 - 화이트리스트 CSV 수식 주입**

   사용자 입력 셀은 CSV 따옴표 처리만 하며 스프레드시트 수식 시작 문자를 무력화하지 않습니다. 관리자가 파일을 열 때 관리자 단말 또는 외부 전달 대상에 영향을 줄 수 있습니다.

2. **P1 기능/정책 - 화이트리스트 해제 흐름 미완결**

   `REMOVAL_REQUESTED` 이후의 완료 상태가 없습니다. 이 상태는 플랜 슬롯을 계속 차지하며, 관리자가 해제 완료를 정확히 기록할 수 없습니다.

3. **P1 보안 - 기업 인증 악성 문서 업로드**

   서버는 개수, 파일 크기, 파일명 확장자만 확인하고 브라우저가 보낸 콘텐츠 타입을 저장합니다. 서버 측 파일 시그니처 확인, 격리, 악성코드 검사 없이 관리자가 다운로드하도록 되어 있습니다.

4. **P1 조건부 배포 - DB 이관 체인**

   최신 자식 문서 테이블 패치는 현재 JPA/신규 스키마와 맞지만, 저장소에는 전체 과거 DB를 최신 상태로 올릴 완전한 순서형 이관 체인이 없습니다. 기존 인증 파일 메타데이터를 현재 다운로드 모델로 복원하는 절차도 없습니다.

## 다음 조치

- 화이트리스트에 명시적 해제 완료 상태와 허용 전이표를 결정하고, 플랜 슬롯 해제 시점을 고정해야 합니다.
- CSV 셀 수식 무력화, 원자적 export claim, 페이지/청크 처리, 배치 재다운로드를 함께 구현해야 합니다.
- 대표채널과 플랜 한도는 사용자 단위 잠금 또는 DB로 강제 가능한 불변식으로 보호해야 합니다.
- 기업 인증 업로드는 서버 판별 MIME/시그니처, 격리 및 검사, 고정 다운로드 콘텐츠 타입을 도입해야 합니다.
- 기업 인증 화면은 `BUSINESS` 전용으로 선제 차단하고, 보완 요청/반려 사유를 필수화해야 합니다.
- 인증 서류의 보관 기간, 반려/탈퇴 시 삭제 기준, 다운로드/심사 감사 로그, 화이트리스트 외부 전달 컬럼과 보관 기간을 정책으로 승인해야 합니다.

## 검증 범위

실제 CSV 내보내기, 서류 업로드/다운로드, DB 변경, 상태 변경, 운영 데이터 조회는 수행하지 않았습니다. 현재 소스와 문서에 대한 정적·비파괴 검증만 수행했으며, 상세 근거와 집중 테스트 목록은 Evidence Pack에 기록했습니다.
