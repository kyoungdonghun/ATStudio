[GOAL / WHY]
- Inquiry(문의) 도메인 7개 API 전체 구현
- 사용자가 문의를 등록하고 어드민이 답변/상태 관리하는 CS 핵심 기능
- Question/QuestionAttachment 엔티티 + StorageService 인프라 이미 완비 → 비즈니스 로직 + 라우팅 구현에 집중 가능

---

[SCOPE]
- In:
  - **8.1** `POST /api/questions` — 문의 등록 (multipart: title, content, category, isPublic, attachments?)
  - **8.2** `POST /api/questions/{id}/answers` — 답변 작성 (문의자 or ADMIN, OPEN→IN_PROGRESS 자동 전환)
  - **8.3** `GET /api/questions` — 문의 목록 (일반: 공개+내것, ADMIN: 전체, category/status/mine 필터)
  - **8.4** `GET /api/questions/{id}` — 문의 상세 (비공개: 소유자+ADMIN만, answers 포함)
  - **8.5** `GET /api/questions/{id}/attachments/{attachmentId}` — 첨부파일 다운로드
  - **8.6** `PUT /api/questions/{id}/status` — 상태 변경 (ADMIN only, OPEN→IN_PROGRESS→RESOLVED→CLOSED)
  - **8.7** `DELETE /api/questions/{id}` — 문의 삭제 (소유자+OPEN 상태 only, 또는 ADMIN)
  - QuestionRepository, QuestionAttachmentRepository, QuestionAnswerRepository 신규 작성
  - QuestionService, QuestionController, 관련 DTO 신규 작성
- Out:
  - 결제/구독 관련 기능
  - 문의 수정 API (v3에서 제거됨)

---

[SUCCESS CRITERIA (DoD)]
- 7개 엔드포인트 명세서 응답 형식 충족
- 비공개 문의: 소유자+ADMIN만 조회 가능 → 403
- 어드민 첫 답변 시 OPEN → IN_PROGRESS 자동 전환
- 삭제 제약: 소유자이고 OPEN 상태일 때만, 또는 ADMIN
- 첨부파일: StorageService.store() 재사용, 다운로드는 presigned URL or stream
- `gradlew.bat test` → 전체 테스트 통과, 0 failures
