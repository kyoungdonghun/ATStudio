# Friends pilot scope and next implementation

The [roadmap and acceptance table](REQ-20261104-ATS-002.md#stage-b-rollout-2026-11-21) use the existing public listening catalog to decide which files an invited USER can download. New publication makes a track eligible. Unpublishing blocks new file requests, including repeat requests from a license or history page. Each participant can view their own history, licenses and issued codes.

Local implementation can begin with two synthetic users and timed nonbilling grants. Work through file authorization and record ownership, frontend and proxy changes, focused tests in pilot/listening/sales modes, and an Extra High independent review. Participant dates, limits and contact details are needed before real invitations. Signup, signup consent, production mail and payment stay in B2.
