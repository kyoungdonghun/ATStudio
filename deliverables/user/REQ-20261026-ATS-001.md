# REQ-20261026-ATS-001 로컬 변경 보존 및 작업별 커밋

[REQ]
Project: ATS
Owner: MA
Status: complete — 사용자가 2026-10-26 분류·비밀정보 확인, 재사용 도구 보존, 작업별 로컬 커밋까지 승인했다.

[GOAL / WHY]
클라이언트 답변 대기 시점의 소스·운영 도구·문서를 재현 가능한 중간 저장 지점으로 보존한다.

[SCOPE]
In: 누적 변경 분류, 원문을 노출하지 않는 비밀정보/개인정보 검사, 안전한 재사용 도구·문서의 버전 관리 보존, 필요한 최소 정리, 기존 결과 재사용과 집중 검증, 작업별 로컬 커밋 및 사후 확인.
Out: push/fetch/외부 공유, 서버/DB/앱/클라우드 작업, 비용·결제, 새로운 기능, 다음 백업 도구의 역할 가드 수정, 원본 증거 삭제/덮어쓰기, 무관한 변경 초기화, 비공개 본문 출력.

[SUCCESS CRITERIA]
변경마다 커밋/비공개 유지/생성물 보관 분류가 있다. 재사용 도구는 원본 핀과 재구성 경로를 보존한다. 검토한 정확한 경로만 stage하고 단계별 커밋한다. 잔여 변경과 미푸시 상태를 정확히 보고한다. 검증은 현재 소스/대상에 한정하며 서버 준비 완료로 확대하지 않는다.

[CONSTRAINTS]
기존 commit 금지는 이번 로컬 커밋 승인 범위에 한해 대체한다. 사용자 판단은 새로운 비용/범위/실제 민감정보 보관 방식 결정이 필요한 경우만 요청한다. 결과 불명 Git 쓰기는 읽기 전용으로 먼저 확인한다. git add . / add -A, 강제 push, reset/clean, 기존 커밋 amend 금지. 미추적 파일의 사용자 작업도 보존한다.
