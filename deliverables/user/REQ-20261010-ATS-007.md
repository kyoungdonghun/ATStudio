# REQ-20261010-ATS-007: 최초 서버 접속과 기본 실행 환경

[REQ]

[GOAL / WHY]
- 신청된 서버 1대의 신원을 검증하고 접속 잠금 위험 없이 기본 환경을 준비한다.
- 월 7만 원은 예산이며 과금 차단 한도가 아니다. 추가 유료 서비스는 먼저 설명하고 승인받는다.

[SCOPE]
- 대상은 현재 iwinv 콘솔에서 확인한 atstudio-prod-01, KR1-Z03, Ubuntu 24.04, 2vCPU/8GB/NVMe100GB 1대뿐이다. 주소와 호스트 지문은 공개 저장소에 기록하지 않는다.
- 콘솔 복구 경로, 독립 경로의 SSH 호스트 지문, 기존 승인 공개키 대응 확인, 사용자 직접 암호 입력 방식의 SSH 접속 확인.
- 접속 후 읽기 전용 OS/자원/포트/서비스 조사. 검토된 무료 배포판 패키지 Java17/MySQL8/Nginx/FFmpeg와 기본 운영 디렉터리, 최소 권한 서비스 사용자, 시간 및 로그 설정 준비.
- 변경 전 설정 보존, 검증 후 적용, 복구 접속 유지. SSH 및 방화벽의 구체적 변경은 실제 조사 후 별도 확인한다.
- 도메인 atmusic.co.kr 구매는 DNS/HTTPS 이전 추적 항목이다. 구매, DNS 변경, 인증서 발급은 이번에 자동 실행하지 않는다.
- 제외: 추가 결제, 서버 증설, 백업 저장소 개통/전송, 앱/메일/결제 실행, 공개 웹 포트 개방, DB/스키마/사용자 생성과 이관, 개인키/암호 열람, 새 시크릿 생성, 데이터 삭제, 자동 재부팅, 커밋/푸시.

[SUCCESS CRITERIA (DoD)]
- [x] 독립 콘솔 호스트 지문과 SSH 신원 확인 후 접속 성공.
- [x] 원격 OS/자원/서비스/포트 현황을 민감정보 없이 기록.
- [x] 검토된 기본 환경 적용과 연결 재검증, 또는 정확한 보류 원인 및 재개 절차 기록. WI021의 MA 최종 영수증으로 승인된 관리 계정·SSH·디렉터리·MySQL·journald·정리 확인 완료. OS 업데이트/재부팅과 배포 후속 게이트는 별도 미완료다.
- [x] 독립 절차 검토와 최신 진입 문서 갱신. 완료/미실행 범위 분리. 실제 호스트의 독립 검증 완료를 의미하지 않는다.

[CONSTRAINTS / POLICIES]
- 모든 변경은 WI 추적. MA는 스킬에 따른 오케스트레이션 문서와 명시적 사용자 승인 UI/접속 절차를 조정하고 구현 파일은 위임한다.
- 암호를 채팅/로그에 요청하지 않는다. 개인키는 PC 밖으로 복사하지 않는다. StrictHostKeyChecking 우회나 검증 없는 TOFU 승인 금지.

[2026-10-10 최신 실행 체크포인트: WI018]
- 검증일 2026-10-10, 대상은 승인된 기존 서버와 로컬 Windows 운영 환경, 실행·증거 소유자는 MA다. 위 최초 PROGRESS/RISKS 및 승인 당시 미실행 문장은 역사적 기록이며 이 체크포인트가 최신 상태다. SE/PG는 로컬 절차만 검토했고 DOCOPS는 MA 영수증을 문서화했다.
- 기존 서버 1대 구매 후 19:42 KST 추가 표시 비용 0원으로 승인된 재설치를 실행했다. 복구 콘솔 인증, 재설치 후 독립 Ed25519 비교·공개키 전사 해시 검사, 전용 로컬 신뢰 파일 생성 후 strict pin/BatchMode 네이티브 SSH 키 로그인과 반복 재접속 PASS. 사용자가 콘솔에서 초기 root 암호를 변경했고 MA가 성공을 확인했으며 암호는 읽거나 기록하지 않았다.

- 남은 작업: 별도 관리자·sudo 및 두 번째 접속 검증, SSH 강화, 서비스 사용자/디렉터리, 로그 보존, MySQL 튜닝. 현재 SSH 전역 설정은 root/password 로그인과 X11/agent/TCP forwarding을 허용하므로 공급자 SSH 소스 제한만으로 보안 구성이 완료됐다고 보지 않는다. 후속 정확한 변경 승인·검토 후 재개하며 기존 접속을 먼저 차단하지 않는다.
- 앱 DB/시크릿/기동, 도메인 구매→DNS/HTTPS, 백업/복원·알림·부하·운영 공개는 미완료. 추가 상품 구매·도메인 구매·앱 배포 없음. 서버 월53,020원(VAT 포함)은 기존 구매 금액이며 월70,000원은 예산이지 과금 차단 한도가 아니다.

[2026-10-10 후속 승인: 관리 계정과 SSH/운영 설정]
- 사용자: "오케이 그럼 별도 관리 계정으로 접속 확인하고, root·비밀번호 SSH 로그인 제한이랑 운영 디렉터리·로그·DB 설정까지 이어서 진행해줘. 추가 결제 필요한 건 먼저 말해주고."
