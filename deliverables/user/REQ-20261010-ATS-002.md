[SCOPE]
- In: 실제 메뉴/검색 화면 조회와 개인정보 없는 캡처, atmusic.co.kr 등록 가능 여부 및 현재 공개 가격/기간 조건 확인, 등록 명의/연락처/갱신/만료 알림 확인 안내.

- 접근 제한 때문에 확인하지 못한 신청 화면이나 조건은 상상하여 만들지 않고 문서에 구분한다.
- 한국어 PDF는 승인된 사용자 전달용 예외이다. 기술 기록은 영어로 작성한다.

[SUCCESS CRITERIA (DoD)]

- 정확한 도메인 철자, 등록 기간/부가세/갱신 비용과 최종 결제금액 확인 포인트를 구분한다.
- 가격 및 등록 가능 여부에는 조회일과 근거/한계를 표시한다. 가이드가 예약이나 구매를 의미하지 않는다.
- 계정명/개인 이메일/전화/주소/인증·결제정보 없는 캡처만 저장한다.
- 기존 PDF, 캡처, 생성 스크립트, 검증 자료를 보존한다.
