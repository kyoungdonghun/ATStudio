[GOAL / WHY]
- 친구 및 클라이언트가 iwinv 콘솔에서 서버 신청 위치와 선행 절차를 이해하도록 실제 화면 기반의 쉬운 한국어 PDF를 만든다.

[SCOPE]
- In: docs/client-guides/iwinv/ 새 폴더, 개인정보를 제외한 실제 화면 캡처, A4 PDF 1~2쪽, 짧은 보관/검증 기록.
- 내용: 콘솔 → 컴퓨트 → 가상 서버 → 생성하기 경로, 본인인증 및 카드등록 필요 안내, 사업자 정보 안내의 확인 범위, 담당자 확인 후 구매 원칙.
- Out: 실제 인증/약관 동의/카드등록/구매/서버생성, 애플리케이션 또는 배포 설정 변경, 새 가격/법률 판단, 기존 문서 덮어쓰기, 외부 발송.
- 한국어 PDF는 사용자에게 승인된 클라이언트용 산출물 예외이며 기술 보관 기록은 영어로 작성한다.

[SUCCESS CRITERIA (DoD)]
- 실제 콘솔 캡처를 포함한 A4 1~2쪽 PDF. 한글 폰트 포함, 텍스트/링크 검증 및 모든 페이지 시각 검증.
- 저장된 캡처와 PDF에 계정명, 이메일, 인증정보, 카드정보가 포함되지 않는다.
- 현재 화면에서 확인한 메뉴와 선행 절차를 구분하고, 확인하지 않은 카드등록 상세 화면/구매 완료를 만들어내지 않는다.
- 기존 비용 안내 PDF와 관련 없는 파일을 보존한다.
