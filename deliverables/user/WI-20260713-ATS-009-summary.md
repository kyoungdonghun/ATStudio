# WI-20260713-ATS-009 보안 검토 요약

## 판정

- 공개 원본 정적 경로, Track 응답, 스트림 Range, SMTP 로그를 다시 검토한 결과 P0 차단 조건을 충족한다.
- 보안 검토 중 `preview_file` 값 자체를 무조건 신뢰하면 원본 경로나 `../audio` 변형을 전용 미리듣기로 오인할 수 있는 위험을 보강했다.
- 이제 `tracks/preview/` 아래의 정규화된 별도 경로만 전용 미리듣기로 인정하고, 나머지는 제한 fallback 정책을 적용한다.
- 인코딩·경로 순회 형태의 `/uploads/tracks/audio` 접근은 리소스 해석 전에 `400` 또는 `403`으로 차단되는 테스트가 있다.
- 메일 로그에는 성공/실패 각각 `deliveryId`, 결과, 실패 시 예외 클래스만 남으며 수신자·본문·URL·토큰·예외 메시지는 없다.

## 검증

- 통합 집중 스위트: 133/133 통과
- `git diff --check`: 공백 오류 없음
- EmailService 민감 fallback 로그 패턴 검색: 0건

## 잔여 위험

- 전용 저용량 미리듣기 파일 생성기는 아직 없다. 현재는 원본 전체 노출을 막는 제한 구간 fallback으로 안전성과 기존 재생을 함께 유지한다.
- 기존 원본 파일의 물리적 이동은 이번 범위가 아니며 별도 승인 대상이다.
