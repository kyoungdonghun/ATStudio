# WI-20260809-ATS-060 결정 요약

> 목적: 사용자 승인된 ID·동의·세션·복귀 경로·로그아웃 정책을 구현 전 결정으로 확정한다.

## 승인 결정

- 가입에는 이용약관과 개인정보 수집·이용 동의를 각각 받아야 하며, 마케팅 동의는 선택 및 독립 항목이다. 보관 범위는 사용자 ID, 정책 유형·버전, 동의 시각이며 IP·기기 지문은 추가하지 않는다.
- 미인증 계정에는 인증 세션을 발급하거나 저장하지 않는다. 올바른 자격 증명은 이메일 인증 안내와 재발송 흐름으로만 이어지며 보호 기능을 제공하지 않는다.
- 로그인 복귀 경로는 같은 애플리케이션의 경로와 쿼리만 유지한다. 허용되지 않거나 접근할 수 없는 값은 현재 역할·사용자 유형 확인 후 `/`로 보낸다.
- 로그아웃은 먼저 `POST /api/auth/logout`을 시도한다. `204`와 계약상 확인된 이미 무효·철회된 세션만 서버 철회 성공이며, 그 밖의 완료된 실패는 로컬 세션을 정리하고 이동하되 서버 철회 미확인 안내를 표시한다. 호출자는 완료를 기다리고 중복 실행을 막는다.

## 현재와 이후 경계

- 이번 WI는 결정 기록만 완료했다. 소스, DB 스키마, API, 테스트, 런타임 또는 제품 동작 변경은 없고 외부 효과도 없다.
- 동의 저장 구조, 미인증 세션 차단, 로그아웃 호출자 보정은 이후 별도 구현 WI에서 처리한다. DB 스키마 구현은 별도 명시적 스키마 변경 승인이 있기 전까지 보류한다.
- P1 보정 세 건은 반영되었고, 독립 QA 통합 R2 검토는 최종 `PASS`다. 문서 검증과 `git diff --check`도 통과했다.

## 후속 및 되돌리기

- 이 결정은 `WI-042`, `WI-072`, `WI-077`의 선행 조건이다. 해당 작업은 별도 승인과 구현·검증 완료 후 진행한다.
- 되돌리기는 소스 제어에서 이 두 문서만 되돌리는 방식이며, 런타임 또는 외부 상태를 되돌릴 작업은 없다.
