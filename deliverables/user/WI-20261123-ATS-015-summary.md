# 지인 두 계정의 좋아요·재생목록 검증

로컬 Spring 서버와 시험 DB에서 두 계정으로 각각 로그인해 좋아요·해제, 첫 재생목록 생성, 담기·순서 변경·제거, 다시 로그인한 뒤 저장된 곡 재생을 확인했습니다. 한 계정은 다른 계정의 목록을 열거나 변경할 수 없었습니다. 공개를 해제한 곡은 좋아요와 목록에서 사라졌고, 새 재생 요청도 차단됐습니다.

기존 다운로드·라이선스 회귀를 포함한 Spring 시험 66건과 프록시 설정 검사 2건이 통과했습니다. 운영 서버에 반영하기 전 실제 nginx 설정 검사와 배포 후 접근 확인이 남습니다. [시험과 적용 범위](../agent/WI-20261123-ATS-015-evidence-pack.md)
