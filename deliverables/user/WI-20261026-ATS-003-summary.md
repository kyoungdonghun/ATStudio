# 클라이언트 답변 대기 중 로컬 준비 완료

**정책 답변과 가입을 기다리는 동안 진행할 수 있는 준비 3가지를 완료하고 검토했습니다.** 서버에는 접속하지 않았습니다.

| 완료한 준비 | 결과와 다음 연결 |
|---|---|
| 운영 안전장치 점검 | 기존 운영 소스 11개·보존 JAR 일치 PASS. 과거 백업·TLS 성공을 재사용하고 새 백업, 정기 실행·알림, 전체 복구·앱 재부팅 검증의 남은 범위를 분리했습니다. |
| 개인정보 처리 흐름 정리 | 14개 흐름의 입력·저장·외부 전달·탈퇴 처리를 확인했습니다. 개인정보는 남고 다운로드·라이선스는 삭제되는 현재 동작을 기준으로, 정책 확정 뒤 바꿀 부분과 집중 검사 8개를 정리했습니다. |
| 사용자 시험 준비 | 실제 PC·모바일의 화면·탐색·재생·권한 확인 시험표와 안전한 오류 기록 양식을 만들었습니다. 기존 1단계 전체를 반복하는 계획이 아닙니다. |

**다음 우선 작업은 기존 백업 도구의 로컬 호환 보완입니다.** 성공한 도구가 예전 ID1=USER와 과거 감사행 수를 기대하므로 현재 ADMIN 상태에 그대로 실행할 수 없습니다. 원본은 보존하고 현재 역할·이용권·감사 기록을 정확히 검증하는 최소 파생본을 만들어 집중 검사·독립 검토한 뒤 서버 접근을 준비해야 합니다. 이번에는 문제와 수정 범위까지 확정했으며 도구를 고치거나 새 백업을 실행하지 않았습니다.

Toss 유지 결정은 확정으로 기록했습니다. **KG이니시스로 전환할 개발은 제외**하며 클라이언트에게 PG 선택을 다시 묻지 않습니다. 기존 PDF는 당시 자료로 보존합니다. 상품·환불·기존 콘텐츠 사용권 등 남은 정책 답변과 NCP/Toss 가입·계약은 계속 기다립니다.

현재 ID1·2는 관리자이므로 ID1을 이용권 없는 구매자 차단 시험에 쓸 수 없습니다. 시험표에 이 역할 변화를 반영했고, ID3의 폐기된 이전 비밀번호도 재사용하지 않습니다.
