[GOAL / WHY]
- Whitelist Channels 도메인 4개 API 전체 구현
- 구독자가 음원 사용 예정인 유튜브 채널 URL을 등록/관리하는 기능
- 초기 버전: URL 수집 + 수동 검증 방식 (아티스트/운영자가 모인 채널 목록을 보고 Content ID 화이트리스트 처리)
- WhitelistChannel 엔티티 + DB 테이블 이미 완비 → Repository/Service/Controller/DTO 구현에 집중

---

[SCOPE]
- In:
  - **12.1** `POST /api/whitelist-channels` — 채널 등록 (channelUrl + channelName, 구독자만)
  - **12.2** `GET /api/whitelist-channels` — 내 채널 목록 조회
  - **12.3** `PUT /api/whitelist-channels/{channelId}` — 채널 정보 수정 (소유자만)
  - **12.4** `DELETE /api/whitelist-channels/{channelId}` — 채널 삭제 (소유자만)
  - WhitelistChannelRepository, WhitelistChannelService, WhitelistChannelController, 관련 DTO 신규 작성
  - WhitelistChannelServiceTest, WhitelistChannelControllerTest 신규 작성
- Out:
  - 관리자/아티스트 전체 채널 목록 조회 API (초기 버전 미구현 — 운영자가 DB 직접 조회)
  - 유튜브 OAuth 채널 소유 인증 (초기 버전 미구현)
  - Content ID 화이트리스트 실제 처리 (외부 유통사 연동 — 운영 영역)

---

[SUCCESS CRITERIA (DoD)]
- 4개 엔드포인트 API 명세서 응답 형식 충족
- channelUrl 검증: `youtube.com` 포함 여부 체크, 미포함 시 400 INVALID_ARGUMENT
- 구독 상태 체크: 비구독자 등록 시도 시 403
- 채널 한도 체크: `subscriptions.max_whitelist_channels` 초과 시 403 WHITELIST_CHANNEL_LIMIT_EXCEEDED
- 소유자 체크: 타인 채널 수정/삭제 시 403
- `gradlew.bat test` → 전체 테스트 통과, 0 failures
