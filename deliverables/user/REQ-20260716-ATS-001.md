[GOAL / WHY]
- 클라이언트 시연 화면과 실제 사용자 접점에 노출되는 기존 브랜드명 `ATStudio`를 새 브랜드명 `AT.M`으로 통일한다.
- URL이나 내부 식별자까지 변경하는 대규모 리네이밍은 피하고, 현재 캡처와 사용 경험에 직접 영향을 주는 표시 문구를 우선 정리한다.

[SCOPE]
- In:
  - React SPA의 공개·인증·관리자 화면에 표시되는 브랜드명
  - 브라우저 탭 제목과 접근성상 사용자에게 읽힐 수 있는 브랜드 문구
  - 이메일 제목·본문 기본값과 Toss 결제 상품명 등 사용자 또는 운영자에게 노출되는 브랜드 문구
  - 신규 초기화 시 사용되는 공지 seed의 브랜드 문구
  - 관련 회귀 테스트와 현재 클라이언트 시연 서버 반영
- Out:
  - 저장소·폴더·Java package/class·Spring application name·npm package name
  - URL, 도메인, 이메일 주소, 환경변수, DB명, 스키마명, 내부 HTTP header
  - 암호화 호환성을 가지는 associated-data 문자열
  - 기존 DB에 이미 저장된 공지 데이터의 직접 수정
  - 로고 이미지 제작 또는 전면 디자인 개편

[SUCCESS CRITERIA (DoD)]
- 활성 SPA의 헤더, 관리자 헤더, 로그인·회원가입, 홈 푸터와 브라우저 탭에 `AT.M`이 표시된다.
- 이메일 및 Toss 사용자 노출 문구에 새 브랜드명이 사용된다.
- 활성 사용자 노출 소스에는 의도하지 않은 `ATStudio` 표시 문구가 남지 않는다.
- 내부 식별자와 URL은 변경되지 않으며 기존 호환성이 유지된다.
- 프론트 typecheck, lint, test, build와 백엔드 관련 테스트 또는 컴파일 검증이 통과한다.
- 클라이언트용 공개 URL에서 `AT.M` 표시를 확인한다.

[CONSTRAINTS / POLICIES]
- Work tracking unit: WI
- 사용자가 승인한 표시 브랜드 변경 외 기능·정책·디자인은 변경하지 않는다.
- 기존 DB 데이터 수정은 별도 승인 없이는 수행하지 않는다.
- 런타임 로그와 비밀값은 stage 또는 문서화하지 않는다.
