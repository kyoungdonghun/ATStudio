# 1. 빠른 체크리스트

> 목적: 전체 테스트 전에 큰 문제가 있는지 짧게 먼저 확인합니다.

## 표시 방법

| 표시 | 의미 |
|------|------|
| 통과 | 기대한 대로 동작함 |
| 실패 | 깨졌거나 명확히 헷갈림 |
| 보류 | 계정, 데이터, 설정이 없어 확인하지 못함 |

실패 항목은 [SR 작성 양식](4-sr-format.md)에 맞춰 남겨주세요.

## 1. 기본 접속

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 테스트 주소를 연다. | 홈 화면이 오류 없이 열린다. |
| 홈, 음원, 앨범, 구독, 공지로 이동한다. | 화면 이동이 자연스럽고 상단 메뉴가 계속 보인다. |
| PC와 모바일 크기로 본다. | 글자와 버튼이 겹치지 않는다. |
| 없는 주소를 열어본다. | 알기 쉬운 오류 화면이 나온다. |

## 2. 계정

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 개인 회원으로 가입한다. | 가입이 완료되거나 부족한 입력값을 알려준다. |
| 기업 회원으로 가입한다. | 회사 정보 입력란이 나오고 가입할 수 있다. |
| 로그인하고 로그아웃한다. | 메뉴와 접근 권한이 상태에 맞게 바뀐다. |
| 프로필을 연다. | 내 정보가 보이고 수정할 수 있다. |

## 3. 음원과 콘텐츠

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 음원 목록을 연다. | 목록 또는 빈 상태 안내가 나온다. |
| 곡 제목으로 검색한다. | 데이터가 있으면 맞는 곡이 나온다. |
| 제목 아래 용도/가이드 문구로 검색한다. | 데이터가 있으면 맞는 곡이 나온다. |
| 음원이나 앨범을 누른다. | 상세 화면이 열린다. |
| 음원을 재생한다. | 하단 플레이어가 나오고 조작할 수 있다. |

## 4. 구독

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 구독 플랜을 연다. | 개인/기업, 월간/연간 선택이 이해된다. |
| 새 구독을 시작한다. | Toss 카드 정기결제 등록 흐름으로 이동한다. |
| 구독 후 내 구독 화면을 연다. | 현재 플랜, 결제 주기, 만료일, 결제수단 상태가 보인다. |
| 상위 플랜으로 바꿔본다. | 즉시 결제할 차액을 먼저 보여준다. |
| 하위 플랜으로 바꿔본다. | 다음 결제일부터 적용된다고 보여준다. |
| 구독을 취소한다. | 만료일까지 이용 가능하고, 만료 전에는 다시 유지할 수 있다. |

## 5. 화이트리스트 채널

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 화이트리스트 채널 화면을 연다. | 채널명, 유튜브 핸들, 채널 링크, 채널 ID 입력란이 보인다. |
| 채널을 저장한다. | 관리자 처리 없이 내 목록에 저장된다. |
| 대표 채널을 설정한다. | 대표 채널이 하나만 표시된다. |
| 등록 요청을 한다. | 구독 한도 안이면 요청/처리 상태로 바뀐다. |

## 6. 기업 인증

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 기업 회원으로 기업 인증 화면을 연다. | 구독 전에도 신청할 수 있다. |
| 서류를 제출한다. | 심사 중 상태가 된다. |
| 관리자가 보완 요청한다. | 사용자가 사유를 보고 새 서류를 제출할 수 있다. |
| 관리자가 승인한다. | 승인 상태가 보이고 기업 구독을 진행할 수 있다. |

## 7. 관리자

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 관리자 계정으로 로그인한다. | 관리자 메뉴가 열린다. |
| 대시보드, 회원, 음원, 앨범, 태그, 구독 화면을 연다. | 각 화면이 오류 없이 열린다. |
| 결제 운영 화면을 연다. | 주문, 자동결제, 결제내역, 대사, 영수증, 감사로그, 정산, 환불, 권한 보정 탭이 보인다. |
| 화이트리스트 운영 화면을 연다. | 요청 조회, CSV 내보내기, 상태 변경을 할 수 있다. |
| 기업 인증 운영 화면을 연다. | 제출 서류를 확인하고 심사 상태를 바꿀 수 있다. |
