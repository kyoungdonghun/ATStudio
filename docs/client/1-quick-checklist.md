# 빠른 점검표

약 20~30분 동안 핵심 흐름을 확인하는 목록입니다.

## 접속과 계정

- [ ] 운영 담당자가 준 주소가 열립니다.
- [ ] 일반 계정으로 로그인하고 새로고침해도 로그인 상태가 유지됩니다.
- [ ] 로그아웃 뒤 보호 화면에 다시 들어가면 로그인 화면으로 이동합니다.
- [ ] 관리자 계정은 사용자 결제 화면 대신 관리자 결제 화면으로 이동합니다.

## 음악과 앨범

- [ ] 로그인하지 않아도 음악 목록과 상세 화면이 열립니다.
- [ ] 공개 음악을 처음부터 끝까지 들을 수 있습니다.
- [ ] 검색, 태그, 페이지 이동 뒤 최신 조건의 결과가 보입니다.
- [ ] 앨범 목록과 상세 화면이 열립니다.

## 재생 기록과 좋아요

- [ ] 음악이 실제 재생된 뒤 재생 기록에 나타납니다.
- [ ] 같은 음악을 다시 재생하면 중복 대신 최신 위치로 이동합니다.
- [ ] 재생 기록을 지우면 현재 브라우저에서 사라집니다.
- [ ] 좋아요 추가와 해제가 정상 동작합니다.

## 구독과 결제

- [ ] 요금제 목록과 월간/연간 금액이 보입니다.
- [ ] 새 구독은 Toss 테스트 카드 등록과 첫 결제 성공 뒤 활성화됩니다.
- [ ] 결제수단 다시 등록 화면에는 즉시 결제가 없다는 안내가 보입니다.
- [ ] 다시 등록 뒤 현재 요금제와 만료일이 바뀌지 않습니다.
- [ ] 구독 해지 뒤에도 기존 만료일까지 이용 가능하다고 표시됩니다.

## 구독자 기능

- [ ] 재생목록을 만들고 음악을 추가할 수 있습니다.
- [ ] 재생목록 화면의 만들기 버튼을 누르면 새 재생목록 만들기 창이 열립니다.
- [ ] 구독 권한이 있는 계정만 공식 다운로드를 할 수 있습니다.
- [ ] 다운로드 기록과 라이선스를 확인할 수 있습니다.

## 사업자와 관리자

- [ ] 사업자 계정에서 기업 인증 신청/상태 화면이 열립니다.
- [ ] 관리자 대시보드에 회원, 음악, 구독자 수와 최근 회원이 표시됩니다.
- [ ] 관리자 사이트 설정에서 기업 인증 안내문을 불러오고 저장할 수 있습니다.
- [ ] 관리자 결제 화면의 주문, 자동결제, 결제내역, 사고, 영수증, 감사, 정산, 환불, 권한 보정 탭이 열립니다.

## 결과

- [ ] 치명적인 진행 중단이 없습니다.
- [ ] 발견한 문제를 문제 제보 양식으로 기록했습니다.
- [ ] 확인하지 못한 항목과 필요한 환경을 따로 적었습니다.
