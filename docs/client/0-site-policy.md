# 0. 사이트 정책 구조

## 0.1 사용자 역할 (3계층)

| 역할 | 설명 | 접근 범위 |
|------|------|----------|
| **비회원 (Guest)** | 로그인하지 않은 방문자 | 음원 검색/스트리밍, 앨범 열람, 공지사항, 구독 플랜 페이지 |
| **회원 (User)** | 일반 가입자 | 비회원 기능 + 좋아요, 프로필, 문의, 재생기록, 구독 가입 |
| **관리자 (Admin)** | 사이트 운영자 | 모든 기능 + 음원/앨범 관리, 사용자 관리, 태그 관리, 기업인증 심사, 사이트 설정 |

## 0.2 사용자 유형 (2종)

| 유형 | 설명 | 차이점 |
|------|------|--------|
| **개인 (Individual)** | 개인 크리에이터/사용자 | 기본 가입 유형 |
| **기업 (Business)** | 사업자등록번호 보유 기업 | 기업용 플랜 구독 전 기업 인증 승인 필요 |

- 회원가입 시 유형을 선택합니다.
- 기업 회원은 **프로필 > 기업 인증 관리**에서 서류를 제출하고 관리자 심사를 받아야 합니다.
- 기업 회원은 기업 인증이 승인된 뒤에만 기업용 구독 결제가 가능합니다.

## 0.3 구독 체계 (3단계 x 2유형)

### 개인 회원 플랜

| 플랜 | 일 다운로드 한도 | 재생목록 | 화이트리스트 채널 | 우선 지원 |
|------|------------------|----------|-------------------|-----------|
| **스탠다드** | 5곡 | 3개 | 1개 | X |
| **디럭스** | 20곡 | 10개 | 2개 | X |
| **프리미엄** | 무제한 | 10개 | 2개 | O (72시간 내) |

### 기업 회원 플랜

| 플랜 | 일 다운로드 한도 | 재생목록 | 화이트리스트 채널 | 우선 지원 |
|------|------------------|----------|-------------------|-----------|
| **스탠다드** | 10곡 | 3개 | 1개 | X |
| **디럭스** | 50곡 | 10개 | 2개 | X |
| **프리미엄** | 무제한 | 10개 | 2개 | O (72시간 내) |

**구독 정책:**
- **플랜명**: 현재 UI는 `스탠다드 / 디럭스 / 프리미엄` 3단계를 사용하며, 개인/기업 탭으로 나뉩니다.
- **업그레이드**: 즉시 적용, 차액 결제
- **다운그레이드**: 현재 결제 기간 종료 후 적용
- **취소**: 만료일까지 서비스 유지, 이후 자동 만료
- **비구독자**: 음원 스트리밍은 가능하나 다운로드/재생목록/화이트리스트 채널 불가
