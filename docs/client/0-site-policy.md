# AT.M 서비스 정책 요약

## 서비스 역할

- 비로그인: 공개 음악/앨범/공지/요금제를 볼 수 있고 음악을 전체 재생할 수 있습니다.
- 일반 회원: 프로필, 좋아요, 재생 기록, 문의를 사용할 수 있습니다.
- 구독 회원: 요금제 권한에 따라 재생목록, 다운로드, 라이선스, 화이트리스트 기능을 사용합니다.
- 사업자 회원: 기업 인증 승인 뒤 필요한 구독/사업자 기능을 사용합니다.
- 관리자: 회원, 음악, 구독, 결제, 화이트리스트, 기업 인증, 문의, 공지, 사이트 설정을 운영합니다.

## 음악 이용

공개 음악은 누구나 전체 재생할 수 있습니다. 다운로드는 구독 권한과 일일 한도를 따르며, 다운로드 시 사용 라이선스가 발급됩니다. 공개 재생과 다운로드 권한은 별개입니다.

## 재생 기록

현재 재생 기록은 브라우저에 최대 100곡 저장됩니다. 다른 기기와 자동 동기화되지 않고, 브라우저 데이터를 지우면 사라질 수 있습니다. 예전 서버 재생 기록 기능과 연결되지 않습니다.

## 구독과 자동결제

- 신규 구독은 Toss 카드 등록과 첫 결제가 성공한 뒤 시작됩니다.
- 결제수단 다시 등록은 0원 등록이며 즉시 결제나 요금제 변경이 없습니다.
- 상위 요금제는 차액 결제 뒤 즉시 적용됩니다.
- 하위 요금제와 결제 주기 변경은 다음 갱신일부터 적용됩니다.
- 구독 해지는 다음 자동결제를 멈추고 만료일까지 이용권을 유지합니다.
- 회원 탈퇴는 자동결제를 막지만 자동 환불하지 않습니다.

예전 일회성 구독 결제 주소는 호환을 위해 실패 안내만 남아 있습니다. 현재 화면은 사용하지 않으며, 오래된 호출이 없다는 근거와 별도 승인 없이 제거하지 않습니다.

## 개인정보와 파일

비밀번호, 인증번호, 결제 키, 카드번호, 내부 저장 경로는 사용자/관리자 화면에 노출하지 않습니다. 기업 인증 문서는 관리자 권한 확인 뒤 내려받습니다. 자동 보존기간 삭제와 악성파일 검사는 아직 정책 검토 중입니다.

## 현재 확인 경계

소스와 자동 테스트가 통과해도 실제 결제사 키, 유지 중인 DB 이전, 운영 프록시/CORS, 모니터링, 클라이언트 최종 승인은 별도 확인이 필요합니다. 공개 개발 서버는 운영 담당자가 안전한 의존성 상태 또는 접근 제한 방식을 확인한 경우에만 사용합니다.
