# 문제 제보 양식

문제 하나당 제보 하나를 작성합니다.

## 제목

`[화면 이름] 무엇을 했을 때 어떤 문제가 발생함`

예시: `[구독 관리] 결제수단 다시 등록 뒤 기존 요금제가 보이지 않음`

## 기본 정보

- 테스트 날짜와 시각:
- 테스트 주소:
- 계정 종류: 비로그인 / 개인 / 사업자 / 관리자
- 브라우저와 기기:
- 네트워크: 회사 / 집 / 모바일 등

## 재현 순서

1. 어느 화면에서 시작했는지 적습니다.
2. 누른 버튼이나 입력한 값을 순서대로 적습니다.
3. 문제가 나타난 순간을 적습니다.

## 기대한 결과

정상이라면 무엇이 보여야 하는지 한두 문장으로 적습니다.

## 실제 결과

실제로 무엇이 보였는지 적습니다. 오류 문구는 가능한 한 그대로 적되 비밀번호, 인증번호, 카드 정보, 토큰은 지웁니다.

## 자료

- 화면 캡처 또는 짧은 영상
- 발생 시각
- 관련 항목 ID(화면에 보이는 경우)

## 심각도 제안

- 차단: 다음 단계로 갈 수 없고 우회 방법이 없음
- 높음: 결제, 권한, 개인정보, 데이터 손상 위험
- 보통: 주요 기능이 잘못되지만 우회 가능
- 낮음: 문구, 정렬, 작은 화면 표시 등

## 확인 불가

필요한 계정, 결제사 설정, 유지 DB, 운영 서버 권한이 없어 확인하지 못했다면 그 이유를 적습니다. 확인 불가는 정상 판정이 아닙니다.
