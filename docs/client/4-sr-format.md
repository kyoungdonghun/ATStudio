# 4. SR 작성 양식

> 목적: 문제를 다시 확인하고 바로 작업할 수 있게, 짧지만 필요한 정보는 빠짐없이 남깁니다.

## 복사해서 쓰는 양식

```markdown
## 제목

문제를 한 줄로 적어주세요.

### 위치
- 화면:
- 주소:

### 재현 방법
1.
2.
3.

### 기대한 동작

### 실제 동작

### 중요도
- Blocker / High / Medium / Low

### 첨부
- 스크린샷 또는 영상

### 비고
```

## 중요도 기준

| 중요도 | 언제 쓰나요? |
|--------|--------------|
| Blocker | 테스트를 더 진행할 수 없거나 로그인/결제/관리자 접근/데이터 안전 문제가 있을 때 |
| High | 주요 기능이 동작하지 않거나 잘못된 결과를 만들 때 |
| Medium | 기능은 되지만 흐름, 문구, 화면이 헷갈릴 때 |
| Low | 오탈자, 간격, 색상, 작은 사용성 개선일 때 |

## 작성 예시

```markdown
## 구독 취소 후 다시 유지하기 버튼이 보이지 않음

### 위치
- 화면: 내 구독 관리
- 주소: /subscriptions/manage

### 재현 방법
1. 구독 중인 계정으로 로그인한다.
2. 내 구독 관리 화면으로 이동한다.
3. 구독 취소를 누른다.
4. 다시 내 구독 관리 화면을 확인한다.

### 기대한 동작
만료일까지 이용 가능하다는 안내와 함께 구독 유지하기 버튼이 보여야 한다.

### 실제 동작
취소 상태만 보이고 다시 구독을 유지할 수 있는 버튼이 보이지 않는다.

### 중요도
High

### 첨부
- screenshot.png
```

## 작성 팁

- 하나의 SR에는 하나의 문제만 적어주세요.
- 같은 문제가 여러 화면에서 나오면 한 SR에 화면 목록을 같이 적어도 됩니다.
- 스크린샷에는 실제 개인정보, 카드번호, 회사 서류, 비밀번호, 시크릿 값이 나오지 않게 해주세요.
