# 4. SR (수정 요청) 문서 양식

### 4.1 SR이란?
**SR (Specification Request)** = 테스트 중 발견한 버그, 개선 사항, 기능 요청을 정형화한 문서입니다.

### 4.2 접수 원칙

- **SR 번호는 비워두세요.** 최종 번호(`SR-91` 같은 형식)는 운영 측에서 부여합니다.
- **완벽한 분석보다 재현 가능한 사실이 우선입니다.** 원인 추정보다 현상/기대 동작/재현 방법을 적어주세요.
- **최소 4가지는 꼭 포함해주세요.**
  - 사용 기기/브라우저
  - 발생한 페이지 또는 경로
  - 현재 동작
  - 다시 해보는 방법
- 스크린샷, 짧은 영상, 콘솔 오류 문구가 있으면 같이 보내주세요.

### 4.3 SR 문서 양식

```markdown
# SR-XX 제목 (간결하게, 무엇이 문제인지)

## 분류
- [ ] 버그 (Bug)
- [ ] 개선 (Enhancement)
- [ ] 기능 요청 (Feature Request)
- [ ] UI/UX 개선

## 우선순위
- [ ] HIGH (서비스 이용 불가)
- [ ] MEDIUM (불편하지만 우회 가능)
- [ ] LOW (개선하면 좋음)

## 환경
- 기기: (예: 갤럭시 S24, iPhone 15, PC Chrome 등)
- OS: (예: Android 14, iOS 17, Windows 11)
- 브라우저: (예: Chrome 120, Safari 17)
- 페이지/경로: (예: `/tracks`, 앨범 상세, 플레이어바)
- 계정 상태: (예: 비로그인 / 일반회원 / 스탠다드 구독 / 관리자)

## 현상
현재 어떻게 동작하는지 구체적으로 설명합니다.
(가능하면 스크린샷 첨부)

## 기대 동작
올바르게 동작해야 하는 방식을 설명합니다.

## 재현 방법
1. OO 페이지에 접속
2. OO 버튼 클릭
3. OO 입력 후 제출
4. → 여기서 문제 발생

## 비고
추가 의견이나 참고사항이 있으면 작성합니다.
```

### 4.4 SR 작성 예시

```markdown
# SR-XX 회원가입 시 전화번호 하이픈 없이 입력하면 에러 발생

## 분류
- [x] 버그 (Bug)

## 우선순위
- [ ] HIGH
- [x] MEDIUM
- [ ] LOW

## 환경
- 기기: 갤럭시 A17
- OS: Android 16
- 브라우저: 카카오톡 인앱 브라우저
- 페이지/경로: /signup
- 계정 상태: 비로그인

## 현상
회원가입 페이지에서 연락처에 "01012345678"을 입력하면
자동으로 "010-1234-5678"로 변환되어야 하는데,
변환이 되지 않고 "올바른 전화번호 형식을 입력해주세요" 에러가 발생합니다.

## 기대 동작
숫자만 입력해도 자동으로 하이픈이 추가되어야 합니다.

## 재현 방법
1. /signup 페이지 접속
2. 연락처 필드에 "01012345678" 입력
3. "가입하기" 클릭
4. → 에러 메시지 발생

## 비고
PC Chrome에서는 정상 동작합니다. 모바일 인앱 브라우저에서만 발생합니다.
```
