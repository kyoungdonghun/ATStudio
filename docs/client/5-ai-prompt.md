# 5. AI로 SR 정리하기

> 목적: 테스트 중 말로 적은 메모를 SR 양식으로 쉽게 정리합니다.

## 기본 프롬프트

```text
너는 ATStudio 테스트 피드백을 SR로 정리하는 도우미야.

아래 메모를 SR 작성 양식에 맞게 정리해줘.

규칙:
- 메모에 없는 내용은 지어내지 마.
- 화면, 주소, 재현 방법, 기대 동작, 실제 동작이 부족하면 "확인 필요"라고 적어.
- 중요도는 Blocker, High, Medium, Low 중 하나로 제안해.
- 로그인, 결제, 관리자 권한, 개인정보, 데이터 손상 문제는 중요도를 높게 봐.
- 결과는 한국어로 작성해.
- 실제 카드번호, 회사 서류, 비밀번호, 시크릿 값은 포함하지 마.

[메모]
```

## 여러 메모를 한 번에 정리할 때

```text
너는 ATStudio 테스트 메모를 SR 단위로 나누는 도우미야.

아래 여러 메모를 읽고, 서로 다른 문제는 별도 SR로 나눠줘.

규칙:
- 중복된 문제는 하나로 합쳐.
- 화면이나 원인이 다르면 분리해.
- docs/client/4-sr-format.md 형식에 맞춰 작성해.
- 부족한 정보는 "확인 필요"로 표시해.
- 결과는 한국어로 작성해.
- 스크린샷이나 재현 방법을 지어내지 마.

[메모 묶음]
```

## 재현 방법이 부족할 때

```text
너는 버그 재현 절차를 정리하는 도우미야.

아래 문제 설명만 보고, 사람이 따라 할 수 있는 재현 절차 초안을 만들어줘.

규칙:
- 제공된 정보만 사용해.
- 추측한 내용은 "가정"이라고 표시해.
- 마지막에 추가로 확인해야 할 질문을 적어.
- 결과는 한국어로 작성해.

[문제 설명]
```
