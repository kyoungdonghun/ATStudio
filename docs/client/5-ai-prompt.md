## 5. AI를 활용한 SR 작성

테스트 중 문제를 발견했지만 문서 작성이 번거로울 때, **AI(ChatGPT, Claude 등)에게 음성으로 설명**한 후 SR 양식에 맞게 정리시킬 수 있습니다.

### 5.1 AI 프롬프트

아래 프롬프트를 AI에게 붙여넣고, 이후 자유롭게 설명하세요:

```
당신은 소프트웨어 테스트 SR(수정 요청) 문서 작성 도우미입니다.

제가 테스트 중 발견한 문제를 설명하면, 아래 양식에 맞춰 SR 문서를 작성해주세요.
제가 말을 대충 해도 양식에 맞게 정리해주세요.

[SR 양식]
# SR-XX 제목

## 분류
- [ ] 버그 (Bug)
- [ ] 개선 (Enhancement)
- [ ] 기능 요청 (Feature Request)
- [ ] UI/UX 개선

## 우선순위
- [ ] HIGH (서비스 이용 불가)
- [ ] MEDIUM (불편하지만 우회 가능)
- [ ] LOW (개선하면 좋음)

## 환경
- 기기:
- OS:
- 브라우저:

## 현상
(현재 동작)

## 기대 동작
(올바른 동작)

## 재현 방법
1.
2.
3.

## 비고
(추가 참고사항)

[규칙]
- SR 번호는 XX로 비워두세요 (번호는 제가 부여합니다)
- 제목은 20자 이내로 간결하게
- 재현 방법은 누구나 따라할 수 있도록 구체적으로
- 확실하지 않은 부분은 "확인 필요"로 표시
- 한국어로 작성
```

### 5.2 사용 예시

**테스터가 AI에게 말한 내용:**
> "아 그 음원 재생하는데 다음 곡으로 넘어갈 때 잠깐 멈추는 것 같아. 갤럭시폰에서 그랬어. 카톡으로 접속했고."

**AI가 생성한 SR:**
```markdown
# SR-XX 음원 재생 시 다음 곡 전환 시 일시 멈춤

## 분류
- [x] 버그 (Bug)

## 우선순위
- [ ] HIGH
- [x] MEDIUM
- [ ] LOW

## 환경
- 기기: 갤럭시 (모델 확인 필요)
- OS: Android (버전 확인 필요)
- 브라우저: 카카오톡 인앱 브라우저

## 현상
음원 재생 중 다음 곡으로 자동 전환될 때 짧은 멈춤(버퍼링) 현상 발생.

## 기대 동작
다음 곡으로 끊김 없이 자연스럽게 전환.

## 재현 방법
1. 음원 리스트에서 아무 곡 재생
2. 재생 완료 후 다음 곡으로 자동 전환 대기
3. → 전환 시 짧은 멈춤 발생

## 비고
정확한 멈춤 시간(초) 및 기기 모델 확인 필요. PC에서도 동일한지 확인 필요.
```
