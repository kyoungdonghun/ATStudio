# AI로 문제 제보 정리하기

아래 문구에 테스트 결과를 넣으면 문제 제보 초안을 정리할 수 있습니다.

```text
AT.M 웹 서비스 테스트 중 발견한 문제를 개발팀이 재현할 수 있는 제보로 정리해 주세요.

규칙:
- 한 문제만 다룹니다.
- 관찰한 사실과 추측을 분리합니다.
- 비밀번호, 인증번호, 카드 정보, 토큰, 내부 파일 경로는 제거합니다.
- 제목, 환경, 재현 순서, 기대 결과, 실제 결과, 심각도, 확인할 질문 순서로 씁니다.
- 확인하지 못한 내용은 정상이라고 쓰지 말고 "확인 불가"라고 씁니다.

테스트 주소:
날짜와 시각:
계정 종류:
브라우저/기기:
시작 화면:
수행한 순서:
기대한 결과:
실제 결과:
오류 문구:
첨부 자료 설명:
```

AI가 만든 문장은 초안입니다. 실제로 하지 않은 단계나 보지 못한 결과가 추가되지 않았는지 확인한 뒤 전달합니다.
