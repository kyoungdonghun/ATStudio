# 전체 기능 점검표

## 1. 공개 화면

- [ ] 메인 화면의 음악과 앨범이 표시됩니다.
- [ ] 음악 목록에서 검색어, 분위기, 장르, 용도 태그를 바꿀 수 있습니다.
- [ ] 빠르게 조건을 바꿔도 이전 결과가 나중 결과를 덮지 않습니다.
- [ ] 음악 상세에서 전체 재생이 됩니다.
- [ ] 비로그인 사용자가 다운로드를 누르면 구독/로그인 안내가 정확합니다.
- [ ] 앨범 이미지형/목록형 화면과 상세 화면이 열립니다.
- [ ] 공지 목록과 상세 화면이 열립니다.
- [ ] 존재하지 않는 주소는 404 화면으로 이동합니다.

## 2. 회원가입과 로그인

- [ ] 이메일, 휴대폰, 닉네임 중복 확인이 동작합니다.
- [ ] 개인 회원은 직업, 사업자 회원은 회사명을 입력합니다.
- [ ] 이메일 인증과 비밀번호 재설정 안내가 이해하기 쉽습니다.
- [ ] Google/Kakao/Naver 중 운영 환경에서 켜진 로그인만 보입니다.
- [ ] 처음 소셜 로그인한 사용자는 추가 정보 입력 화면으로 이동합니다.
- [ ] 처음 소셜 로그인에서 추가 정보 입력을 마친 뒤에도 로그인 전 보던 내부 화면으로 안전하게 돌아옵니다.
- [ ] 같은 소셜 로그인 완료 주소를 다시 열어도 로그인 처리가 반복되지 않습니다.
- [ ] 외부 주소나 `//`로 시작하는 주소는 돌아갈 주소로 사용되지 않습니다.

## 3. 프로필과 탈퇴

- [ ] 프로필 조회와 수정 뒤 화면과 재로그인 상태가 일치합니다.
- [ ] 비밀번호 변경은 현재 비밀번호 확인 뒤 완료됩니다.
- [ ] 비밀번호 계정 탈퇴는 비밀번호 확인 뒤 진행됩니다.
- [ ] 탈퇴는 다음 자동결제를 막지만 과거 결제를 자동 환불하지 않습니다.
- [ ] 소셜 전용 계정 탈퇴는 현재 정책 검토 중이며 비밀번호 방식으로 대신 처리되지 않습니다.

## 4. 재생, 좋아요, 재생 기록

- [ ] 재생/일시정지, 다음 곡, 이전 곡, 진행 위치가 동작합니다.
- [ ] 네트워크 지연/중단 시 오류와 다시 시도 안내가 보입니다.
- [ ] 키보드로 플레이어와 주요 버튼을 사용할 수 있습니다.
- [ ] 재생 기록은 실제 재생 시작 뒤 현재 브라우저에 저장됩니다.
- [ ] 재생 기록은 최대 100곡이며 같은 곡은 중복되지 않습니다.
- [ ] 다른 브라우저/기기와 자동 동기화되지 않습니다.
- [ ] 좋아요 음악과 앨범을 추가/삭제할 수 있습니다.

## 5. 재생목록

- [ ] 재생목록 만들기 창이 열리고 닫을 때 입력값이 초기화됩니다.
- [ ] `/playlists/new`도 같은 만들기 창을 사용합니다.
- [ ] 목록, 상세, 수정 화면에서 음악 추가/삭제/순서 변경이 됩니다.
- [ ] 요금제 한도에 도달하면 정확한 안내가 보입니다.
- [ ] 저장 중 중복 제출이 되지 않습니다.

## 6. 구독과 결제

- [ ] 새 구독은 카드 등록 뒤 첫 결제 성공 전에는 활성화되지 않습니다.
- [ ] 결제 실패/취소 뒤 구독이 잘못 활성화되지 않습니다.
- [ ] 결제수단 다시 등록은 `BILLING_AGREEMENT`, 금액 0원으로 준비됩니다.
- [ ] 다시 등록 단계에서 카드가 결제되지 않고 현재 요금제/기간이 유지됩니다.
- [ ] 상위 요금제는 남은 기간 차액 결제 뒤 즉시 적용됩니다.
- [ ] 하위 요금제와 결제 주기 변경은 다음 갱신 예약으로 표시됩니다.
- [ ] 예약 변경을 다른 선택으로 바꾸거나 취소할 수 있습니다.
- [ ] 해지 뒤 만료일까지 이용 가능하고, 유효한 결제수단이 있으면 만료 전 재활성화할 수 있습니다.
- [ ] 오래된 일회성 결제 주소는 안전한 안내만 보이고 구독을 변경하지 않습니다.

## 7. 다운로드와 라이선스

- [ ] 구독 권한과 일일 한도를 통과한 첫 다운로드가 성공합니다.
- [ ] 같은 음악을 다시 내려받을 때 중복 라이선스가 생기지 않습니다.
- [ ] 다운로드 기록과 라이선스 목록/상세가 일치합니다.
- [ ] 원본 저장 경로나 내부 파일명이 화면/API에 보이지 않습니다.

## 8. 화이트리스트 채널

- [ ] 채널 초안을 저장, 수정, 삭제, 대표 설정할 수 있습니다.
- [ ] 최대 100개 저장 한도와 요금제 등록 한도가 구분되어 안내됩니다.
- [ ] 등록 요청 뒤 허용되지 않은 이전 상태로 돌아가지 않습니다.
- [ ] 삭제가 불가능한 상태에서는 삭제 대신 해지 요청으로 처리됩니다.
- [ ] 관리자 처리 상태와 사용자 화면 상태가 일치합니다.
- [ ] 현재 규칙에 맞지 않는 과거 채널 주소는 클릭 링크가 아니라 확인용 글자로만 보입니다.

## 9. 기업 인증

- [ ] BUSINESS 계정만 신청/상태 화면을 사용할 수 있습니다.
- [ ] PDF, JPG, JPEG, PNG만 허용되고 잘못된 파일은 거절됩니다.
- [ ] 이미지 파일은 안전하게 확인된 뒤 저장됩니다.
- [ ] 반려 사유가 화면에 보이고 재제출할 수 있습니다.
- [ ] 파일 경로, 내부 저장명, 관리자 메모가 일반 사용자 응답에 보이지 않습니다.

## 10. 문의와 공지

- [ ] 문의 작성, 목록, 상세, 첨부파일, 삭제가 권한에 맞게 동작합니다.
- [ ] 관리자가 답변/상태를 바꾸면 사용자 화면에 반영됩니다.
- [ ] 공지 작성/수정은 관리자만 가능하고 공개 목록/상세에 반영됩니다.

## 11. 오류와 접근성

- [ ] 로딩, 빈 결과, 권한 없음, 찾을 수 없음, 입력 오류, 서버 오류가 구분됩니다.
- [ ] 다시 시도 버튼을 연속 클릭해도 중복 요청이 생기지 않습니다.
- [ ] 모달이 닫힌 뒤 초점이 원래 버튼으로 돌아옵니다.
- [ ] 키보드만으로 주요 흐름을 진행할 수 있습니다.
- [ ] 작은 화면에서도 버튼과 글자가 겹치지 않습니다.

## 12. 환경 확인

- [ ] 운영 담당자가 현재 테스트 주소를 공개 가능한 상태라고 확인했습니다.
- [ ] 실제 카드/실제 개인정보/실제 사업자 문서를 사용하지 않았습니다.
- [ ] 확인 불가 항목은 필요한 계정, 제공자 설정, DB 또는 운영 환경과 함께 기록했습니다.
