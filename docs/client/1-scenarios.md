## 1. 기능 시나리오

### 1.1 비회원 시나리오

#### SC-G-01: 홈페이지 탐색
1. 홈페이지(`/`) 접속
2. 장르/분위기 태그 선택 → 해당 태그로 필터링된 음원 리스트 이동 확인
3. 신규 앨범 캐러셀 표시 확인, 좌우 스크롤 동작
4. 인기 앨범 그리드 표시 확인
5. 신규 음원 섹션 표시 확인
6. Footer 네비게이션 링크 동작 확인

#### SC-G-02: 음원 리스트 — 키워드 검색
1. 음원 리스트(`/tracks`) 접속
2. 검색창에 키워드 입력 → 검색 결과 확인
3. 검색 해제(X 버튼 또는 빈 검색) → 전체 목록 복원 확인

#### SC-G-03: 음원 리스트 — 필터
1. 음원 리스트에서 장르/분위기/악기 태그 필터 적용
2. BPM 범위 선택 (프리셋: 60-90, 90-120 등)
3. 조성(Key) 선택
4. 필터 조합 적용 → 결과 확인

#### SC-G-04: 음원 리스트 — 태그 필터 모달
1. 음원 리스트 → 필터 모달 열기
2. 장르/분위기/악기 태그 다중 선택
3. 모달 내 태그 검색 기능으로 빠르게 찾기
4. "적용" → 필터링된 결과 확인

#### SC-G-05: 음원 리스트 — 정렬
1. 정렬 옵션 변경: 최신순 / 인기순 / 좋아요순 / 다운로드순
2. 각 정렬 기준에 따라 결과 순서가 변경되는지 확인

#### SC-G-06: 음원 리스트 — 페이지네이션
1. 음원이 한 페이지 이상일 때 하단 페이지네이션 표시 확인
2. 페이지 이동 → 해당 페이지 결과 표시

#### SC-G-07: 음원 리스트 — Empty State
1. 존재하지 않는 키워드 검색 또는 결과 없는 필터 조합 적용
2. "검색 결과가 없습니다" 등 empty state 메시지 확인

#### SC-G-08: 음원 리스트 — 트랙별 재생
1. 음원 리스트에서 트랙 재생 버튼 클릭
2. 하단 플레이어에서 해당 곡 재생 시작 확인

#### SC-G-09: 음원 리스트 — 비회원 액션 시 로그인 유도
1. 비로그인 상태에서 좋아요/다운로드/재생목록 추가 등 시도
2. "로그인이 필요한 기능입니다" 토스트 표시 확인

#### SC-G-10: 음원 상세
1. 음원 상세 페이지 접속
2. 재생 버튼 클릭 → 재생 확인
3. 태그(장르/분위기/악기) 표시 확인
4. 비회원 상태에서 다운로드/좋아요/재생목록 버튼이 미표시 또는 로그인 유도 확인

#### SC-G-11: 앨범 리스트 — 카드뷰/리스트뷰 전환
1. 앨범 리스트(`/albums`) 접속 → 카드뷰(이미지) 확인
2. 리스트뷰 전환 버튼 클릭 → 리스트 형태 확인
3. 다시 카드뷰로 전환

#### SC-G-12: 앨범 리스트 — 정렬 및 페이지네이션
1. 정렬 옵션 변경 (최신순/트랙수순 등)
2. 앨범별 좋아요 표시 확인
3. 페이지네이션 동작 확인
4. 결과 없을 때 empty state 확인

#### SC-G-13: 앨범 상세
1. 앨범 상세 페이지 접속
2. 앨범 좋아요 버튼 확인 (비회원 시 로그인 유도)
3. "전체 재생" 버튼 클릭 → 앨범 내 전 트랙 재생 확인
4. 트랙별 인터랙션: 재생 / 좋아요 / 다운로드 / 대기열 추가 / 재생목록 추가
5. 트랙 클릭 → 음원 상세 페이지 이동 확인
6. 비회원 시 인증 필요 액션에 로그인 유도 확인

#### SC-G-14: 구독 플랜 페이지
1. 구독 페이지(`/subscriptions`) 접속
2. 월간/연간 토글 → 가격 변경 확인
3. 플랜 비교 테이블 확인 (Starter/Pro/Business)
4. FAQ 섹션 확인
5. 비회원 상태에서 "시작하기" 클릭 → 로그인 유도 확인
6. 이미 구독 중인 회원 접속 시 현재 플랜 배너 표시 확인

#### SC-G-15: 공지사항 리스트
1. 공지사항(`/notices`) 접속
2. 고정 공지가 상단에 표시되는지 확인
3. 정렬 변경: 최신순 / 조회수순
4. 페이지네이션 동작 확인

#### SC-G-16: 공지사항 상세
1. 공지사항 클릭 → 상세 페이지 이동
2. 조회수 표시 확인
3. 첨부파일이 있는 공지 → 다운로드 링크 클릭 → 파일 다운로드 확인

#### SC-G-17: 헤더 — 검색바
1. 헤더 검색바에 키워드 입력 → Enter
2. 음원 리스트 페이지로 이동하며 해당 키워드가 검색에 반영되는지 확인

#### SC-G-18: 헤더 — 역할별 메뉴
1. 비회원 상태: 로그인/회원가입 버튼 표시
2. 로그인 후 회원 상태: 내 계정/로그아웃 메뉴 확인
3. 구독자 상태: 구독자 전용 메뉴 확인
4. 관리자 상태: 관리자 메뉴 확인

#### SC-G-19: 헤더 — 모바일 햄버거 메뉴
1. 모바일 해상도에서 햄버거 아이콘 표시 확인
2. 클릭 → 모바일 메뉴 펼침
3. 메뉴 항목 클릭 → 해당 페이지 이동

#### SC-G-20: 헤더 — 다크/라이트 모드 토글
1. 헤더의 다크/라이트 모드 토글 클릭
2. 페이지 전체 색상 테마 변경 확인
3. 새로고침 후에도 설정 유지 확인

### 1.2 인증 시나리오

#### SC-AUTH-01: 회원가입 — 유형 선택
1. 회원가입(`/signup`) 접속
2. 회원 유형 선택: 개인(Individual)
3. 기본 폼 필드 확인 (닉네임/이메일/비밀번호/연락처/직업)
4. 유형을 기업(Business)으로 변경 → 회사 연락처 입력란 추가 확인

#### SC-AUTH-02: 회원가입 — 중복 확인
1. 닉네임 입력 → 중복 확인 버튼 클릭 → 중복 시 에러 메시지
2. 이메일 입력 → 중복 확인 → 이미 사용 중인 이메일 에러

#### SC-AUTH-03: 회원가입 — 비밀번호 확인 불일치
1. 비밀번호 입력 후 비밀번호 확인란에 다른 값 입력
2. "비밀번호가 일치하지 않습니다" 에러 표시 확인

#### SC-AUTH-04: 회원가입 — 전화번호 자동 포맷팅
1. 연락처에 `01012345678` 입력
2. 자동으로 `010-1234-5678` 형식으로 포맷팅 확인

#### SC-AUTH-05: 회원가입 — 완료 및 이메일 인증 안내
1. 모든 필드 정상 입력 → "가입하기" 클릭
2. 이메일 인증 안내 메시지 확인
3. 참고: 외부 테스트 환경에서는 메일 서버 미설정으로 건너뜀

#### SC-AUTH-06: 로그인 — 정상
1. 로그인(`/login`) 접속
2. 이메일 + 비밀번호 입력 → 로그인
3. 상단 헤더에 "내 계정" 버튼 확인
4. 로그아웃 클릭 → 비회원 상태 복귀

#### SC-AUTH-07: 로그인 — 이미 로그인 시 자동 리다이렉트
1. 로그인 상태에서 `/login` 접속 시도
2. 자동으로 홈페이지로 리다이렉트 확인

#### SC-AUTH-08: 소셜 로그인 — Google
1. 로그인 페이지 → "Google로 로그인" 클릭
2. Google 인증 화면에서 계정 선택/승인
3. 신규 사용자: 프로필 완성 페이지(`/complete-profile`)로 이동 → 닉네임/연락처/직업/유형 입력 → 완료
4. 기존 사용자: 바로 메인 페이지로 이동
5. 참고: Kakao/Naver는 현재 미설정 안내 표시

#### SC-AUTH-09: 이메일 인증
1. 회원가입 완료 후 인증 이메일 수신
2. 이메일 내 인증 링크 클릭 → `/email-verify?token=...`
3. 인증 완료 메시지 확인
4. 참고: 외부 테스트 환경에서는 메일 서버 미설정으로 자동 건너뜀

#### SC-AUTH-10: 비밀번호 찾기/재설정
1. 로그인 페이지 → "비밀번호 찾기" 클릭
2. 비밀번호 재설정(`/password-reset`) 페이지에서 이메일 입력
3. 재설정 이메일 수신 → 링크 클릭
4. 새 비밀번호(8자 이상) + 확인 입력 → 재설정 완료
5. 새 비밀번호로 로그인 확인

### 1.3 회원(비구독) 시나리오

#### SC-U-01: 프로필 — 계정 정보 탭
1. 내 계정(`/profile`) 접속
2. "계정 정보" 탭: 이메일, 유형(개인/기업), 직업, 가입일 확인
3. 기업 회원: "기업 인증 관리" 버튼 표시 확인

#### SC-U-02: 프로필 — 프로필 수정
1. "프로필 수정" 탭 이동
2. 닉네임 변경 → 저장 → 변경 반영 확인

#### SC-U-03: 프로필 — 비밀번호 변경
1. "비밀번호 변경" 탭 이동
2. 현재 비밀번호 + 새 비밀번호 + 확인 입력 → 변경
3. 변경된 비밀번호로 재로그인 확인

#### SC-U-04: 프로필 — 구독 탭
1. "구독" 탭 이동
2. 현재 플랜 표시 확인 (미구독 시 "구독 시작" 링크)
3. 구독 관리 버튼 확인

#### SC-U-05: 프로필 — 활동 탭 네비게이션
1. "활동" 탭 이동
2. 하위 네비게이션 확인: 좋아요 / 다운로드 / 재생목록 / 재생기록 / 라이선스
3. 각 하위 탭 클릭 → 해당 목록 표시

#### SC-U-06: 좋아요 — 음원/앨범 좋아요 토글
1. 음원 상세 또는 앨범 상세에서 좋아요 버튼 클릭 → 좋아요 추가
2. 다시 클릭 → 좋아요 해제
3. 좋아요 수 증감 확인

#### SC-U-07: 좋아요 — 좋아요 목록 (음원/앨범 탭 전환)
1. 좋아요 목록(`/likes`) 접속
2. "음원" 탭: 좋아요한 음원 목록 확인
3. "앨범" 탭: 좋아요한 앨범 목록 확인
4. 탭 전환 동작 확인

#### SC-U-08: 좋아요 — 음원 탭 인터랙션
1. 좋아요 목록 음원 탭에서 트랙 선택
2. 재생 / 재생목록 추가 / 다운로드 / 대기열 추가 / 좋아요 해제 동작 확인

#### SC-U-09: 좋아요 — 앨범 탭 인터랙션
1. 좋아요 목록 앨범 탭에서 앨범 선택
2. 좋아요 해제 동작 확인
3. 앨범 클릭 → 앨범 상세 페이지 이동 확인

#### SC-U-10: 좋아요 — Empty State
1. 좋아요가 없는 상태에서 좋아요 목록 접속
2. "좋아요한 항목이 없습니다" 등 empty state 메시지 확인

#### SC-U-11: 문의 — 문의 작성
1. 문의 작성(`/questions/new`) 접속
2. 제목, 카테고리(다운로드/결제/저작권/제작/기타) 선택, 내용 입력
3. 공개 여부 설정
4. 첨부파일 추가 (최대 5개, 각 20MB)
5. 제출 → 문의 목록에서 확인

#### SC-U-12: 문의 — 문의 목록
1. 문의 목록(`/questions`) 접속
2. "전체 문의" / "내 문의" 탭 전환
3. 카테고리 필터 적용
4. 상태 필터(OPEN/IN_PROGRESS/RESOLVED/CLOSED) 적용

#### SC-U-13: 문의 — 문의 상세
1. 문의 상세 페이지 접속
2. 첨부파일 다운로드 확인
3. 답변 작성 (질문자 본인)
4. 관리자 답변에 관리자 뱃지 표시 확인
5. CLOSED 상태 문의 → 답변 작성 불가 확인

#### SC-U-14: 문의 — 문의 삭제
1. 본인 문의 상세에서 삭제 버튼 클릭
2. 확인 모달 표시
3. 확인 → 삭제 완료
4. 타인 문의에는 삭제 버튼 미표시 확인

#### SC-U-15: 재생기록
1. 재생기록(`/play-history`) 접속 → 재생한 곡 목록 확인
2. 전체 선택 체크박스 동작 확인
3. 선택 삭제 → 선택한 항목 삭제 확인
4. 페이지네이션 동작 확인

### 1.4 구독자 시나리오

#### SC-S-01: 구독 가입 — 플랜 선택 및 결제
1. 구독 페이지(`/subscriptions`) → 플랜 선택 → "시작하기"
2. 결제 페이지(`/subscriptions/payment`)에서 결제 주기 선택 (월간/연간)
3. 연간 선택 시 월 환산 가격 표시 확인
4. 결제 완료 → 구독 활성화

#### SC-S-02: 구독 가입 — 플랜 미선택 에러
1. 플랜 미선택 상태로 결제 페이지 접근 시도
2. 에러 메시지 또는 플랜 선택 유도 확인

#### SC-S-03: 구독 관리 — 현재 플랜 확인
1. 구독 관리(`/subscriptions/manage`) 접속
2. 현재 플랜 이름 및 상태별 뱃지 확인 (ACTIVE / CANCELLED / EXPIRED)
3. 결제 주기 정보 확인

#### SC-S-04: 구독 관리 — 업그레이드
1. 현재 플랜보다 상위 플랜으로 업그레이드 선택
2. 변경 미리보기 (차액 안내) 확인
3. 확인 → 즉시 적용 확인

#### SC-S-05: 구독 관리 — 다운그레이드
1. 현재 플랜보다 하위 플랜으로 다운그레이드 선택
2. 유예 안내 메시지 확인 (현재 기간 종료 후 적용)
3. 예약 알림 표시 확인

#### SC-S-06: 구독 관리 — 취소
1. 구독 취소 버튼 클릭 → 확인 모달 표시
2. 확인 → 취소 처리
3. 만료일까지 서비스 유지 확인
4. 상태 뱃지 CANCELLED 표시

#### SC-S-07: 구독 관리 — 구독 없음 상태
1. 구독이 없는 회원이 구독 관리 페이지 접속
2. "구독 중인 플랜이 없습니다" 안내 및 구독 시작 링크 확인

#### SC-S-08: 음원 다운로드 — 상세/리스트/앨범에서 다운로드
1. 음원 상세 페이지에서 "다운로드" 버튼 클릭 → 다운로드 큐 추가
2. 음원 리스트에서 트랙 다운로드 버튼 클릭
3. 앨범 상세에서 트랙별 다운로드 버튼 클릭

#### SC-S-09: 음원 다운로드 — 한도 초과
1. 다운로드 한도가 소진된 상태에서 다운로드 시도
2. "다운로드 한도를 초과했습니다" 에러 토스트 확인

#### SC-S-10: 음원 다운로드 — 대기열 추가 (중복 에러)
1. 이미 대기열에 있는 음원을 다시 대기열 추가 시도
2. "이미 대기열에 존재합니다" 에러 확인

#### SC-S-11: 다운로드 큐 — 목록 조회
1. 다운로드 큐(`/download-queue`) 접속
2. 오늘 다운로드 횟수 / 일일 한도 표시 확인
3. 다운로드 완료/대기 상태 뱃지 확인

#### SC-S-12: 다운로드 큐 — 미다운로드 전체 받기
1. 대기 상태 항목이 여러 개일 때 "전체 받기" 버튼 클릭
2. 모든 대기 항목 다운로드 실행 확인

#### SC-S-13: 다운로드 큐 — 항목 제거 및 재다운로드
1. 큐에서 항목 제거 버튼 클릭 → 제거 확인
2. 다운로드 완료 항목 재다운로드 확인
3. 빈 큐일 때 empty state 확인

#### SC-S-14: 재생목록 — 생성
1. 재생목록(`/playlists`) 접속
2. "새 재생목록" 클릭 → 제목, 설명, 썸네일 입력 → 생성
3. 재생목록 3개 존재 시 "새 재생목록" 버튼 비노출 확인

#### SC-S-15: 재생목록 — 상세
1. 재생목록 상세 페이지 접속
2. 곡 재생 / 좋아요 / 다운로드 / 대기열 추가 / 재생목록 이동 동작 확인

#### SC-S-16: 재생목록 — 편집
1. 재생목록 편집 페이지 접속
2. 제목/설명/썸네일 수정
3. 트랙 검색 → 추가
4. 트랙 제거
5. 트랙 순서 변경 (위/아래 버튼)

#### SC-S-17: 재생목록 — 삭제
1. 재생목록 삭제 버튼 클릭 → 확인 모달 표시
2. 확인 → 삭제 완료
3. 재생목록 없을 때 empty state 확인

#### SC-S-18: 화이트리스트 채널 관리
1. 화이트리스트 채널(`/whitelist-channels`) 접속
2. 채널 URL + 이름 입력 → 등록
3. 등록된 채널 수정 (URL/이름 변경)
4. 채널 삭제
5. 플랜별 최대 채널 수 제한 확인

#### SC-S-19: 라이선스 — 목록 조회
1. 라이선스(`/licenses`) 접속
2. 다운로드한 음원 라이선스 목록 확인
3. 라이선스 없을 때 empty state 확인

#### SC-S-20: 라이선스 — 상세 모달
1. 라이선스 항목 클릭 → 상세 모달 표시
2. 곡명, 발급일, 라이선스 코드 확인
3. 라이선스 코드 복사 버튼 동작 확인
4. 재다운로드 버튼 동작 확인

### 1.5 기업 회원 시나리오

#### SC-B-01: 기업 인증 신청
1. 프로필(`/profile`) → "기업 인증 관리" 클릭
2. 인증 신청 페이지 이동
3. 가이드 텍스트 확인 (관리자가 편집 가능한 안내문)
4. 서류 첨부 (PDF/HWP/DOCX/JPG/PNG, 최대 10개, 각 20MB)
5. "신청하기" → 상태: 심사중

#### SC-B-02: 기업 인증 신청 — 허용되지 않는 파일
1. 인증 신청 페이지에서 `.exe` 등 허용되지 않는 파일 첨부 시도
2. "허용되지 않는 파일 형식입니다" 에러 확인

#### SC-B-03: 기업 인증 신청 — 기존 신청 존재 시
1. 이미 인증 신청이 있는 상태에서 신청 페이지 접근 시도
2. 자동으로 인증 현황 페이지로 리다이렉트 확인

#### SC-B-04: 기업 인증 현황
1. 기업 인증 현황 페이지 접속
2. 상태별 뱃지 확인: 심사중 / 승인 / 반려 / 수정요청
3. 승인 상태: 인증 코드 표시 확인
4. 관리자 메모 표시 확인
5. 신청 없을 때 → 신청 페이지 링크 표시

### 1.6 관리자 시나리오

#### SC-A-01: 대시보드
1. 관리자 > 대시보드(`/admin/dashboard`) 접속
2. 총 사용자 수, 총 음원 수, 구독자 수 통계 확인
3. 최근 가입자 목록 확인

#### SC-A-02: 음원 업로드
1. 관리자 > 음원 업로드(`/admin/tracks/upload`)
2. 오디오 파일 선택 (최대 20곡 배치 업로드)
3. 각 트랙별 제목, BPM, 조성, 설명, 오디오, 썸네일, 태그 입력
4. 업로드 → 음원 관리 페이지에서 확인

#### SC-A-03: 음원 편집
1. 관리자 > 음원 편집 페이지 접속
2. 음원 정보 수정 (제목/BPM/조성/설명/태그)
3. 파일 교체 (오디오/썸네일)
4. 활성/비활성 토글

#### SC-A-04: 음원 관리
1. 관리자 > 음원 관리(`/admin/track-manage`) 접속
2. 활성/비활성 필터 적용
3. 음원 선택 → 활성화/비활성화 토글
4. 음원 삭제 → 확인 모달 → 소프트 삭제 처리
5. 비활성 음원이 공개 페이지에서 미노출 확인

#### SC-A-05: 앨범 생성
1. 관리자 > 앨범 생성(`/admin/albums/new`)
2. 제목, 설명, 썸네일 입력
3. 트랙 검색 → 앨범에 추가
4. 생성 완료

#### SC-A-06: 앨범 편집
1. 관리자 > 앨범 편집(`/admin/albums/:id/edit`)
2. 앨범 정보 수정 (제목/설명/썸네일)
3. 트랙 추가 / 제거
4. 트랙 순서 변경

#### SC-A-07: 앨범 관리
1. 관리자 > 앨범 관리 목록 접속
2. 수정 모달에서 앨범 정보 수정
3. 앨범 삭제 → 확인 모달 ("트랙은 삭제되지 않습니다" 안내 확인)

#### SC-A-08: 사용자 관리
1. 관리자 > 사용자 관리(`/admin/users`)
2. 사용자 검색 (이메일/닉네임)
3. 사용자 역할 변경 (USER <-> ADMIN)
4. 이메일 인증 상태 수동 변경

#### SC-A-09: 구독 플랜 관리
1. 관리자 > 구독 관리(`/admin/subscriptions`)
2. 플랜별 가격 / 다운로드 한도 / 화이트리스트 채널 수 조회

#### SC-A-10: 사용자 구독 관리
1. 관리자 > 사용자 구독 관리(`/admin/user-subscriptions`)
2. 사용자 구독 목록 조회
3. 구독 수정 모달에서 정보 변경
4. 강제 취소 모달 → 취소 처리
5. 대기 플랜(다운그레이드 예약) 표시 확인

#### SC-A-11: 라이선스 관리
1. 관리자 > 라이선스 관리(`/admin/licenses`)
2. 사용자 검색 → 해당 사용자 라이선스 이력 조회
3. 라이선스 상세 정보 확인

#### SC-A-12: 문의 관리
1. 관리자 > 문의 관리(`/admin/questions`)
2. 카테고리 필터 / 상태 필터 적용
3. 문의 목록에서 상태 드롭다운으로 직접 상태 변경
4. 문의 상세 → 답변 작성

#### SC-A-13: 기업 인증 심사
1. 관리자 > 기업 인증(`/admin/company-certifications`)
2. 상태 필터 적용 (심사중/승인/반려/수정요청)
3. 신청 건 선택 → 서류 확인
4. 승인 / 반려 / 수정요청 처리
5. 관리자 메모 작성

#### SC-A-14: 태그 관리
1. 관리자 > 태그 관리(`/admin/tags`)
2. 태그 생성: 이름 + 타입(장르/분위기/악기)
3. 태그 수정: 이름 변경
4. 태그 삭제

#### SC-A-15: 공지사항 관리
1. 관리자 > 공지사항 작성(`/admin/notices/new`): 제목, 내용, 고정 여부, 첨부파일
2. 공지사항 편집(`/admin/notices/:id/edit`): 내용 수정, 첨부파일 추가/삭제
3. 고정/해제 토글 확인

#### SC-A-16: 사이트 설정
1. 관리자 > 사이트 설정(`/admin/settings`)
2. 기업 인증 가이드 텍스트 편집
3. 저장 → 기업 인증 신청 페이지에 반영 확인

### 1.7 플레이어 시나리오

#### SC-P-01: 기본 조작
1. 음원 클릭 → 하단 플레이어에서 재생 시작
2. 재생/일시정지 버튼 토글
3. 진행바 드래그로 재생 위치 이동
4. 볼륨 슬라이더로 음량 조절
5. 음소거 토글 (볼륨 아이콘 클릭)

#### SC-P-02: 셔플/반복 모드
1. 셔플 버튼 클릭 → ON/OFF 토글
2. 반복 버튼 클릭 → 순환: 반복 없음 → 전체 반복 → 한 곡 반복
3. 셔플 ON 상태에서 다음 곡이 랜덤으로 재생되는지 확인

#### SC-P-03: 이전곡/다음곡 버튼
1. 이전곡 버튼 클릭 → 이전 곡 재생
2. 다음곡 버튼 클릭 → 다음 곡 재생

#### SC-P-04: 키보드 곡 이동
1. 음원 리스트에서 곡 재생 중
2. 키보드 ↑ 키 → 이전 곡으로 이동 재생
3. 키보드 ↓ 키 → 다음 곡으로 이동 재생

#### SC-P-05: 대기열 모달
1. 플레이어에서 대기열 버튼 클릭 → 대기열 모달 열기
2. 곡 순서 변경 (드래그 또는 위/아래 버튼)
3. 곡 제거
4. 대기열 내 곡 선택 → 해당 곡 재생

#### SC-P-06: 좋아요/재생목록 추가
1. 플레이어바에서 현재 재생 곡 좋아요 버튼 클릭 → 좋아요 토글
2. 재생목록 추가 버튼 클릭 → 재생목록 선택 → 추가 확인

#### SC-P-07: 비회원/비구독자 — 구매하기 버튼
1. 비회원 상태: 플레이어 구매하기 버튼 → 로그인 페이지 이동
2. 비구독자 상태: 플레이어 구매하기 버튼 → 구독 페이지 이동

#### SC-P-08: 모바일 확장 패널
1. 모바일 해상도에서 미니 플레이어 표시 확인
2. 미니 플레이어 클릭 → 확장 패널 열림
3. 확장 패널에서 전체 컨트롤(재생/진행바/볼륨/셔플/반복/대기열) 사용 확인

### 1.8 라우트 가드 시나리오

#### SC-GUARD-01: 비로그인 → 인증 필요 페이지
1. 비로그인 상태에서 프로필/좋아요/문의 등 인증 필요 페이지 접속 시도
2. "로그인이 필요한 기능입니다" 토스트 표시
3. 로그인 페이지로 리다이렉트

#### SC-GUARD-02: 비구독 → 구독 필요 페이지
1. 비구독 회원이 다운로드 큐/재생목록/화이트리스트 채널 등 접속 시도
2. "구독이 필요한 기능입니다" 토스트 표시
3. 구독 페이지로 리다이렉트

#### SC-GUARD-03: 비관리자 → 관리자 페이지
1. 일반 회원이 `/admin/*` 페이지 접속 시도
2. "접근 권한이 없습니다" 토스트 표시
3. 홈 페이지로 리다이렉트

#### SC-GUARD-04: 관리자 → 문의 목록 자동 리다이렉트
1. 관리자가 일반 문의 목록(`/questions`) 접속
2. 자동으로 관리자 문의 관리 페이지로 리다이렉트

#### SC-GUARD-05: 관리자 → 구독 관리 자동 리다이렉트
1. 관리자가 일반 구독 관리 페이지 접속
2. 자동으로 관리자 구독 관리 페이지로 리다이렉트

#### SC-GUARD-06: 로그인 상태 → 로그인 페이지
1. 이미 로그인된 상태에서 `/login` 접속
2. 자동으로 홈 페이지로 리다이렉트

### 1.9 에러 및 반응형 시나리오

#### SC-ERR-01: 404 Not Found 페이지
1. 존재하지 않는 URL 접속 (예: `/abcdef`)
2. 404 에러 페이지 표시 확인
3. 홈으로 돌아가기 버튼 동작 확인

#### SC-ERR-02: 500 Server Error 페이지
1. 서버 오류 발생 시 500 에러 페이지 표시 확인
2. 홈으로 돌아가기 버튼 동작 확인

#### SC-ERR-03: 모바일 반응형 — 주요 페이지
1. 모바일 기기 또는 브라우저 개발자 도구로 모바일 해상도 설정
2. 주요 페이지 레이아웃 확인: 홈, 음원 리스트, 앨범, 프로필
3. 헤더 햄버거 메뉴 동작 확인
4. 플레이어 모바일 레이아웃 확인
5. 회원가입/로그인 등 폼 입력 페이지 모바일 표시 확인

#### SC-ERR-04: 모바일 반응형 — 관리자 페이지
1. 모바일 해상도에서 관리자 페이지 접속
2. 모바일 사이드바 표시 및 토글 동작 확인
3. "사이트로 돌아가기" 링크 동작 확인

#### SC-ERR-05: 다크/라이트 모드
1. 헤더 토글로 다크/라이트 모드 전환
2. 주요 페이지(홈/음원/앨범/프로필/관리자) 색상 확인
3. 새로고침 후 설정 유지 확인
