# 3. 관리자 체크리스트

> 목적: 운영자가 개발자 도구 없이 서비스를 관리할 수 있는지 확인합니다.

## 관리자 테스트 주의

관리자 기능은 실제 데이터를 바꿀 수 있습니다. 테스트 DB가 변경되어도 되는 상황인지 확인한 뒤 진행하세요.

특히 아래 작업은 조심합니다.

- 환불 실행
- 권한 보정 실행
- 회원, 음원, 앨범, 태그, 공지, 구독 삭제
- 실제 회사 서류가 들어간 기업 인증 승인/반려

## A. 관리자 접근

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 관리자 계정으로 로그인한다. | 관리자 메뉴가 보인다. |
| `/admin/dashboard`를 연다. | 대시보드가 열린다. |
| 왼쪽 메뉴로 이동한다. | 선택한 관리자 화면으로 이동한다. |
| 일반 계정으로 관리자 주소를 연다. | 접근이 막힌다. |

## B. 콘텐츠 운영

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 태그 목록을 본다. | 태그가 조회된다. |
| 태그를 만들거나 수정한다. | 사용자 필터와 목록에 반영된다. |
| 음원을 업로드한다. | 음원 정보, 파일, 커버, 태그, 용도/가이드 문구를 입력할 수 있다. |
| 음원 관리 화면을 본다. | 검색, 수정, 활성/비활성, 삭제 흐름을 확인할 수 있다. |
| 앨범을 관리한다. | 앨범 생성, 수정, 트랙 연결을 할 수 있다. |
| 공지를 관리한다. | 공지 생성과 수정이 가능하다. |

## C. 회원과 구독 운영

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 회원 목록을 본다. | 회원을 조회하고 검색할 수 있다. |
| 회원 권한/상태를 바꾼다. | 저장 전에 확인 절차가 있다. |
| 구독 플랜 목록을 본다. | 현재 플랜과 월간/연간 가격이 보인다. |
| 사용자 구독 목록을 본다. | 사용자별 구독 상태를 확인할 수 있다. |
| 구독 수동 처리를 시도한다. | 저장 전 확인이 나온다. |

## D. 결제 운영

| 탭 | 확인할 것 | 정상이라면 |
|----|-----------|------------|
| 주문 | 결제 주문 목록 | 상태와 금액이 읽기 쉽다. |
| 자동결제 | 저장된 결제수단 | 마스킹된 결제수단만 보인다. |
| 결제내역 | 완료된 구독 결제 | 금액, 주문, 플랜, 상태를 확인할 수 있다. |
| 대사 Incident | Toss와 로컬 데이터 불일치 기록 | 상태와 메모를 바꿀 수 있다. |
| 영수증 | 결제 증빙 정보 | 카드 원문이나 시크릿 없이 증빙을 볼 수 있다. |
| 감사로그 | 결제 운영 이력 | 누가, 언제, 무엇을 했는지 추적된다. |
| 정산 | CSV 가져오기와 불일치 확인 | 가져온 row와 불일치 사유가 보인다. |
| 환불 | 미리보기, 요청, 승인, 실행 | 미리보기 후 요청하며, 실행은 강한 확인을 거친다. |
| 권한 보정 | 미리보기, 요청, 승인, 실행 | 환불과 별도 절차로 접근 권한을 조정한다. |

중요한 데이터에서는 환불 실행과 권한 보정 실행을 하지 마세요.

## E. 화이트리스트 운영

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 화이트리스트 운영 화면을 연다. | 요청 채널이 보인다. |
| 상태로 필터링한다. | 상태에 맞게 목록이 바뀐다. |
| 이메일, 닉네임, 채널명, URL로 검색한다. | 맞는 결과가 나온다. |
| CSV를 내보낸다. | 사용자 이메일과 채널 정보가 포함된다. |
| 상태를 바꾼다. | 상태와 관리자 메모가 저장된다. |
| 보완 요청으로 바꾼다. | 사용자가 수정 후 다시 요청할 수 있다. |

## F. 기업 인증 운영

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 기업 인증 목록을 연다. | 신청 목록을 상태별로 볼 수 있다. |
| 상세를 연다. | 신청자와 제출 서류 목록이 보인다. |
| 서류를 내려받는다. | 관리자만 파일을 받을 수 있다. |
| 승인한다. | 사용자는 승인 상태를 보고 기업 구독을 진행할 수 있다. |
| 보완 요청한다. | 사용자는 메모를 보고 대체 서류를 제출할 수 있다. |
| 반려한다. | 사용자는 사유를 보고 새 신청을 할 수 있다. |

## G. 문의와 설정

| 확인할 것 | 정상이라면 |
|-----------|------------|
| 문의 관리 화면을 연다. | 문의를 읽고 답변하거나 상태를 바꿀 수 있다. |
| 사이트 설정을 수정한다. | 저장이 가능하다. |
| 설정이 반영되는 공개 화면을 확인한다. | 해당 화면에 변경 내용이 보인다. |
