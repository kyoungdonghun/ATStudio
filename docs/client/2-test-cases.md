## 2. 예시 테스트 케이스

### TC-001: 회원가입 — 정상 케이스
| 항목 | 내용 |
|------|------|
| **전제조건** | 비회원 상태 |
| **입력** | 닉네임: `TestUser1`, 이메일: `test@example.com`, 비밀번호: `Test1234`, 연락처: `010-1234-5678`, 직업: 편집자, 유형: 개인 |
| **기대결과** | 가입 성공, 로그인 페이지로 이동 |

### TC-002: 회원가입 — 닉네임 중복
| 항목 | 내용 |
|------|------|
| **전제조건** | `TestUser1` 닉네임이 이미 존재 |
| **입력** | 닉네임: `TestUser1` (나머지 정상) |
| **기대결과** | "이미 사용 중인 닉네임입니다." 에러 |

### TC-003: 회원가입 — 비밀번호 길이 부족
| 항목 | 내용 |
|------|------|
| **전제조건** | 비회원 상태 |
| **입력** | 비밀번호: `1234` (4자) |
| **기대결과** | "비밀번호는 8자 이상이어야 합니다." 에러 |

### TC-004: 비구독자 다운로드 시도
| 항목 | 내용 |
|------|------|
| **전제조건** | 로그인 상태, 구독 없음 |
| **행동** | 음원 상세 → 다운로드 버튼 클릭 |
| **기대결과** | 구독 페이지로 리다이렉트 또는 "구독이 필요합니다" 메시지 |

### TC-005: 재생목록 3개 제한
| 항목 | 내용 |
|------|------|
| **전제조건** | 구독 상태, 재생목록 3개 보유 |
| **행동** | 재생목록 페이지 접속 |
| **기대결과** | "새 재생목록" 버튼이 비노출 |

### TC-006: 전화번호 포맷팅
| 항목 | 내용 |
|------|------|
| **전제조건** | 회원가입 페이지 |
| **입력** | 연락처에 `01012345678` 입력 |
| **기대결과** | 자동으로 `010-1234-5678`로 포맷팅 |

### TC-007: 기업 인증 서류 — 허용되지 않는 파일
| 항목 | 내용 |
|------|------|
| **전제조건** | 기업 인증 신청 페이지 |
| **입력** | `.exe` 파일 첨부 시도 |
| **기대결과** | "허용되지 않는 파일 형식입니다" 에러 (PDF, HWP, DOCX, JPG, PNG만 가능) |

### TC-008: 키보드 곡 이동
| 항목 | 내용 |
|------|------|
| **전제조건** | 음원 리스트에서 곡 재생 중 |
| **행동** | 키보드 ↑↓ 방향키 |
| **기대결과** | 이전/다음 곡으로 이동하여 재생 |
