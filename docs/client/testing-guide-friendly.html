1. 사이트는 이렇게 돌아가요

회원 종류

ATStudio에는 세 종류의 사용자가 있어요.

누구?뭘 할 수 있나요?
비회원 음원 검색, 미리 듣기, 앨범 구경, 공지사항 확인. 듣기만 가능하고 다운로드는 안 돼요.
일반 회원 비회원 기능 + 좋아요, 내 프로필, 문의하기, 재생 기록 확인. 구독하면 다운로드도 가능!
관리자 모든 기능 + 음원/앨범 올리기, 사용자 관리, 태그 관리, 기업인증 심사 등

개인 vs 기업

회원가입할 때 "개인" 또는 "기업"을 선택해요.

  • 개인: 대부분의 사용자. 특별한 제한 없음.
  • 기업: 사업자등록번호가 있는 분. 기업용 플랜을 구독하려면 기업 인증(서류 제출)이 먼저 승인되어야 해요.

구독 플랜

음원을 다운로드하려면 구독이 필요해요. 세 가지 플랜이 있어요.

플랜개인 회원기업 회원
스탠다드일 5곡 / 재생목록 3 / 채널 1일 10곡 / 재생목록 3 / 채널 1
디럭스일 20곡 / 재생목록 10 / 채널 2일 50곡 / 재생목록 10 / 채널 2
프리미엄무제한 / 재생목록 10 / 채널 2 / 우선지원무제한 / 재생목록 10 / 채널 2 / 우선지원
알아두세요: 업그레이드하면 바로 적용되고, 다운그레이드는 현재 결제 기간이 끝난 후 적용돼요. 취소해도 만료일까지는 이용 가능!

2. 이런 걸 테스트해주세요

아래는 사이트의 주요 기능들이에요. 직접 해보면서 이상한 점이 있으면 알려주세요!

비회원 으로 해볼 것들

홈페이지 구경하기
메인 페이지에서 장르/분위기 태그를 눌러보세요. 신규 앨범 캐러셀, 인기 앨범, 신규 음원 섹션이 잘 보이나요?
음원 검색하기
검색바에 키워드를 입력하거나, 필터(장르/분위기/BPM/조성)를 걸어보세요. 정렬도 바꿔보세요(최신/인기/좋아요/다운로드).
음원 듣기
아무 곡이나 클릭해서 재생해보세요. 하단 플레이어가 잘 작동하나요?
앨범 구경하기
앨범 페이지에서 카드뷰/리스트뷰 전환해보세요. 앨범을 클릭하면 수록곡이 잘 보이나요? "전체 재생"도 눌러보세요.
구독 플랜 확인하기
구독 페이지에서 월간/연간 토글, 플랜 비교 테이블, FAQ가 잘 보이나요?
공지사항 확인하기
공지사항 목록과 상세 페이지를 확인해보세요. 첨부파일이 있으면 다운로드도 해보세요.
다크/라이트 모드
헤더의 모드 전환 버튼을 눌러보세요. 색상이 바뀌나요?
비회원인데 뭔가 하려고 하면?
로그인 안 한 상태에서 좋아요나 다운로드를 시도하면 "로그인이 필요합니다" 안내가 뜨는지 확인해주세요.

회원가입/로그인

회원가입
회원가입 페이지에서 개인/기업 선택, 닉네임, 이메일, 비밀번호(8자 이상), 연락처, 직업을 입력하고 가입해보세요. 전화번호 입력하면 자동으로 하이픈(-)이 들어가나요?
로그인/로그아웃
가입한 계정으로 로그인 → 헤더에 "내 계정" 표시 → 로그아웃하면 원래대로 돌아오나요?
소셜 로그인
테스트 환경에서 소셜 로그인이 설정되어 있다면, 제공되는 로그인 버튼을 눌러 인증 화면과 첫 로그인 흐름을 확인해보세요.
비밀번호 찾기
메일 설정이 된 테스트 환경이라면, 로그인 페이지에서 "비밀번호 찾기" → 이메일 입력 → 재설정 링크 → 새 비밀번호 설정을 확인해보세요.
참고: 이메일 인증 메일 수신 여부는 테스트 환경 메일 설정에 따라 달라질 수 있어요. 메일이 오지 않으면 환경 운영자에게 확인 절차를 문의해주세요.

로그인 후 해볼 것들

프로필 관리
"내 계정" → 계정 정보/프로필 수정/비밀번호 변경 탭을 각각 확인해보세요. 닉네임 변경이 잘 되나요?
좋아요 누르기
음원이나 앨범에 좋아요를 눌러보세요. 좋아요 목록에서 확인되나요? 다시 누르면 취소되나요?
좋아요 목록
좋아요 목록에서 "음원" 탭과 "앨범" 탭을 전환해보세요. 각 탭에서 재생/다운로드/해제 등이 잘 되나요?
문의하기
문의 작성 페이지에서 제목, 카테고리, 내용을 입력하고 첨부파일도 올려보세요(최대 5개). 제출 후 목록에서 확인!
재생 기록
곡을 몇 개 들은 후 재생 기록 페이지를 확인해보세요. 선택 삭제, 전체 삭제가 잘 되나요?

구독 후 해볼 것들

구독 가입하기
구독 페이지에서 플랜을 골라 "시작하기" → 결제 주기(월간/연간) 선택 → 결제. 연간이면 할인된 가격이 보이나요?
음원 다운로드
음원 상세/리스트/앨범 상세에서 다운로드 버튼을 눌러보세요. 즉시 파일이 받아지고, 다운로드 기록에도 반영되나요?
다운로드 기록
다운로드 메뉴에서 다운로드 기록 페이지로 들어가 오늘 다운로드 횟수, 검색, "전체 재다운로드" 버튼을 확인해보세요.
재생목록 만들기
재생목록 페이지에서 새 재생목록을 만들어보세요(최대 3개). 곡을 추가/제거하고 순서도 바꿔보세요.
라이선스 확인
다운로드한 곡의 라이선스 페이지에서 라이선스 코드가 보이나요? 복사 버튼도 눌러보세요.
화이트리스트 채널
채널 URL과 이름을 등록해보세요. 수정/삭제도 잘 되나요?
구독 업/다운그레이드, 취소
구독 관리 페이지에서 플랜 변경, 취소를 시도해보세요. 안내 메시지가 잘 나오나요?

기업 회원이라면

기업 인증 신청
프로필 → "기업 인증 관리" → 서류 첨부(PDF, HWP, DOCX, JPG, PNG만 가능, 최대 10개) → 신청. 허용 안 되는 파일(.exe 등)을 올리면 에러가 뜨나요?
인증 현황 확인
신청 후 현황 페이지에서 상태(심사중/승인/반려)가 잘 보이나요?

관리자라면

음원 올리기
관리자 페이지에서 음원 업로드(최대 20곡), 제목/BPM/조성/태그 입력 → 업로드. 음원 편집, 활성/비활성 토글도 해보세요.
앨범 만들기
새 앨범 생성 → 트랙 검색해서 추가 → 순서 변경. 삭제도 해보세요.
사용자/태그/공지/문의/기업인증 관리
각 관리 페이지에서 검색, 필터, 생성/수정/삭제, 상태 변경 등을 시도해보세요.
사이트 설정
사이트 설정에서 기업 인증 가이드 텍스트를 수정하고, 실제 신청 페이지에 반영되는지 확인해보세요.
대시보드
대시보드에서 통계(사용자 수/음원 수/구독자 수)가 잘 보이나요?

플레이어

기본 조작: 재생/일시정지, 진행바 드래그, 볼륨 조절, 음소거
셔플/반복: 셔플 ON/OFF, 반복 모드(없음 → 전체 → 한곡)
곡 이동: 이전/다음 버튼, 키보드 ↑↓ 방향키
모바일: 모바일에서 미니 플레이어 → 클릭하면 확장 패널이 열리나요?

접근 제한 확인

로그인 안 하고 프로필/좋아요 페이지 가면? → "로그인이 필요합니다" 안내 후 로그인 페이지로 이동
구독 안 하고 다운로드/재생목록 가면? → "구독이 필요합니다" 안내 후 구독 페이지로 이동
일반 회원이 관리자 페이지(/admin) 가면? → "접근 권한이 없습니다" 안내 후 홈으로 이동

모바일에서도 확인해주세요!

스마트폰으로 접속해서 주요 페이지가 깨지지 않는지 확인해주세요. 특히 헤더 메뉴, 플레이어, 회원가입 폼, 관리자 사이드바를 중점적으로!

3. 테스트 예시

"이런 식으로 해보면 돼요"라는 예시입니다.

뭘 해볼까어떻게이렇게 되면 정상
회원가입 닉네임, 이메일, 비밀번호(8자 이상), 연락처, 직업 입력 후 "가입하기" 가입 성공, 로그인 가능
닉네임 중복 이미 있는 닉네임으로 가입 시도 "이미 사용 중인 닉네임입니다" 에러
짧은 비밀번호 비밀번호를 4자만 입력 "비밀번호는 8자 이상이어야 합니다" 에러
비구독자 다운로드 구독 없이 다운로드 버튼 클릭 구독 페이지로 안내
재생목록 플랜별 제한 현재 플랜 한도까지 만든 뒤 추가 생성 시도 "새 재생목록" 버튼이 안 보이거나 한도 안내 표시
전화번호 자동 포맷 연락처에 01012345678 입력 자동으로 010-1234-5678로 변환
허용 안 되는 파일 기업 인증에서 .exe 파일 첨부 "허용되지 않는 파일 형식" 에러
키보드 곡 이동 곡 재생 중 키보드 ↑↓ 누르기 이전/다음 곡으로 이동

4. 테스트는 이런 식으로 해요

어렵게 생각하지 마세요. 그냥 사이트를 써보면서 이상한 점을 찾는 거예요!

자유롭게 써보기 (탐색적 테스트)

정해진 순서 없이 이것저것 눌러보세요. "어? 이거 좀 이상한데?" 하는 게 있으면 그게 버그일 수 있어요.

처음부터 끝까지 해보기 (시나리오 테스트)

예를 들어: 회원가입 → 로그인 → 구독 가입 → 음원 검색 → 다운로드 → 라이선스 확인. 이런 식으로 실제로 쓰듯이 해보는 거예요.

극단적으로 해보기 (경계값 테스트)

입력란에 일부러 이상한 값을 넣어보세요.

  • 닉네임: 1글자만 (너무 짧음) / 30글자 (너무 김)
  • 비밀번호: 7자 (부족) / 공백만
  • BPM: 0 / 1000 / 글자 입력
  • 전화번호: 숫자 아닌 것 / 너무 짧은 번호

상태가 바뀌는 것 확인하기

구독 상태나 기업 인증 상태가 바뀔 때 화면이 제대로 반응하는지 확인해보세요.

  • 구독: 없음 → 활성 → 취소됨 → 만료
  • 기업 인증: 없음 → 심사중 → 승인/반려
  • 문의: 접수 → 처리중 → 해결 → 종료

5. 문제를 발견하면 이렇게 알려주세요

SR(수정 요청)이라는 양식으로 알려주시면 저희가 빠르게 고칠 수 있어요.

핵심: SR 번호는 비워두세요. 최종 번호는 운영 측에서 붙입니다. 원인 분석보다 환경 / 페이지 / 현상 / 재현 방법을 정확히 적는 게 더 중요해요.

SR 양식

# SR-XX 제목 (뭐가 문제인지 한 줄로)

## 분류
- [ ] 버그 (안 되는 것)
- [ ] 개선 (불편한 것)
- [ ] 기능 요청 (있으면 좋겠는 것)
- [ ] UI/UX (디자인/사용성)

## 심각도
- [ ] HIGH (아예 못 씀)
- [ ] MEDIUM (불편하지만 다른 방법 있음)
- [ ] LOW (있으면 좋겠는 정도)

## 환경
- 기기: (갤럭시 S24, 아이폰 15, PC 등)
- OS: (안드로이드 14, iOS 17, Windows 11 등)
- 브라우저: (크롬, 사파리, 카톡 인앱 등)
- 페이지/경로: (/tracks, 앨범 상세, 플레이어바 등)
- 계정 상태: (비로그인 / 일반회원 / 스탠다드 구독 / 관리자)

## 어떤 상황이었나요?
지금 이렇게 동작해요. (스크린샷 있으면 첨부!)

## 원래 이렇게 됐으면 좋겠어요
이렇게 되는 게 맞을 것 같아요.

## 다시 해보려면
1. OO 페이지에 갔는데
2. OO 버튼을 눌렀더니
3. OO가 발생했어요

## 기타
추가로 하고 싶은 말

예시

SR-XX: 모바일에서 회원가입 버튼이 잘려요

분류: UI/UX
심각도: MEDIUM
환경: 갤럭시 A17, Android 16, 카카오톡 인앱 브라우저, /signup, 비로그인

상황: 회원가입 페이지에서 모든 정보를 입력한 후 "가입하기" 버튼이 화면 아래로 잘려서 스크롤을 해야 보여요.
