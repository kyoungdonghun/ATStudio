# SR-24

## 대상 화면

상단 내비게이션 > 재생 목록 페이지

---

## 수정 내용

회원이지만 구독하지 않은 계정임에도 불구하고 상단 내비게이션의 재생 목록 메뉴 클릭 시 재생 목록 페이지에 접근이 가능한 문제가 있음.

- 실제 비즈니스 로직에서는 재생 목록 생성 시 구독 여부를 확인하여 예외가 정상적으로 발생하고 있음.
- 하지만 페이지 접근 자체는 사전에 차단되지 않고 있는 상태임.
- 해당 기능은 설계상 구독 사용자만 접근 가능한 기능이므로 페이지 진입 단계에서부터 접근이 제한되어야 함.
- 현재 스프링 시큐리티 설정을 확인하여 단순 로그인 기준으로 접근 허용되어 있는지 또는 구독 여부까지 권한 조건에 포함되어 있는지 확인한다.
- 확인 결과를 기반으로 구독 여부까지 포함한 권한 체크 로직을 적용하고, 재생 목록 페이지 접근 시 미구독자는 접근 차단 또는 구독 유도 처리가 되도록 수정한다.
- 필요 시 Controller, Service, Security Config 전반을 점검하여 일관된 권한 제어가 이루어지도록 개선한다.
