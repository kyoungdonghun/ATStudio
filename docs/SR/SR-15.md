# SR-15 관리자 라이선스 관리 사용자 아이디 검색 Validation 수정

## 대상 화면

-   관리자 페이지 \> 라이선스 관리

## 수정 내용

-   라이선스 관리 화면에서 사용자 아이디 입력 검색란의 입력 제한이
    비정상적으로 동작하는 문제 확인.
-   현재 일부 영어 문자만 입력 가능하거나 입력 가능한 문자 수 또는
    형식이 제한되는 현상이 발생하고 있음.
-   해당 입력 필드에서 말하는 사용자 아이디가 회원 로그인 아이디를
    의미하는 것인지 확인한다.
-   로그인 아이디 기준 검색이라면 입력 필드에 적용된 정규 표현식(Regex)
    및 Validation 로직을 점검한다.
-   사용자 아이디 검색 기능이 정상적으로 동작하도록 입력 검증 로직을
    수정 및 개선한다.
