# SR-71 하단 플레이어 반복재생 3단계 유지 + 아이콘 단순 도형화 + 색상/도형 분리

> **우선 가치**: 작업 수행 전, 현재 반복재생 3단계(끔/전체/한곡)의 아이콘과 색상이 어떻게 적용되어 있는지 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC, 모바일 공통

## 배경

- SR-44에서 2단계(끔/전체반복)로 변경하기로 했으나, 클라이언트 피드백에 따라 3단계(끔 → 전체반복 → 한곡반복) 유지로 번복
- 기존 문제: hover 시 active 색상이 덮여서 상태 구분 불가 + 한곡 반복 시 이모지가 이질적
- 메인 색상이 초록/흰색이라 색상만으로 3단계를 구분하기 어려울 수 있음

## 수정 내용

- 반복재생 아이콘을 단순 도형으로 통일
- 3단계를 색상 또는 도형 변화로 명확히 구분
- 색상만으로 구분이 어색한 경우, 단순화된 도형의 모양을 단계별로 다르게 하거나 어색하지 않은 색상 조합을 제안할 것
- hover 시에도 현재 상태 색상이 유지되도록 (기존 hover 덮어쓰기 문제 포함 수정)
- 다크 모드, 라이트 모드 모두 동일 적용
