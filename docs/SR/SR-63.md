# SR-63 🐛 음원 재생바 seek 시 다음 곡으로 넘어감

> **우선 가치**: 작업 수행 전, 프로그레스바 seek 시 실제로 다음 곡으로 넘어가는지 재현하고, 오디오 이벤트 핸들러(ended, timeupdate 등)에서 seek과 재생 완료를 혼동하는지 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC

## 현상

- 재생 중 프로그레스바를 중간으로 이동(seek)하면 다음 곡으로 넘어가는 오류

## 수정 내용

- seek 시 현재 곡의 해당 위치에서 정상 재생되도록 수정
