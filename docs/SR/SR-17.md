# SR-17

## 대상 화면

하단 음원 재생바 (큐바 플레이어)

---

## 수정 내용

현재 다크 모드 ↔ 화이트 테마 전환 시 하단 음원 재생바(큐바)의 UI 색상은 일부 변경되지만, 텍스트 및 세부 요소의 색상이 제대로 적용되지 않는 문제가 있음.

- 화이트 테마 적용 시 텍스트 가독성, 아이콘 색상, 배경 대비 등이 적절하게 반영되지 않는 부분을 전반적으로 점검한다.
- 테마 전환 시 재생바 전체 UI(텍스트, 아이콘, 버튼, 진행바 등)가 일관된 색상 규칙을 따르도록 수정한다.
- 다크 모드 / 화이트 테마 모두에서 UI가 자연스럽고 가독성 있게 표시되도록 스타일을 개선한다.
