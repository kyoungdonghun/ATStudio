# SR-49 회원가입 닉네임 띄어쓰기 불허 Validation

> **전수조사 결과**: 이미 구현 완료됨 — 추가 작업 불필요

## 환경

- PC

## 조사 결과

- **프론트**: `validation.ts` — `NICKNAME_PATTERN = /^[가-힣a-zA-Z0-9_]+$/` 공백 미포함, 이미 불허
- **백엔드**: `ValidationConstants.java` — 동일 패턴 적용, `@Pattern` 어노테이션으로 검증
- **에러 메시지**: "닉네임은 2~20자의 한글, 영문, 숫자, 밑줄(_)만 사용할 수 있습니다."

## 상태

- **NOT CONFIRMED** — FE + BE 양쪽 모두 이미 공백 불허 처리됨
