# SR-27

## 대상 화면

하단 음원 재생바 (큐바 플레이어) > 구매하기 버튼

---

## 수정 내용

현재 하단 재생바의 구매하기 버튼 클릭 시 아무런 반응이 발생하지 않는 문제가 있음.

- 해당 버튼의 기능 의도 및 역할이 명확하지 않거나 구현이 누락된 상태로 판단됨.

우선 다음 사항을 확인한다.

- 구매하기 버튼의 기획 의도 (개별 음원 구매, 구독 유도, 라이선스 구매 등)
- 현재 기능이 실제로 구현되어 있는지 여부

기능 의도가 정의되어 있는 경우 클릭 시 정상적으로 동작하도록 이벤트 및 로직을 구현 또는 수정한다.

### 사용자 상태별 권한 분기 처리

| 사용자 상태 | 처리 방식 |
|---|---|
| 비회원 | 로그인 또는 회원가입 유도 |
| 회원 (비구독자) | 구독 안내 또는 결제 페이지 이동 |
| 회원 (구독자) | 버튼 비노출 또는 비활성화 처리 |
| 관리자 | 버튼 비노출 처리 |

- 권한 기준에 따라 버튼 노출 여부, 클릭 이벤트, 사용자 안내 흐름이 일관되게 동작하도록 수정한다.

> 해당 작업은 기능 정의 확인 → 권한 정책 정리 → UI 및 이벤트 구현 순으로 진행한다.
