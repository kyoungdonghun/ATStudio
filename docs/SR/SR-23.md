# SR-23

## 대상 화면

하단 음원 재생바 (큐바 플레이어) > 대기열 버튼 영역

---

## 수정 내용

데스크톱 화면에서 큐바 플레이어의 대기열 버튼 텍스트가 세로로 표시되는 레이아웃 깨짐 현상이 발생하고 있음.

- 해당 문제로 인해 버튼 UI가 비정상적으로 보이며 사용자 경험이 저하되는 상태임.
- 데스크톱 해상도 기준으로 버튼 영역의 width, flex 설정, 텍스트 줄바꿈 처리 등을 점검하여 텍스트가 정상적으로 가로로 표시되도록 수정한다.
- 반응형 구조에서 모바일 / 태블릿 / 데스크톱 각각의 breakpoint에 따라 레이아웃이 깨지지 않도록 스타일을 재조정한다.
- 특히 white-space, flex/grid 설정, overflow 및 줄바꿈 관련 CSS 등을 점검하여 텍스트 표현 방식이 의도대로 유지되도록 개선한다.
