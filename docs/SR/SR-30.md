# SR-30

## 대상 화면

문의 게시판 > 일반 사용자용 문의 목록 화면

---

## 수정 내용

일반 사용자가 작성한 문의글이 관리자 페이지에서는 조회되지만 일반 사용자용 문의 게시판에서는 표시되지 않는 문제가 있음.

### 현재 상태

- 관리자 화면에서는 조회 가능
- 일반 사용자 화면에서는 문의글이 조회되지 않음

---

- 문의 게시판의 노출 정책을 확인하여 본인 작성 문의글은 사용자 본인에게 정상적으로 노출되도록 수정한다.
- 문의글 상태(비공개, 처리 상태 등)에 따른 필터 조건을 점검한다.
- 조회 API 및 쿼리 조건을 수정하여 정상적인 데이터 노출이 이루어지도록 개선한다.
