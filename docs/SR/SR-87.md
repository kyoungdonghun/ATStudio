# SR-79 앨범/좋아요/재생목록 페이지 방향키 이동 및 재생 상태 UI 동기화

> **우선 가치**: 작업 수행 전, SR-40에서 구현된 키보드 방향키 이동 기능이 어떤 페이지에서 동작하고 어떤 페이지에서 동작하지 않는지, 플레이어바 next 동작 시 각 리스트의 재생 상태 UI가 어떻게 업데이트되는지 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC

## 현상

### 1. 방향키(↑↓) 이동 미동작

- **앨범 상세 페이지**: 아래 방향키가 작동하지 않음
- **좋아요 페이지**: 아래 방향키가 작동하지 않음 (플레이어바 next는 정상)
- **재생목록 페이지**: 아래 방향키가 작동하지 않음 (플레이어바 next는 정상)

SR-40(음원 목록 키보드 방향키 곡 이동 재생)이 음원 목록 페이지에만 적용되어 있고, 위 페이지들에는 적용되지 않은 것으로 보임.

### 2. 앨범 상세 페이지 재생 상태 UI 미동기화

- 앨범 상세 페이지에서 플레이어바의 next 버튼으로 다음 곡 재생은 되지만, 앨범 내 음원 목록의 플레이 버튼이 현재 재생 중인 곡에 맞게 갱신되지 않음
- 사용자가 어떤 곡이 재생 중인지 리스트에서 시각적으로 확인 불가 → UX 방해

## 수정 내용

- 앨범 상세, 좋아요, 재생목록 페이지에서도 방향키(↑↓) 이동 지원
- SR-40의 사이드이펙트 방지 원칙 동일하게 적용 (해당 페이지가 아닌 곳에서 오동작 금지)
- 앨범 상세 페이지 음원 목록의 재생 상태 표시(플레이 버튼 등)가 현재 재생 중인 곡과 동기화되도록 수정
