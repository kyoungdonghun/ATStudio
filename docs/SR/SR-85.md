# SR-85 모바일 네비게이션 로그인/닉네임 직접 노출

> **우선 가치**: 현재 모바일 네비가 햄버거(≡) 메뉴 안에 로그인이 2뎁스로 숨어있는 구조를 확인한 후, 로그인 버튼/닉네임을 1뎁스로 끌어올린다.

## 환경

- 모바일 전용
- 파일: `frontend/src/layouts/Header.tsx`, `Header.module.css`

## 현상

- 현재 모바일 네비: 햄버거(≡) → 메뉴 열기 → 로그인 클릭 (2뎁스)
- 로그인 상태일 때도 햄버거 내부에 프로필/로그아웃 위치

## 수정 내용

### 1. 비로그인 상태

- 햄버거 메뉴 밖(네비 상단 바)에 **"로그인" 버튼 직접 노출**
- 클릭 시 `/login`으로 이동
- 기존 햄버거 메뉴는 나머지 메뉴용으로 그대로 유지

### 2. 로그인 상태

- 햄버거 메뉴 밖에 **닉네임 표시** (로그인 버튼 자리 대체)
- 닉네임 클릭 시 동작: **기존 햄버거 메뉴 드롭다운과 동일** (로그아웃, 프로필 등 나열)
- 즉, 햄버거 + 닉네임 두 진입점이 같은 메뉴를 엽니다
- 또는 닉네임은 시각적 표시만 + 실제 메뉴는 햄버거 그대로 (선택: 클라이언트 확인 필요)

## 확인 사항

- 햄버거 메뉴의 기존 구조 유지 여부 — 나머지 메뉴는 현행 유지 요청
- 로그인 버튼 + 햄버거 버튼의 가로 배치 공간 (모바일 ≤767px에서 텍스트 길이 충분한지)
- 로그인 버튼 스타일 — 간결하게 (아이콘+텍스트 또는 텍스트만)
