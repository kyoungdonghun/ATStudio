# SR-39 앨범 상세 음원 리스트 테이블 스타일 통일

## 대상 화면

- 음원 목록 (TrackListPage) — 기준 화면
- 앨범 상세 내 음원 리스트 (AlbumDetailPage) — 수정 대상

## 현상

비회원 기준으로 앨범 상세 페이지의 음원 리스트 테이블이 음원 목록 페이지의 테이블과 스타일이 다르다. thead의 th, tbody의 td 스타일이 미세하게 불일치하며 전체적인 테이블 통일감이 떨어진다.

## 작업 절차

1. **분석**: 음원 목록 테이블의 th/td CSS 스타일을 기준으로 분석
2. **비교**: 앨범 상세 음원 리스트의 th/td 스타일과 차이점을 도출
3. **보고**: 차이점을 정리하여 보고
4. **제안**: 어떻게 수정할 것인지 방향 제안
5. **승인**: 승인 후 수정 진행

## 사전 확인 사항 (코드 검토 결과)

### 구조 차이

- 음원 목록: 7개 컬럼 (#, 음원, 장르/태그, BPM, 조성, 길이, 액션), 재사용 컴포넌트(TrackRow)로 행 렌더링
- 앨범 상세: 4개 컬럼 (#, 음원, 순서, 빈 열), 인라인 tr/td 마크업으로 행 렌더링

### 스타일 차이

| 항목 | 음원 목록 | 앨범 상세 |
|------|----------|----------|
| 썸네일 크기 | 40×40px | 38×38px |
| 행 구현 방식 | TrackRow 컴포넌트 위임 | 인라인 마크업 |
| 컬럼 너비 지정 | CSS 클래스 | 인라인 style 속성 혼용 |
| 액션 버튼 스타일 | 통일된 actBtn 패턴 | 개별 버튼 클래스 |
| 반응형 처리 | 태블릿/모바일별 컬럼 숨김 | min-width 400px 단일 처리 |

## 수정 방향

앨범 상세의 음원 리스트 테이블 스타일(th/td padding, font-size, 색상, 정렬 등)을 음원 목록 기준에 맞춘다. 컬럼 수와 내용이 다른 것은 화면 목적이 다르므로 유지하되, 공통되는 시각적 요소(글꼴, 간격, 호버 효과, 썸네일 크기 등)를 통일한다.

구체적인 수정 범위와 방식은 클로드 코드가 코드를 확인한 후 결정한다. 더 나은 방향이 있다면 적극적으로 제안한다.
