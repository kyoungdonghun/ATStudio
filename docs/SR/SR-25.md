# SR-25

## 대상 화면

상단 내비게이션 > 다운로드 페이지

---

## 수정 내용

현재 구독하지 않은 회원 계정으로도 다운로드 페이지 접근이 가능한 상태임.

- 해당 페이지는 서비스 구조상 구독 기반 기능과 직접적으로 연결된 영역이므로 접근 정책에 대한 명확한 정의가 필요함.
- 우선 현재 비즈니스 정책 기준으로 다운로드 페이지가 비구독자에게도 공개 가능한 영역인지 또는 구독자 전용 영역인지를 명확히 정의한다.

정책 검토 후 다음 중 하나의 방향으로 처리한다.

### ① 접근 제한 방식

- 다운로드 페이지 자체를 구독 사용자만 접근 가능하도록 제한한다.
- 비구독자가 접근 시 접근 차단 및 구독 안내 메시지 또는 페이지로 리다이렉트 처리한다.

### ② 접근 허용 + 유도 방식

- 다운로드 페이지 접근은 허용하되, 실제 다운로드 기능 실행 시 구독 여부를 체크하여 차단한다.
- 페이지 내에서 구독 시 다운로드 가능 안내 문구 및 구독 유도 UI를 제공하여 사용자 전환을 유도한다.

---

- 서비스 특성상 사용자 전환을 고려하여 접근 허용 + 구독 유도 방식이 적절한지 검토한다.
- 최종 방향 결정 후 스프링 시큐리티 권한 설정, 페이지 접근 제어 로직, 다운로드 기능 실행 시 권한 체크를 일관되게 적용한다.
