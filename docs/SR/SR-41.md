# SR-41 입력값 Validation 정책 전수조사 및 적용

## 목적

프론트엔드와 백엔드 전체에 걸쳐, 모든 입력 필드에 대한 Validation 정책을 수립하고 적용한다.

## 중요가치
공통 util으로 정리하여, 불필요한 중복을 최소화 한다.

## 작업 절차

### Phase 1 — 전수조사

프론트엔드와 백엔드를 상세하고 세밀하게 조사하여, Validation이 필요한 모든 입력 지점을 목록화한다. 각 입력 필드별로 현재 적용된 Validation 상태와 누락된 부분을 파악한다.

### Phase 2 — 입력값 제한 제안

전수조사 결과를 바탕으로, 각 입력 필드에 대해 적용할 Validation 규칙(최소/최대 길이, 허용 문자, 형식, 필수 여부 등)을 정리하여 제안한다.

### Phase 3 — 승인 후 적용

제안된 입력값 제한에 대해 사용자 컨펌을 받은 뒤, 프론트엔드와 백엔드 양쪽에 Validation을 구현한다.

## 수정 방향

구체적인 조사 범위, Validation 규칙, 구현 방식은 클로드 코드가 실제 코드를 확인한 후 결정한다. 더 나은 방향이 있다면 적극적으로 제안한다.
