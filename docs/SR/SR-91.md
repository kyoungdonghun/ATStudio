# SR-91 음원 목록 태그 분류 UI 3분할

> **우선 가치**: 이번 변경은 실험적 테스트 성격이므로, 구현 변경은 별도 브랜치 또는 독립 커밋으로 격리해 언제든 되돌릴 수 있어야 한다. 되돌림 시에는 음원 목록의 태그 표시와 태그 필터/선택 영역을 기존 상태로 복구할 수 있어야 한다.

## 환경

- 기기: PC
- OS: Windows 계열로 추정 (확인 필요)
- 브라우저: 확인 필요
- 페이지/경로: 음원 목록 화면 (`/tracks` 또는 대응 라우트 확인 필요)
- 계정 상태: 관리자 로그인 화면에서 확인됨 (`adminuser`)

## 배경

- 현재 음원 목록 테이블은 `장르 / 태그` 한 컬럼에 장르, 악기, 분위기 성격의 태그를 모두 섞어 표시한다.
- 클라이언트 테스트 관점에서는 태그의 의미가 한눈에 구분되지 않아, 음악 탐색 시 정보 구조가 흐려진다.
- 상단 태그 필터/선택 영역에는 `장르`, `분위기`, `BPM`만 보이고, DB에는 존재하는 `악기` 분류가 UI에 노출되지 않는다.

## 현상

- 음원 목록 행의 태그 영역이 `장르 / 태그` 한 영역으로만 제공되어 모든 태그가 동일한 배지 목록처럼 표시된다.
- 사용자는 특정 곡의 장르, 사용 악기, 분위기를 컬럼 단위로 구분해서 보기 어렵다.
- 상단 태그 선택/필터 영역에서 `악기` 섹션이 누락되어, DB에 있는 악기 태그를 목록 필터에서 사용할 수 없다.

## 기대 동작

- 음원 목록 테이블의 태그 표시 영역을 `장르`, `악기`, `분위기` 세 영역으로 분리한다.
- 각 영역에는 해당 분류에 속한 태그만 표시한다.
- 상단 태그 선택/필터 영역에도 `악기` 섹션을 추가해 `장르 / 악기 / 분위기 / BPM` 구조로 정렬한다.
- 기존 태그 선택, 필터링, 접기/펼치기, 정렬, 재생/좋아요/다운로드 동작은 회귀 없이 유지한다.

## 수정 내용

### 1. 음원 목록 태그 컬럼 3분할

- 기존 `장르 / 태그` 컬럼을 `장르`, `악기`, `분위기`로 분리한다.
- 각 곡의 태그 데이터는 분류 기준에 따라 해당 컬럼에만 표시한다.
- 특정 분류의 태그가 없는 경우 빈 영역으로 두되, 행 높이와 정렬이 깨지지 않도록 한다.
- 컬럼 폭은 기존 BPM, 조성, 길이, 액션 영역을 침범하지 않도록 조정한다.

### 2. 태그 선택/필터 영역에 악기 섹션 추가

- 상단 필터 영역에 `악기` 행 또는 섹션을 추가한다.
- DB/백엔드에서 제공되는 악기 태그가 이미 있다면 기존 API 응답을 우선 활용한다.
- 프론트엔드에서 장르/분위기만 하드코딩하고 있다면 악기 분류도 동일한 패턴으로 추가한다.
- 기존 `장르`, `분위기`, `BPM` 필터 동작과 선택 상태 표시를 유지한다.

### 3. 되돌림 가능성 확보

- 이 SR은 실험적 테스트이므로 구현 변경은 전용 브랜치 또는 독립 커밋으로 격리한다.
- 구현 완료 후 변경 파일과 검증 결과를 명확히 기록한다.
- 되돌림이 필요하면 해당 브랜치 폐기 또는 SR-91 커밋 revert로 원복할 수 있어야 한다.

## 재현 방법

1. 관리자 또는 일반 사용자로 음원 목록 화면에 접속한다.
2. 음원 목록 테이블에서 `장르 / 태그` 컬럼을 확인한다.
3. 태그가 장르, 악기, 분위기 구분 없이 한 영역에 섞여 표시되는지 확인한다.
4. 상단 태그 선택/필터 영역을 확인한다.
5. `장르`, `분위기`, `BPM`은 있으나 `악기` 섹션이 없는지 확인한다.

## 확인 사항

- 실제 태그 데이터 모델/API가 `GENRE`, `INSTRUMENT`, `MOOD` 또는 동등한 분류 값을 제공하는지 확인한다.
- 기존 화면에서 `장르 / 태그` 컬럼이 사용되는 모든 목록 화면 영향 범위를 확인한다.
- 모바일 레이아웃에서 3분할 컬럼이 과도하게 좁아지는 경우 별도 축약 정책이 필요한지 확인한다.

## 비고

- 사용자가 첨부한 1번 이미지는 현재 한 영역에 모든 태그가 표시되는 상태를 보여준다.
- 사용자가 첨부한 2번 이미지는 `장르 / 악기 / 분위기` 3분할 기대 레이아웃을 표시한다.
- 사용자가 첨부한 3번 이미지는 상단 태그 선택/필터 영역에서 `악기` 섹션이 누락된 상태를 표시한다.
