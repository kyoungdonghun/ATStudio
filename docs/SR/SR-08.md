# SR-08 공지 상세 첨부파일 다운로드 기능 확인 및 구현

## 대상 화면

-   공지 페이지 \> 공지 상세 화면

## 수정 내용

-   공지 게시글 조회 시 본문 내용만 표시되고 첨부파일 다운로드 영역이
    표시되지 않는 상태임.
-   기존 요구사항에 첨부파일 다운로드 기능이 포함되어 있는지 여부를
    확인한다.
-   기능이 구현되지 않은 경우 공지 상세 화면에 첨부파일 다운로드 영역을
    추가하여 파일 다운로드 기능을 구현한다.
-   첨부파일이 존재할 경우 다운로드 가능한 파일 목록을 표시하도록
    구성한다.
