# SR-22

## 대상 화면

메인 화면 > 메인 배너 영역

---

## 수정 내용

라이트 모드에서 메인 배너의 문구 텍스트가 배경 색상과 유사하여 가독성이 떨어지는 문제가 있음.

- 현재 텍스트 컬러와 배너 배경 컬러 간의 명도/대비 차이가 부족하여 일부 구간에서 문구가 가려지는 현상이 발생함.
- 라이트 모드 기준으로 텍스트 컬러를 조정하거나 배경 컬러 또는 오버레이를 수정하여 텍스트 가독성이 확보되도록 디자인을 개선한다.
- 필요 시 텍스트 그림자(text-shadow), 반투명 오버레이, 강조 색상 등을 활용하여 시인성을 보완한다.
- 다크 모드와 라이트 모드 모두에서 일관된 가독성이 유지되도록 테마별 스타일을 점검 및 개선한다.
