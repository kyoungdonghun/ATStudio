# SR-62 🐛 재생목록 모달 중복 추가 시 오류 메시지 미표시

> **우선 가치**: 작업 수행 전, 재생목록 모달(AddToPlaylistModal)의 에러 핸들링 구조를 파악한다.

## 환경

- PC

## 현상

- 대기열(다운로드 큐) 중복 추가 시 토스트는 5개 페이지 모두 정상 동작 (409 → "이미 대기열에 있는 음원입니다.")
- **문제**: 재생목록 모달(`AddToPlaylistModal`)에서 이미 추가된 트랙을 재추가하면 "추가에 실패했습니다" 제네릭 메시지만 표시
- 백엔드는 409 + `RESOURCE_DUPLICATE` 정상 반환하지만, 프론트 모달에서 409 분기 없음

## 원인 분석

- `AddToPlaylistModal.tsx:58-64` — catch 블록에서 `isSubscriptionRequired`만 체크, 나머지는 전부 `setResult('error')` → "추가에 실패했습니다"
- 백엔드 `PlaylistService.java:119-122` — `existsById()` 체크 후 `RESOURCE_DUPLICATE`(409) 정상 반환

## 수정 내용

- `AddToPlaylistModal.tsx` catch 블록에 409 / `RESOURCE_DUPLICATE` 분기 추가
- "이미 재생목록에 추가된 트랙입니다." 등 구체적 메시지 표시
