# SR-54 음원 리스트 좋아요 상태 지속 표시 (hover 없이 상시 노출)

> **우선 가치**: 작업 수행 전, 현재 좋아요 버튼(♥)의 상태 표시가 어떻게 동작하는지(API 응답에 liked 필드가 있는지, 프론트에서 상태를 유지하는지) 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC

## 현상

- 좋아요 상태(♥) 데이터 자체는 전역 Zustand store(`likeStore`)로 정상 유지됨
- **문제**: 좋아요 버튼이 `.actions` 컨테이너 안에 있고, `.actions`는 기본 `opacity: 0` → `row:hover` 시에만 `opacity: 1`
- 따라서 **마우스를 올리지 않으면 ♥ 표시 자체가 보이지 않음** → 좋아요한 곡을 한눈에 구분 불가

## 수정 내용

- 좋아요된 곡(♥)은 hover 여부와 관계없이 항상 표시되도록 수정
- 방법: `.actions` 내 `.liked` 버튼이 있을 때 해당 버튼만 상시 노출하거나, ♥ 버튼을 `.actions` 밖으로 분리

## 원인 분석

- `TrackRow.module.css` — `.actions { opacity: 0; }` + `.row:hover .actions { opacity: 1; }`
- `.liked` 클래스는 색상만 변경, 부모의 `opacity: 0`을 오버라이드하지 못함
