# SR-74 🐛 음원 업로드 타임아웃 + Content-Type 문제 (iOS/Safari)

> **우선 가치**: 작업 수행 전, 다음을 명확하게 파악한다: (1) iOS/Safari에서 Content-Type이 어떻게 전송되는지, (2) 현재 업로드 용량 제한이 곡당인지 전체인지, (3) Axios 타임아웃 설정값. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- iOS (애플 스마트폰), macOS Safari
- 크롬에서는 미재현 가능성

## 현상

- 음원 업로드 시 `timeout of 15000ms exceeded` 오류 발생
- MP3는 업로드 가능하나 WAV 등 대용량 파일에서 실패
- 사파리에서 MP3, WAV 모두 500 에러 발생하는 경우도 있음
- Content-Type 관련 문제 가능성

## 수정 내용

- iOS/Safari에서의 Content-Type 처리 확인 및 수정
- 업로드 용량 제한을 **곡당 30MB**로 설정 (멀티 업로드 시 각 곡 개별 적용)
- 여러 곡 합산이 아닌 곡당 제한으로, 멀티 업로드 시 뜻하지 않은 오류 방지
- 대용량 파일 업로드를 위한 타임아웃 설정 조정
- WAV 파일(곡당 30MB 이내)이 정상 업로드되는지 확인
