# SR-72 구독 시 기본 재생목록 자동 생성 (SR-53 변경)

> **우선 가치**: 작업 수행 전, 현재 구독 완료 후 재생목록이 비어 있는 상태에서 사용자 플로우가 어떻게 되는지, 백엔드에서 구독 처리 시 기본 데이터 생성 로직이 있는지 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC

## 배경

- SR-53에서 "최초 가입 시" 기본 재생목록 생성으로 작성했으나, 클라이언트 피드백에 따라 "구독 시"로 변경
- 가입이 아닌 구독을 했을 때 기본 재생목록이 생성되어야 함

## 수정 내용

- 구독 완료 시 기본 재생목록 하나를 자동 생성
- 곡 추가 시 기본 재생목록에 바로 추가되도록
- 기본 재생목록 이름은 사용자가 추후 변경 가능
- "재생목록이 없으니 먼저 만들라"는 상황 방지
