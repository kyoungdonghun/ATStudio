# SR-20

## 대상 화면

앨범 페이지 > 카드 뷰 / 리스트 뷰

---

## 수정 내용

현재 앨범 페이지에서는 카드 뷰 및 리스트 뷰 모두 정렬 기능이 제공되지 않는 상태임.

- 음원 페이지와 동일하게 정렬 기능(예: 인기순, 최신순 등)을 제공할 필요가 있음.
- 우선 프로젝트의 DB 스키마 및 API 구조를 확인하여 앨범 단위에서 활용 가능한 정렬 기준(좋아요 수, 생성일 등)이 존재하는지 분석한다.
- 앨범 특성상 음원을 묶는 구조이므로 다운로드 수와 같은 지표가 앨범 단위로 집계되지 않았을 가능성이 있으므로 해당 부분을 확인한다.
- 현재 가능한 데이터 기준으로 적용 가능한 정렬 기준을 정의하고, 부족한 데이터가 있을 경우 앨범 기준 집계 로직(예: 앨범 내 음원 다운로드 합계 등)을 설계한다.
- 설계 결과를 기반으로 앨범 정렬 기준을 정의하고 카드 뷰 / 리스트 뷰 모두에서 동일하게 정렬 기능을 적용할 수 있도록 구현한다.

> 해당 작업은 단순 UI 수정이 아닌 데이터 구조 분석 + 정렬 기준 정의 + 필요 시 집계 로직 설계 및 구현까지 포함하는 설계형 작업으로 진행한다.
