# SR-60 🐛 비활성 음원 수정 시 조회 실패

> **우선 가치**: 작업 수행 전, 관리자 음원 목록에서 비활성 트랙의 수정 흐름을 정확히 파악한다.

## 환경

- PC (관리자)

## 현상

- 관리자 음원 목록(`TrackManagePage`)에서 비활성(soft-deleted) 트랙도 표시되고 수정 버튼 존재
- 수정 클릭 → `TrackEditPage` → `GET /api/tracks/{id}` → `getTrack()` 호출
- `TrackService.getTrack()` 에서 `isActive()` 체크 → 비활성이면 `TRACK_NOT_FOUND` 예외 발생
- **에러**: "trackId에 해당하는 Track이 존재하지 않습니다."

## 원인 분석

- `TrackService.java:126-127` — `getTrack()`이 `isActive` 체크로 비활성 트랙 차단
- 반면 `updateTrack()`은 `findTrackById()`를 사용하여 `isActive` 체크 없음
- 즉, **데이터 로딩만 실패**하고 수정 자체는 가능한 구조

## 수정 내용

- 관리자용 트랙 상세 조회 시 `isActive` 체크를 건너뛰는 방법 적용
- 방법: 관리자 전용 엔드포인트 추가 또는 기존 `getTrack()`에 관리자 권한 시 `isActive` 체크 스킵
