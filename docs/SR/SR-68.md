# SR-68 앨범 업로드 이미지 사이즈 보장 + 반응형 레이아웃 깨짐 수정

> **우선 가치**: 작업 수행 전, 앨범 이미지가 표시되는 모든 화면(업로드 폼, 앨범 카드, 앨범 상세 등)을 파악하고, 각 화면에서 이미지 크기에 따른 레이아웃 영향을 확인한다.

## 환경

- PC, 태블릿, 모바일 공통

## 현상

- 앨범 업로드 시 이미지를 첨부하면 이미지 크기(해상도/비율)에 따라 레이아웃이 깨짐
- 큰 이미지 또는 비정상 비율 이미지 업로드 시 주변 요소가 밀리거나 영역을 초과

## 수정 내용

- 앨범 이미지 표시 영역에 고정 크기/비율 보장
  - `object-fit: cover` 또는 동등한 방식으로 이미지가 영역을 벗어나지 않도록 처리
  - 컨테이너 `max-width` / `max-height` 제한으로 레이아웃 보호
- **반응형 브레이크포인트별 이미지 크기 대응**
  - 데스크탑 → 태블릿 → 모바일 각 뷰포트에서 이미지 영역이 적절히 축소/확대
  - 이미지로 인한 가로 스크롤, 요소 겹침, 텍스트 밀림 방지
- 앨범 이미지가 노출되는 모든 화면에 동일 적용 (업로드 폼 미리보기, 앨범 카드, 앨범 상세 등)
