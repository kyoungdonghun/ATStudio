# SR-75 관리자 페이지 모바일 지원 전환

> **우선 가치**: 작업 수행 전, 현재 관리자 페이지 중 모바일을 지원하는 페이지와 지원하지 않는 페이지를 전수 파악한다. 설계 문서(screen-flow, front-list 등)에서 관리자 페이지의 모바일 지원 여부가 어떻게 명시되어 있는지도 확인한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- 모바일 (관리자)

## 배경

- 기존 설계: 관리자 페이지는 모바일 미지원
- 현재 상태: 사이트 반응형 웹 작업 과정에서 일부 관리자 페이지는 모바일이 적용되고, 일부는  관리자 모바일 min width가 사용자페이지 보다 넓은 관계로 스마트폰에서는 일부 짤리는 상황 발생.
- 최초 로딩 시 짤려서 보임

## 수정 내용

- 관리자 페이지를 모바일 미지원에서 **모바일 지원으로 정책 변경**
- 설계 문서(screen-flow, front-list, 관련 설계 문서 등)에 모바일 지원으로 반영
- 관리자 페이지 전체에 min-width 를 일반 페이지와 동일하게 수정 
- 그러한 수정과정의 부수적인 이펙트로 노출되는 정보량이 많아서 레이아웃이 이상하게 나올 수 있는데, 이를 노출될 정보를 줄임으로서 해결할것.
