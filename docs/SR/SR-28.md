# SR-28

## 대상 화면

상단 내비게이션 > 구독(구독하기) 메뉴

---

## 수정 내용

관리자 계정으로 로그인 시 상단 내비게이션에서 구독 메뉴가 노출되며 클릭 시 해당 페이지로 이동이 가능한 상태임.

- 관리자 계정은 서비스 구조상 구독 대상이 아니므로 해당 기능이 노출되면 안 되는 상태임.

### 현재 상태

- 메뉴 노출됨
- 클릭 가능
- 내부적으로 접근 불가 메시지 출력됨

즉 UI, 권한, 정책이 서로 불일치하는 상태임.

---

- 기존 정책 의도에 따라 관리자 계정일 경우 상단 내비게이션에서 구독 메뉴를 비노출 처리한다.
- URL 직접 접근 시에도 접근이 차단되도록 권한 로직을 보완한다.
- 프론트 메뉴 렌더링 조건, 스프링 시큐리티 설정, 컨트롤러 접근 제어를 함께 점검하여 일관된 권한 정책이 적용되도록 수정한다.
