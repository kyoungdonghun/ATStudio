# SR-21

## 대상 화면

공지 페이지 > 공지 목록 화면

---

## 수정 내용

현재 공지 목록 화면에서는 제목과 등록일 정도의 정보만 제공되고 있으며, 추가적인 정보(조회수 등) 및 정렬 기능이 부재한 상태임.

- 사용자 편의성을 위해 조회수, 정렬 기능(예: 최신순, 조회순 등)과 같은 추가 요소 도입이 필요함.
- 우선 프로젝트의 DB 스키마를 확인하여 공지사항에 조회수(View Count) 컬럼이 존재하는지 여부를 검토한다.
- 조회수 정보가 존재하지 않을 경우, 조회수 컬럼 추가 설계 또는 단순 최신순 중심 구조 유지 등 대안 방향을 검토한다.
- 조회수 기능 도입 시 공지 상세 조회 시 조회수 증가 로직 설계 및 중복 증가 방지(세션/쿠키 기반 등) 여부를 검토한다.
- 정렬 기능 관련하여 현재 제공 중인 데이터 기준으로 가능한 정렬 옵션을 정의하고, 조회수 도입 시 조회순 정렬을 추가한다.
- 설계 결과를 기반으로 공지 목록 UI에 조회수 및 정렬 UI를 추가하고 백엔드 정렬 및 조회수 로직을 구현한다.
