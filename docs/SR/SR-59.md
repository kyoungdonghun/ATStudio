# SR-59 음원 업로드 BPM placeholder 개선

> **우선 가치**: 작업 수행 전, BPM 필드의 기본값과 placeholder가 어떻게 세팅되는지 명확하게 파악한다.

## 환경

- PC (관리자)

## 현상

- BPM 필드의 실제 기본값은 빈 문자열이며, "120"은 placeholder임
- 코드상 로직은 정상 (빈값 → 에러 메시지, 120 입력 → 유효 범위 내 통과)
- **문제**: placeholder "120"이 이미 값이 입력된 것처럼 보여서, 사용자가 수정 없이 제출 → 빈값 에러 발생 → UX 혼란

## 수정 내용

- placeholder를 "120" → "BPM을 입력해주세요" 등 명확한 안내 문구로 변경
- 사용자가 값 미입력 상태를 명확히 인지할 수 있도록 개선
