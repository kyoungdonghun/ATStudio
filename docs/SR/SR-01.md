# SR-01 메인 화면 신규 앨범 좌우 이동 기능 추가

## 대상 화면

-   메인 화면 \> 신규 앨범 섹션

## 수정 내용

-   신규 앨범 섹션에서 현재 앨범 목록 좌우 끝단에 다음 앨범으로 이동할
    수 있는 기능이 없음.
-   섹션 좌측 및 우측 끝단에 마우스 hover 시 이동 버튼이 표시되도록 UI를
    추가한다.
-   사용자가 해당 버튼을 클릭하면 다음 앨범 또는 이전 앨범 목록으로
    이동할 수 있도록 슬라이드 또는 스크롤 기능을 제공한다.
-   앨범 개수가 많을 경우 사용자가 좌우 이동을 통해 추가 앨범을 확인할
    수 있도록 한다.
