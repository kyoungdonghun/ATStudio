# SR-45 하단 플레이어 대기열 목록 초기 고정 높이 + 스크롤

> **우선 가치**: 작업 수행 전, 현재 대기열 목록이 실제로 곡 추가 시 영역이 늘어나는 구조인지 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC

## 현상

- 현재 대기열 목록은 `max-height: 360px; overflow-y: auto` 로 구현되어 있음
- 곡이 적을 때(~7개 미만)는 목록 영역이 곡 수에 따라 작아지다가, 7개 이상일 때 스크롤이 생기는 구조
- 클라이언트 요청: 곡이 적더라도 처음부터 7개 분량의 고정 높이를 유지하고, 초과 시 스크롤

## 수정 내용

- 대기열 목록 컨테이너를 `max-height` 대신 `min-height` + `max-height` 조합 또는 고정 `height`로 변경
- 곡이 0개~6개여도 7개 분량의 높이를 항상 유지
- 7개 초과 시 스크롤 동작 유지
