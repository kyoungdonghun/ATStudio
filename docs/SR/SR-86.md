# SR-86 BPM 프리셋 6단계로 변경

> **우선 가치**: 현재 BPM 프리셋이 `~80 / 80-120 / 120~` 3단계임을 파악한 후, 더 세밀한 6단계로 교체한다.

## 환경

- PC, 모바일 공통
- 파일: `frontend/src/pages/public/TrackListPage.tsx` (BPM_PRESETS 상수)

## 현상

현재 프리셋 (3단계):
```ts
[
  { label: '~ 80', min: undefined, max: 80 },
  { label: '80 – 120', min: 80, max: 120 },
  { label: '120 ~', min: 120, max: undefined },
]
```

## 수정 내용

새 프리셋 (6단계):

| Label | min | max |
|-------|-----|-----|
| `~ 59` | undefined | 59 |
| `60 – 79` | 60 | 79 |
| `80 – 99` | 80 | 99 |
| `100 – 119` | 100 | 119 |
| `120 – 139` | 120 | 139 |
| `140 ~` | 140 | undefined |

```ts
const BPM_PRESETS = [
  { label: '~ 59', min: undefined, max: 59 },
  { label: '60 – 79', min: 60, max: 79 },
  { label: '80 – 99', min: 80, max: 99 },
  { label: '100 – 119', min: 100, max: 119 },
  { label: '120 – 139', min: 120, max: 139 },
  { label: '140 ~', min: 140, max: undefined },
] as const;
```

## 확인 사항

- 프리셋 chips가 6개로 늘어나면서 모바일 가로 스크롤이 필요할 수 있음 — 기존 `.filterChips` 스크롤 CSS(SR-64)가 이미 적용되어 있어 자동 대응 예상
- 백엔드 API는 `bpmMin/bpmMax` 숫자만 받으므로 변경 불필요
