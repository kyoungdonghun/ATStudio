# SR-19

## 대상 화면

앨범 페이지 > 리스트 뷰 (테이블 형태)

---

## 수정 내용

앨범 페이지의 리스트 뷰에서 테이블 헤더(th)와 데이터(td)의 컬럼 정렬이 맞지 않는 문제가 있음.

- 예를 들어 곡 수 컬럼의 헤더 위치와 실제 데이터("n곡") 위치가 일치하지 않는 등 레이아웃 불일치가 발생하고 있음.
- 테이블 구조를 점검하여 각 컬럼의 너비 및 정렬 기준이 일관되도록 수정한다.
- 헤더와 바디 영역 간 컬럼 align, width, padding 등을 통일하여 UI 정렬이 정확하게 맞도록 개선한다.
- 리스트 뷰에서 가독성이 유지되도록 전체 테이블 레이아웃을 점검 및 보완한다.
