# SR-77 🐛 모바일 하단 플레이어 재생목록 곡 순서 드래그 앤 드롭 불가

> **우선 가치**: 작업 수행 전, 모바일에서 삼단바(드래그 핸들)로 순서 변경 시 실제로 전체 화면이 스크롤되는지 재현하고, 터치 이벤트와 스크롤 이벤트의 충돌 지점을 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- 모바일

## 현상

- 모바일 하단 플레이어 재생목록에서 삼단바(햄버거)로 곡 순서를 바꾸려 하면, 드래그 대신 전체 화면이 스크롤됨
- 터치 드래그 이벤트와 페이지 스크롤 이벤트가 충돌

## 수정 내용

- 드래그 핸들 터치 시 페이지 스크롤을 방지하고 곡 순서 변경이 정상 동작하도록 수정
