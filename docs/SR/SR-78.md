# SR-78 구독 취소 유예 기간 권한 정합성 확인 + 구매하기 버튼 문맥 변경

> **우선 가치**: 작업 수행 전, 구독 취소 유예 상태(취소 신청 후 ~ 취소 확정 전)에서 사용자 권한이 실제로 어떻게 적용되는지 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC, 모바일 공통

## 확인 사항

### 1. 구독 취소 유예 기간 중 권한 동작 확인

- 구독 취소를 신청했으나 아직 취소가 확정되지 않은(유예 기간) 사용자에 대해:
  - 상단 내비게이션(GNB)에서 재생목록, 다운로드 페이지가 정상 노출되는지
  - 해당 페이지 진입이 정상 동작하는지
  - 들어가지는 경우와 안 들어가지는 경우가 있다면 그 조건 차이를 파악
- 취소 유예 기간 동안은 구독 권한이 유지되어야 하므로, 재생목록과 다운로드가 정상 접근 가능해야 함

### 2. 하단 플레이어 구매하기 버튼 동작 확인 및 문맥 변경

- 현재 하단 플레이어의 "구매하기" 버튼이 작동하는 경우와 안 하는 경우가 있음 — 조건 파악 필요
- 현재 "구매하기"는 구독 신청(구독하기)의 의미로 사용되고 있으나, 이를 **음원을 구매한다**는 의미로 변경해야 함

## 수정 내용

- 구독 취소 유예 상태의 사용자가 재생목록, 다운로드 등 구독자 권한 기능에 정상 접근 가능하도록 확인 및 수정
- 하단 플레이어 "구매하기" 버튼의 동작 및 문맥을 구독 신청이 아닌 음원 구매로 변경
- 버튼이 작동하지 않는 케이스 원인 파악 및 수정

### 3. 구독 구매 직후 플레이어 권한 갱신 확인

- 음원 플레이어가 열려 있는 상태에서 비구독자가 구독을 구매한 경우, 플레이어 내 음원 다운로드(구매하기 버튼) 동작이 갱신된 구독 권한에 맞게 정상 작동하는지 확인
- 페이지 새로고침 없이도 구독 상태가 반영되어야 하는지, 아니면 갱신 시점에 대한 정책이 필요한지 검토
- 아직 문제가 발생하진 않았으나, 발생 가능성이 있으므로 사전 확인
