# SR-07 음원 목록 리스트 재생/정지 이벤트 수정

## 대상 화면

-   음원 목록 페이지 \> 음원 목록 리스트 섹션

## 수정 내용

-   음원 목록 리스트에서 hover 시 재생 버튼이 나타나고 클릭 시 음원이
    재생되는 기능이 있음.
-   현재는 재생 후 다시 클릭해도 정지 기능이 정상적으로 동작하지 않는
    문제가 있음.
-   큐바 플레이어와 동일하게 재생 상태에서 다시 클릭할 경우 정지되도록
    기능을 수정한다.
-   재생 상태에 따라 재생/정지 아이콘 또는 UI 상태가 변경되도록
    수정한다.
