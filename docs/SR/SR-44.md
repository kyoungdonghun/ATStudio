# SR-44 🐛 하단 플레이어 반복재생 버튼 hover 시 상태 구분 불가

> **우선 가치**: 작업 수행 전, 현재 반복재생이 몇 단계인지, 아이콘이 어떻게 변하는지 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC, 모바일 공통

## 현상 (UX 버그)

- 반복재생 3단계 토글(끔 → 전체반복 → 한곡반복) 로직 자체는 정상
- **문제**: 버튼에 마우스를 올리면(hover) active 상태의 초록색이 흰색으로 덮여서, 상태가 바뀌었는지 인지 불가
- 원인: `.ctrlBtn:hover`(특이도 0,1,1)가 `.ctrlBtnActive`(특이도 0,1,0)보다 우선 → hover 시 초록색이 흰색으로 리셋

## 수정 내용

- `.ctrlBtnActive:hover` 규칙 추가하여 hover 시에도 active 색상(초록) 유지
- 다크 모드, 라이트 모드 모두 동일 적용

## 원인 분석

- `PlayerBar.module.css` — `.ctrlBtn:hover { color: var(--player-text) }` 가 `.ctrlBtnActive { color: var(--accent) }` 를 덮어씀
- `.ctrlBtnActive:hover` 규칙이 존재하지 않음
