# SR-31

## 대상 화면

관리자 페이지 > 문의 관리 상세 화면

---

## 수정 내용

관리자 페이지에서 문의글 조회는 가능하나 해당 문의글에 대한 답변을 등록할 수 있는 기능이 존재하지 않는 상태임.

### 현재 상태

- 조회 가능
- 상태 변경 가능
- 답변 작성 불가능

---

- 문의 시스템의 핵심 기능인 답변 기능이 부재한 상태이므로 관리자 페이지에서 답변 작성 기능을 추가한다.

답변 기능 구현 시 다음 사항을 확인 및 처리한다.

- DB에 답변 저장 구조 존재 여부 확인
- 필요 시 문의글과 답변을 연결하는 구조 설계 추가

- 작성된 답변이 일반 사용자 문의 상세 화면에서도 정상적으로 표시되도록 프론트 및 백엔드 연동을 구현한다.

> 해당 작업은 기능 추가, DB 구조 검토 및 확장, 프론트/백엔드 연동을 포함한다.
