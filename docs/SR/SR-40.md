# SR-40 음원 목록 키보드 방향키(↑↓) 곡 이동 재생

## 대상 화면

- 음원 목록 (TrackListPage)

## 수정 내용

음원 목록 페이지에서 키보드 위/아래 방향키를 누르면 이전/다음 곡으로 이동하여 재생할 수 있도록 기능을 추가한다.

## 주의사항

음원 목록 페이지가 **아닌** 곳에서 방향키 입력이 의도치 않은 동작을 유발하지 않도록 사이드이펙트에 주의할 것. 이벤트 리스너의 등록/해제 범위, 포커스 상태, 다른 페이지에서의 키보드 동작(스크롤 등)과의 충돌 가능성을 검토하여 안전하게 구현한다.

구체적인 구현 방식은 클로드 코드가 코드를 확인한 후 결정한다. 더 나은 방향이 있다면 적극적으로 제안한다.
