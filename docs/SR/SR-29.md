# SR-29

## 대상 화면

문의 게시판 > 문의 목록 화면 (관리자 계정)

---

## 수정 내용

일반 사용자 계정으로 문의글을 작성한 이후 정상적으로 등록된 것을 확인했으나, 관리자 계정으로 로그인 후 문의 목록을 확인했을 때 해당 문의글이 표시되지 않는 문제가 있음.

해당 문제는 다음 두 가지 기준으로 확인한다.

- 관리자 계정에서 전체 문의글을 조회하도록 설계되어 있는지 확인
- 조회 API에서 특정 사용자 기준으로 필터링되고 있는지 확인

---

- 실제 DB에는 데이터가 존재하나 조회 조건이 잘못 적용되었을 가능성이 있으므로 쿼리 및 API 로직을 점검한다.
- 관리자 계정은 전체 문의글 조회가 가능하도록 설계되어야 하므로 조회 조건을 수정하여 전체 데이터가 표시되도록 개선한다.
- 필요 시 관리자 전용 조회 로직 또는 API를 별도로 구성한다.
