# SR-69 음원/앨범 목록 액션 버튼 hover 숨김 제거 (상시 노출)

> **우선 가치**: 작업 수행 전, hover로 숨겨진 액션 버튼이 있는 모든 컴포넌트를 빠짐없이 파악한다. 모바일 터치 기기에서 hover 불가 문제도 함께 해결한다.

## 환경

- PC, 모바일 공통

## 현상

- 음원/앨범 리스트 행의 액션 버튼(좋아요, 재생목록 추가, 다운로드, 대기열 등)이 기본 `opacity: 0`으로 숨겨져 있고, 마우스 hover 시에만 노출
- 가시성이 떨어져 기능 존재 자체를 인지하기 어려움
- 모바일 터치 기기에서는 hover 이벤트가 없어 일부 페이지에서 액션 버튼 접근 자체 불가

## 수정 대상 (6곳)

| # | 컴포넌트 | 파일 | 숨김 규칙 | 숨겨진 버튼 |
|---|----------|------|-----------|------------|
| 1 | TrackRow | `components/track/TrackRow.module.css` | `.actions { opacity: 0 }` + `.row:hover .actions { opacity: 1 }` | 좋아요, 재생목록 추가, 다운로드, 구매 |
| 2 | AlbumDetailPage | `pages/public/AlbumDetailPage.module.css` | `.tdActionsInner { opacity: 0 }` + `.trackRow:hover .tdActionsInner { opacity: 1 }` | 좋아요, 재생목록 추가, 다운로드, 대기열 |
| 3 | LikeListPage | `pages/subscriber/LikeListPage.module.css` | `.hoverActions { opacity: 0 }` + `.row:hover .hoverActions { opacity: 1 }` | 재생목록 추가, 다운로드, 대기열 |
| 4 | PlaylistDetailPage | `pages/subscriber/PlaylistDetailPage.module.css` | `.hoverActions { opacity: 0 }` + `.row:hover .hoverActions { opacity: 1 }` | 좋아요, 재생목록 추가, 다운로드, 대기열 |
| 5 | PlaylistListPage | `pages/subscriber/PlaylistListPage.module.css` | `.plOverlay { opacity: 0 }` + `.myCard:hover .plOverlay { opacity: 1 }` | 삭제, 재생 (카드 오버레이) |
| 6 | AlbumCard | `components/album/AlbumCard.module.css` | `.likeBtn { opacity: 0 }` + `.card:hover .likeBtn { opacity: 1 }` | 좋아요 (카드 오버레이) |

## 수정 내용

- 위 6곳 모두 `opacity: 0` 기본 숨김 제거 → 액션 버튼 상시 노출
- hover reveal 규칙(`:hover` → `opacity: 1`) 제거
- 기존 모바일 예외 처리(1, 2번의 `@media` 상시 노출)는 자연스럽게 불필요해짐
- 카드 오버레이(5, 6번)는 상시 노출에 맞게 스타일 조정 필요 (배경 반투명 처리 등)
