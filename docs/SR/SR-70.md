# SR-70 음원 필터 태그 재조합 검색 + UI 구조 변경

> **우선 가치**: 작업 수행 전, 현재 태그 필터의 동작 방식(전체 태그 나열, 선택 후 검색, 결과 없으면 빈 리스트)을 명확하게 파악한다. 대수선이 필요한 영역이므로 구현 전 설계를 충분히 검토한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC, 모바일 공통

## 수정 내용

### 태그 재조합 검색

- 태그를 선택하면, 해당 태그를 가진 곡들의 태그들로 필터 옵션을 재구성
- 현재 방식(전체 태그 나열 → 존재하지 않는 조합이면 결과 없음)에서, 선택할수록 유효한 태그 조합만 남도록 변경

### UI 구조 변경

- "추가 옵션" 제거
- 추가 옵션 대신 "초기화" 버튼만 남김
- 각 태그 카테고리(장르, 분위기 등) 우측에 "펼치기" 버튼 추가 (접기/펼치기 토글)
- 접는 상태가 기본값.
- 음원 목록에서의 태그는 별개의 부분이기에 현행 유지할것(변경 금지.)
