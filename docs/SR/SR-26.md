# SR-26

## 대상 화면

마이페이지 (내 계정 정보 화면)

---

## 수정 내용

현재 마이페이지에서 계정 정보, 구독 정보, 프로필 수정, 비밀번호 변경 항목이 단순 병렬 구조로 나열되어 있어 정보 구조가 단순하고 확장성이 부족한 상태임.

- 서비스 기능 확장에 따라 라이선스 보기, 다운로드 목록, 좋아요 목록 등 사용자 활동 기반 정보가 마이페이지에 포함될 필요가 있음.
- 기존 상단 내비게이션에 존재하는 일부 기능은 향후 마이페이지로 통합되는 방향을 고려하여 구조를 재설계한다.

### 레이아웃 개선 방향

단순 병렬 구조에서 벗어나 카테고리 기반 구조 또는 사이드 네비게이션 구조로 개선한다.

**예시 구조**

- 계정 관리 (계정 정보, 비밀번호 변경 등)
- 구독 관리
- 내 활동 (좋아요, 다운로드, 재생 목록 등)
- 라이선스 관리

### UI 방향

- 카드 나열 방식에서 벗어나 좌측 메뉴 + 우측 콘텐츠 영역 구조 또는 섹션 그룹화 방식으로 개선한다.
- 가독성과 확장성을 확보한다.

> 해당 작업은 단순 UI 수정이 아닌 정보 구조 설계, UX 개선, 기능 통합을 포함한 리디자인 작업으로 진행한다.
