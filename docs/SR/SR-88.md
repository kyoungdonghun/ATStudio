# SR-80 음원 플레이어 재생기록 스크롤바 숨김 (기능 유지)

> **우선 가치**: 작업 수행 전, 현재 재생기록 영역의 스크롤바가 어떻게 렌더링되는지(기본 브라우저 스크롤바인지, 커스텀인지), 다른 스크롤 영역과의 일관성을 명확하게 파악한다. 문제 해결에 추가 정보나 좋은 제안이 있다면 적극적으로 제안한다.

## 환경

- PC

## 수정 내용

- 음원 플레이어의 재생기록 영역에서 스크롤바를 시각적으로 숨김
- 스크롤 기능 자체는 유지 (마우스 휠, 터치 등으로 스크롤 가능해야 함)
- 다크/라이트 모드 모두 동일 적용
