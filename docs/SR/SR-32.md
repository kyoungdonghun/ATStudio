# SR-32

## 대상 화면

관리자 페이지 > 앨범 관리

---

## 수정 내용

현재 관리자 페이지에서 앨범 생성 및 썸네일 설정은 가능하나 앨범에 음원을 추가하는 기능이 존재하지 않는 문제가 있음.

- 앨범의 핵심 기능은 음원을 묶는 것이므로 기능적으로 불완전한 상태임.

---

- 우선 앨범에 음원을 추가하는 기능이 다른 화면에 존재하는지 여부를 확인한다.
- 기능이 존재하지 않을 경우 신규 기능으로 구현한다.

### 음원 추가 기능 구현

- 기존 음원 페이지의 검색 및 태그 기반 선택 UI를 참고하여 음원을 검색하고 선택하여 앨범에 추가할 수 있도록 구성한다.

### 순서 관리 기능 구현

- 앨범에 추가된 음원에 대해 곡 순서 관리 기능이 필요하므로, 큐바 플레이어의 대기열 드래그 앤 드롭 기능을 참고하여 순서 변경 기능을 구현한다.

### 최종 구현 목표

앨범 관리 화면에서 다음 기능이 모두 동작하도록 완성한다.

- 앨범 내 음원 리스트 조회
- 음원 추가 / 제거
- 순서 변경 (드래그 앤 드롭)

---

- 필요 시 DB에서 앨범-음원 관계 테이블 구조를 확인하고, 순서 정보(order index) 컬럼 추가 여부도 검토한다.

> 해당 작업은 기능 미구현 보완, UI 설계, DB 구조 검토까지 포함된 작업으로 진행한다.
