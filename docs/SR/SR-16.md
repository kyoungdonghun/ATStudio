# SR-16 관리자 공지사항 작성 첨부파일 업로드 기능 추가

## 대상 화면

-   관리자 페이지 \> 공지사항 관리 \> 공지사항 작성 화면

## 수정 내용

-   현재 공지사항 작성 화면에서 첨부파일 업로드 기능이 제공되지 않는
    상태임.
-   프로젝트 명세서에 공지사항 작성 시 파일 첨부 기능이 포함되어 있는지
    여부를 확인한다.
-   기능이 명세에 포함되어 있음에도 구현되지 않은 경우 프론트엔드에서
    첨부파일 업로드 컴포넌트를 추가한다.
-   공지사항 작성 시 파일 업로드 및 저장이 가능하도록 기능을 구현한다.
-   백엔드에 기능이 이미 존재하지만 프론트에서 연결되지 않은 경우
    컴포넌트를 추가하여 연동한다.
