# SR-84 모바일 플레이어 "펼치기" 버튼 상시 노출

> **우선 가치**: 현재 모바일 플레이어에서 펼치기 버튼이 재생 중일 때만 보이는 것을 확인한 후, 비재생 상태에서도 노출되도록 수정한다.

## 환경

- 모바일 전용
- 파일: `frontend/src/layouts/PlayerBar.tsx`, `PlayerBar.module.css`

## 현상

- 현재 모바일 하단 플레이어에서 "펼치기" 버튼(확장 토글)은 사용자가 음원을 재생한 이후에만 노출됨
- 비재생 상태(처음 접속, 플레이어 placeholder 표시 시)에선 펼치기 버튼 없음

## 수정 내용

- 모바일 플레이어에서 `currentTrack` 여부와 관계없이 펼치기 버튼을 항상 노출
- 비재생 상태에서 펼쳤을 때의 확장 패널 콘텐츠는 placeholder(예: "재생할 곡을 선택하세요")로 유지
- 재생 상태일 때의 기존 확장 패널 동작은 그대로
