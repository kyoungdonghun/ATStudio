# SR-18

## 대상 화면

음원 목록 페이지

---

## 수정 내용

현재 음원 목록 페이지에서 정렬 기준이 '인기순'과 '최신순'만 제공되고 있는 상태임.

- 프로젝트의 DB 스키마, API 스펙, 유즈케이스 문서를 확인하여 추가적으로 필요한 정렬 기준이 있는지 검토한다.
- 예를 들어 다운로드 수, 좋아요 수 등 추가적인 정렬 기준이 존재하는지 확인한다.
- 확인된 정렬 기준이 존재할 경우 음원 목록 정렬 옵션에 추가하여 사용자 선택이 가능하도록 기능을 확장한다.
- 정렬 기준 추가 시 백엔드 정렬 로직 및 API와의 연동도 함께 검토하여 반영한다.
