# SR-81 아티스트 표기 전면 숨김 (목록 / 상세 / 플레이어바)

> **우선 가치**: ATStudio의 음원은 쇼츠용 사용을 목적으로 하며, 구매/사용 의사결정에서 아티스트 정보의 비중이 낮다. 클라이언트 요청에 따라 사용자 노출 지점에서 아티스트 표기를 전면 제거하여, 제목과 태그 중심의 탐색 UX로 정리한다.

## 환경

- PC, 모바일 공통
- 사용자(구매자/구독자) 화면 전용 — 관리자 화면은 본 SR 범위에서 제외

## 배경

- 기존 UI에는 음원 목록, 트랙 상세, 하단 플레이어바 등 여러 지점에 아티스트 이름이 표기되어 있음
- 클라이언트 요청: **"아티스트는 미표기해도 된다"** → 모든 노출 지점에서 제거

## 수정 내용

### 1. 음원 목록

- `TrackRow` 및 동등 컴포넌트에서 아티스트 필드 렌더 제거
- 제거로 확보된 폭은 SR-80의 태그/제목 폭 정책과 **일관**되게 재분배

### 2. 트랙 상세 페이지

- 상세 상단 메타 정보(제목/태그/재생수/좋아요 등)에서 아티스트 라인 제거
- 관련 라벨/아이콘/링크(아티스트 페이지 이동 등) 있다면 함께 제거
- SEO/메타 태그가 아티스트명을 참조하는 경우 대체 문구 검토

### 3. 하단 플레이어바

- 현재 곡 정보 영역에서 아티스트 표시 제거 — 제목만 노출
- 제목 클릭 / 썸네일 클릭 동작(SR-82)은 유지

### 4. 기타 노출 지점 점검

- 검색 결과 카드/리스트
- 좋아요 목록, 재생목록, 다운로드 기록(SR-79)
- 앨범 상세 내 수록곡
- 메인 홈의 추천/신규 섹션
- **검색 기능의 검색 대상에서도 아티스트 제외** (SR-79 검색란이 "제목 + 태그"만 대상으로 하는 이유와 동일)

## 확인 사항

- 데이터 모델 자체에서 아티스트 필드를 **제거하지는 않음** — 관리자/백엔드 측 기록은 유지
- 플레이어 내부 metadata, OG 태그, 브라우저 탭 타이틀 등에서 아티스트 사용 여부 점검
- 접근성(aria-label) 문구에서 아티스트 참조 정리

## 연관 SR

- SR-79: 검색 대상에서 아티스트 제외
- SR-80: 확보된 폭 재분배
- SR-82: 플레이어바 인터랙션 변경과 함께 제목만 노출
