## 개요

ATStudio 프론트엔드는 크게 6개 그룹으로 구성됩니다.

| 그룹 | 화면 수 | 접근 권한 |
|------|---------|----------|
| 1. 공개 화면 | 9개 | 누구나 (비회원 포함) |
| 2. 인증 화면 | 6개 | 비로그인 상태 대상 |
| 3. 구독자 전용 화면 | 19개 | 로그인 필수 (minRole: USER) |
| 4. 크리에이터/관리자 음원·앨범 관리 | 5개 | ADMIN 전용 |
| 5. 관리자 전용 화면 | 10개 | ADMIN 전용 |
| 6. 에러 화면 | 2개 | 누구나 |

권한 체계: `GUEST(0) < USER(1) < CREATOR(2) < ADMIN(3)`
`ProtectedRoute`가 `minRole` 기준으로 숫자 비교하여 미달 시 홈(`/`)으로 리다이렉트합니다.

## 1. 공개 화면 (비회원 포함 누구나 접근 가능)

공개 화면은 ATStudio의 주요 콘텐츠를 누구나 탐색할 수 있도록 인증 없이 노출합니다.
서비스 진입 장벽을 낮추고, 비회원도 음원·앨범·공지를 확인하여 구독 구매를 유도하는 것이 목적입니다.

---

#### 메인 화면

- **파일**: `frontend/src/pages/public/HomePage.tsx`
- **URL**: `/`
- **접근 권한**: 비회원 포함 누구나
- **주요 기능**:
  - 음원 목록을 리스트 형태(썸네일·제목·파형·재생 버튼)로 노출
  - 앨범 섹션을 이미지 카드 형태로 노출
  - 태그 필터(인라인 CHIP/SELECT)로 장르·분위기별 탐색
  - 로그인 사용자: 좋아요 토글, 재생목록 추가, 다운로드 큐 담기 인라인 제공
  - "더 보기" → 음원 목록 / 앨범 목록 페이지로 이동
- **연관 API**: `GET /api/tracks`, `GET /api/tags`, `POST /api/likes/{trackId}` (로그인 시), `POST /api/download-queue/{trackId}` (로그인 시)

#### 로그인

- **파일**: `frontend/src/pages/auth/LoginPage.tsx`
- **URL**: `/login`
- **접근 권한**: 비회원 (로그인 후 접근 시 홈으로)

  - 소셜 로그인 버튼(Google/Kakao/Naver) 제공
