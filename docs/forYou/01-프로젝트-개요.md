# 01 - 프로젝트 개요

---

## 한 줄 요약

ATStudio는 음악 크리에이터가 쇼츠용 트랙을 업로드·판매하고, 구독자가 그 트랙을 검색·다운로드·활용할 수 있는 **쇼츠 음악 마켓플레이스 웹 애플리케이션**입니다.

---

## 배경과 목적

유튜브 쇼츠, 틱톡, 릴스 등 숏폼 영상 콘텐츠가 폭발적으로 증가하면서, 크리에이터들은 영상에 맞는 짧고 강렬한 배경 음악을 빠르게 찾아야 하는 수요가 생겼습니다. 기존 음원 플랫폼은 쇼츠 특화 라이선스 발급이나 즉시 다운로드 기능을 갖추지 못한 경우가 많습니다.

ATStudio는 이 문제를 해결하기 위해:
- **공급 측**: 음악 크리에이터(Creator)가 쇼츠에 최적화된 트랙을 업로드하고 수익을 얻는 장을 제공합니다.
- **수요 측**: 쇼츠 영상 제작자(구독자, Subscriber)가 원하는 트랙을 검색·미리듣기·다운로드하고 라이선스를 자동으로 발급받을 수 있게 합니다.
- **플랫폼**: 구독 기반 월정액 모델로 운영되며, 관리자(Admin)가 트랙, 사용자, 태그, 공지 등을 관리합니다.

---

## 주요 사용자 유형

### 비회원 (Guest)

회원가입 또는 로그인 없이 접근 가능한 범위는 다음과 같습니다:

- 홈 화면에서 인기/추천 트랙 및 앨범 조회
- 트랙 목록 검색 및 필터링 (장르, 태그 등)
- 트랙 상세 페이지에서 미리듣기(30초 내외)
- 앨범 목록 및 앨범 상세 조회
- 구독 플랜 안내 페이지 조회
- 공지사항 조회

비회원은 트랙 다운로드, 재생목록 생성, 라이선스 발급 기능을 사용할 수 없습니다.

---

### 구독자 (SUBSCRIBER)

이메일 회원가입 후 구독 플랜을 결제한 사용자입니다. 다음 기능을 사용할 수 있습니다:

- 비회원 기능 전체 포함
- 트랙 다운로드 및 라이선스 자동 발급
- 재생목록(Playlist) 생성·관리 (최대 3개)
- 다운로드 대기열(Download Queue) 관리
- 좋아요(Like) 등록 및 목록 조회
- 재생 기록(Play History) 조회
- 유튜브 채널 화이트리스트(Whitelist Channel) 등록 (구독 플랜별 개수 제한)
- 구독 플랜 관리 (업그레이드/다운그레이드/취소)
- 기업 인증(Company Certification) 신청 (BUSINESS 플랜 전용)
- 1:1 문의(Question) 작성 및 답변 조회
- 프로필 수정, 회원 탈퇴

> **주의**: "구독자"와 "크리에이터"는 별개의 역할입니다. 현재 구현에서 크리에이터 기능(트랙 업로드 등)은 관리자(ADMIN) 계정만 사용할 수 있습니다.

---

### 크리에이터 (CREATOR)

트랙을 업로드하고 판매하는 공급자 역할입니다. 현재 구현 상태에서는 **관리자(ADMIN) 계정이 크리에이터 기능을 겸합니다.**

- 트랙 업로드 (오디오 파일, 커버 이미지, 메타데이터 포함)
- 트랙 정보 수정
- 앨범 생성·수정·관리

---

### 관리자 (ADMIN)

플랫폼 전반을 운영·관리하는 최상위 역할입니다:

- 크리에이터 기능 전체 포함
- 관리자 대시보드 (통계: 가입자 수, 구독자 수, 총 트랙 수 등)
- 사용자 목록 조회 및 계정 관리 (역할 변경, 비활성화 등)
- 구독 현황 조회 및 관리
- 라이선스 전체 조회 및 관리
- 1:1 문의 관리 및 답변
- 기업 인증 심사 (승인/반려)
- 태그 생성·삭제 관리 (장르, 분위기, BPM 등 카테고리)
- 트랙 관리 (활성화/비활성화, 삭제)
- 공지사항 작성·수정

## 비즈니스 모델

ATStudio는 **구독 기반 월정액 모델**로 운영됩니다.

구독자는 플랜을 선택하여 매월 결제하며, 플랜에 따라 다운로드 가능 수, 유튜브 채널 화이트리스트 등록 개수 등 사용 한도가 달라집니다.

| 구독 상태 | 설명 |
|-----------|------|
| ACTIVE | 정상 구독 중, 모든 기능 사용 가능 |
| CANCELLED | 취소됨, 만료일(expires_at)까지 서비스 유지 후 종료 |
| EXPIRED | 만료됨, 다운로드 등 구독 전용 기능 차단 |

**업그레이드**: 즉시 적용. 잔여 기간만큼의 차액을 결제합니다.
**다운그레이드**: 현재 기간 유지, 다음 결제일부터 낮은 플랜으로 전환됩니다.
**취소**: 즉시 취소 처리되나, 만료일까지는 서비스를 계속 이용할 수 있습니다.

## 현재 개발 상태

### 백엔드

| 항목 | 내용 |
|------|------|
| 프레임워크 | Spring Boot 4.x + Java 17 |
| 데이터베이스 | MySQL 8.x (23개 테이블) |
| 인증 방식 | JWT (JJWT 0.12.5), 이메일 회원가입 + 소셜 로그인 |
| API 수 | 87개 완성 |
| API 문서 | Swagger UI: `http://localhost:8080/swagger-ui/index.html` |
| 파일 저장 | 로컬 스토리지 (S3 전환 예정) |
