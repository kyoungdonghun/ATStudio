# ATStudio 신규 팀원 온보딩 가이드

이 패키지(`docs/forYou/`)는 ATStudio 프로젝트에 처음 합류한 팀원이 **배경 지식 없이도** 서비스 구조, 코드 구성, 개발 방식을 빠르게 파악할 수 있도록 설계된 입문 문서 모음입니다. 각 문서는 "어떤 질문에 답하는가"를 기준으로 순서가 정해져 있으며, 01번부터 순서대로 읽는 것을 권장합니다. 전체를 읽는 데 약 1~2시간이 소요됩니다.

---

## 추천 읽는 순서

1. **01 - 프로젝트 개요**: ATStudio가 무엇인가? 누가 쓰는가? 어떤 기능이 있는가?
2. **02 - 프로젝트 구조**: 폴더가 어떻게 생겼는가? 코드는 어디에 있는가?
3. **03 - 개발 스탠다드** (예정): 코드를 어떻게 짜야 하는가? 어떤 규칙을 따르는가?
4. **09 - 로컬 환경 셋업** (예정): 개발 환경을 처음부터 어떻게 세팅하는가?
5. **04 - API 명세 요약** (예정): 백엔드가 어떤 API를 제공하는가?
6. **08 - DB 스키마 요약** (예정): 데이터가 어떤 테이블에 어떻게 저장되는가?
7. **05~07** (예정): 비즈니스 흐름, 화면 목록, 화면 이동 경로

## 로컬 빠른 시작

개발 환경을 바로 세팅하고 싶다면 09번 문서(로컬 환경 셋업)를 참조하세요. 09번 문서 작성 전까지는 아래 간단 요약을 사용하세요.

**백엔드 실행:**
```bash
# Windows
gradlew.bat bootRun

# 접속: http://localhost:8080
# Swagger UI: http://localhost:8080/swagger-ui/index.html
```

**프론트엔드 실행:**
```bash
cd frontend
npm install
npm run dev

# 접속: http://localhost:5173
```

**사전 요구사항:** Java 17, MySQL 8.x (로컬 포트 3306, 비밀번호 기본값: `1234`), Node.js 18+
