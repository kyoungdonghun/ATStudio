# PC·모바일 사용자 시험표

이 표는 준비 자료입니다. 지금 실행한 결과나 서버 실행 승인이 아닙니다. 기존 1단계의 음원 API·재설정 성공은 재사용하며, 이후 실제 PC·모바일 화면에서 확인하지 못한 사용 흐름과 변경된 부분에 집중합니다.

시작 전 개발자가 접속 대상·참여자·시간·허용된 변경·중단/원복 담당을 기록하고, 최신 복구 근거와 실행 후보 검토를 완료합니다. 현재 백업 도구에는 예전 ID1 역할 조건이 남아 있으므로 먼저 로컬 보완·검토가 필요합니다. 공개 접근을 임의로 열거나 이 표만 보고 서버를 시작하지 않습니다.

계정은 ID1·2 관리자, ID3 구매자를 재사용합니다. ID3의 폐기된 이전 저장 비밀번호는 사용하지 않습니다. 현재 비밀번호는 시험 시 본인이 직접 입력하며 채팅·오류 양식에 적지 않습니다. 로그인·로그아웃은 세션값을 바꾸고, 최초 다운로드·업로드는 업무 데이터를 만드므로 해당 영향까지 포함한 실행 범위가 필요합니다.

각 행은 PC 1개 브라우저와 실제 휴대폰 1개 브라우저에서 `정상 / 문제 / 미실행`으로 기록합니다. 모바일 화면 크기 흉내만 낸 결과를 실제 휴대폰 검증으로 표시하지 않습니다.

| 항목 | 확인할 동작 | 예상 결과와 영향 |
|---|---|---|
| 로그인·메뉴 | 기존 계정 로그인, 계정 표시·권한 메뉴, 로그아웃 후 보호 화면 진입 | 올바른 사용자·권한 표시, 로그아웃 후 보호 화면 거부. 세션 변경 포함. 비밀번호 재설정 전체 흐름은 새 원인 없으면 반복하지 않음. |
| 내 정보 | 자기 정보 화면과 화면 배치 확인 | 등록 정보가 본인에게만 보이고 모바일에서 잘리지 않음. 저장 버튼은 별도 변경 범위 없으면 누르지 않음. |
| 탐색 | 기존 곡 검색·필터·상세 진입·뒤로 이동 | 결과와 선택 상태가 일관되고 모바일 조작 가능. 검색어에 실제 개인정보를 넣지 않음. |
| 재생·탐색 위치 | 승인된 기존 시험곡 재생·일시정지·중간 이동·다시 재생 | 소리·위치·표시가 일치하고 화면 이동 중 조작 가능. 브라우저 자동재생 제한과 실제 오류를 구분. 재생 이력은 브라우저에 남을 수 있음. |
| 구매자 다운로드·라이선스 | ID3으로 승인된 곡 1개 다운로드, 파일·다운로드 기록·라이선스 화면 확인 | 권한 있는 파일과 본인 기록 확인. 기존 라이선스 재다운로드와 첫 다운로드를 구분; 첫 다운로드는 기록·라이선스·곡 다운로드 수를 변경함. 날짜 기준 이용권 유효 여부를 먼저 확인. |
| 접근 거부 | 로그아웃 상태의 원본 다운로드, ID3의 관리자 화면/기능 접근을 개발자가 정한 경로로 시도 | 정상 거부, 원본·타인 정보 유출 없음. 임의 URL·타인 계정/레코드 탐색 금지. |
| 관리자 업로드 | 승인된 추가 WAV 1개와 범위가 있을 때만 ID1 또는 ID2로 업로드·변환 상태·결과 확인 | 올바른 상태·오류 안내 및 완료 후 재생. 파일·곡·작업 기록이 생성됨. 추가 곡 생성이 불필요하면 기존 곡 화면만 확인하고 업로드는 미실행 기록. |

ID1도 현재 ADMIN이므로 이용권 없는 일반 구매자 역할로 사용하지 않습니다. 소스상 ADMIN은 이용권·일 다운로드 한도 검사를 우회합니다. 기존 라이선스가 있는 곡의 재다운로드도 해당 검사를 건너뛰므로 ID3의 기존 track1 반복 다운로드를 한도 시험으로 표시하지 않습니다. 기존 곡은 재다운로드·파일 일치·화면 확인에 사용합니다. 이용권 없는 일반회원·한도 초과·만료 차단은 기존 증거를 재사용하고, 새 검증이 필요하면 해당 곡 라이선스가 없는 격리 합성 fixture와 변경 범위를 먼저 준비합니다. 이를 위해 ID3 이용권을 임의로 만료시키거나 새 계정을 가입시키지 않습니다. 과거 ID1이 USER였을 때의 1단계 결과는 당시의 유효한 검증으로 보존합니다.

실결제·자동결제·환불은 Toss 계약·요금·LIVE 설정과 정확한 금액/취소 범위가 준비된 별도 시험입니다. 탈퇴·실제 데이터 삭제·CID 외부 등록·마케팅 발송·보유기간 시험도 이 표에 포함하지 않습니다. 시범 운영 전에 가입과 약관 동의 화면이 변경되면 그 변경 부분을 추가합니다.

문제가 생기면 [오류 기록 양식](error-report-template.md)에 한 번 기록하고 같은 동작을 계속 반복하지 않습니다. 결제·업로드처럼 결과가 불명확한 작업은 개발자가 실제 결과를 확인한 후 재시도합니다. 시험 종료 후 개발자가 승인된 데이터 변화·세션·앱/DB·접근 복구 결과를 정리합니다.

근거: `DownloadService.java:44-86`, 현재 ID1·2 ADMIN/ID3 USER 적용 기록, WI001/002 및 1단계 최종 증거. 체크리스트의 동작은 이번에 실행하지 않았습니다.
