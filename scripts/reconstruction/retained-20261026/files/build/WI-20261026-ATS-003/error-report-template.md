# 사용자 시험 오류 기록

아래 빈칸만 적으면 됩니다. 같은 오류를 확인하려고 계속 재시도하지 않아도 됩니다.

| 항목 | 기록 |
|---|---|
| 발생 시각 | 날짜·시각·한국시간 여부 |
| 기기·브라우저 | 예: Windows/Chrome, iPhone/Safari, Android/Chrome와 버전 |
| 시험 항목 | 위 시험표의 항목 이름 |
| 역할 | 관리자 또는 구매자 — 이메일 대신 시험용 별칭 |
| 문제 직전 행동 | 1~3단계로 간단히 |
| 기대한 결과 | |
| 실제 결과 | 화면의 오류 문구·코드만 |
| 발생 빈도 | 첫 시도 / 이미 반복됐음 / 다시 시도하지 않음 |
| 결과가 불명확한 작업 | 업로드·다운로드 등 완료 여부를 모르겠다면 표시 |

비밀번호·인증번호·토큰·재설정 링크·API 키·사업자 증빙·전체 결제 영수증 링크는 적지 않습니다. 원본 화면 캡처를 기본 첨부하지 않습니다. 화면이 꼭 필요하면 개발자가 민감정보가 없는 범위를 먼저 지정합니다. 오류 원인이 파악되면 개발자가 해당 부분만 재확인합니다.
